### Critical insight: Pinterest is a REACH + SAVES engine, not a traffic driver [confirmed 2026-07-24]
The best pin got 24.2k impressions and 201 saves but only **8 outbound clicks**. Pinterest sends almost no one off-platform for this content. So:
- Value of Pinterest = evergreen discovery, brand presence, and saves that compound. NOT clicks to YouTube or Skool.
- Do NOT expect Pinterest to move video views or Skool signups much. Judge pins on impressions + saves.
- Because outbound is low regardless, the destination link matters less than the pin's own reach. Optimize the pin to be saved (useful reference card), not to be clicked.

## The winning formula [confirmed 2026-07-24]

1. **Frame it as a SYSTEM, not a tactic.** The words that win: "Blueprint", "Stack", "Reference Card", "Explained", "N Types of". Whole-system pins beat one-command how-tos every time.
2. **Description shape (copy this):** bold first-person outcome claim -> a comma-separated list of what it does -> end with an explicit "Save this [blueprint / reference card / stack / plan]." EVERY top pin ends with "Save this ___".
3. **Named, searchable concepts** in the title (CLAUDE.md, AI Memory, Solopreneur Stack). Pinterest is a search engine - the title is the keyword.
4. **Numbered / comprehensive** - "runs my ENTIRE", "25 skills", "3 types", "5 tools".
5. **Visual = infographic / "info sheet" / reference card.** 2:3 ratio, 1000x1500. NOT a talking head. Every winner's alt text says "info sheet".

## THE winning visual template [confirmed 2026-07-24, from the 46-repin Skool pin]

The Skool Automation Blueprint pin is the template to clone for all future pins:

- **Ratio:** 2:3 vertical (1000x1500).
- **Background:** warm cream / off-white with subtle paper texture. (Matches Tyler's brand cream + terra cotta, same palette as the Instagram carousels.)
- **Title:** navy, bold, ALL CAPS, 2 lines, very large, spanning the top ~15%. Uses "PLUS" spelled out ("CLAUDE CODE PLUS SKOOL AUTOMATION").
- **Body:** 5 stacked white rounded-rectangle cards with soft shadow. Each card has three parts:
  - LEFT: a terra-cotta gradient rounded-square icon tile with a white line icon (pencil, people, chat, cap, chart).
  - MIDDLE: bold navy ALL-CAPS section heading + a small gray 2-3 line description using " / " separators.
  - RIGHT: 3 bullet points, each a terra-cotta circle checkmark + a short label.
- **Accent color:** terra cotta / burnt orange gradient (icons + checkmarks). Navy for headings. Gray for body.
- **Structure = 5 sections x (icon + heading + 3 checkmarks).** This "5-section reference card" IS the format that hit tens of thousands of impressions.

Not every pin needs exactly 5 sections, but the recipe is: bold all-caps title, cream bg, terra-cotta icon tiles, white cards, checkmark trios.

**Production: Kie.ai + Nano Banana Pro** [confirmed 2026-07-24]. The winning infographic was AI-generated with Nano Banana Pro via Kie.ai (use /kie-nano-banana or /yt-thumbnail). Nano Banana Pro renders clean structured text, so it can do these reference cards. Write a precise prompt with ALL the exact text baked in (title, each heading, each checkmark) and the cream/navy/terra-cotta palette. Generate at 2:3 (1000x1500 / 1024x1536). Always eyeball the output for garbled or misspelled text and regenerate if wrong - dense infographics are where even Nano Banana Pro can slip.

## What flops
- Narrow one-command how-tos ("Auto-Caption with Submagic in One Command", "5 Steps to Auto-Generate a LinkedIn PDF", "$1 UGC Ad"): 0-1 repins. Too specific to be searched or saved.

## CTA / link rules
- Community/system pins -> Skool funnel (the 46-repin winner links to Skool).
- Per-video concept pins -> the YouTube video (CLAUDE.md pin -> 004, still pulling search traffic months later).
- Pinterest is a 6-12 month slow burn. Judge pins on the compounding curve, not day-one.
- **Each pin spikes then decays.** The Skool pin hit ~45 impressions/day in its first 2 weeks (mid-May), then settled to ~10/day. Its 24k lifetime impressions were front-loaded. The recent ↓97% is just this decay, not a problem. Implication: the winning strategy is VOLUME of fresh pins on a steady cadence (Tyler's own algorithm pin says 5-15 fresh pins/day after warmup), not a few pins you expect to run forever. 2-3 pins x 12 videos = 24-36 fresh pins to schedule out, not dump at once.
