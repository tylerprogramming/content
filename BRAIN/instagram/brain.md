## Rules that are working right now

1. **Always gate with a comment keyword.** Caption line 1 = "Comment WORD and I'll send you X". Every top performer in the niche does this (chandlerintelligence 3.45M plays in 13 days with "Comment JARVIS"). It drives comment velocity and builds the DM list. One word, all caps, easy to type. [confirmed 2026-07-20]
2. **Claude content is a mainstream IG lane.** 11.4M (meech_ward Claude Code features), 3M (varunmayya Claude memory), 2.6M (Illegal Claude Tips Part 37), 2.4M (Claude skill giveaway). Lean into Claude Code specifics, not generic AI. [confirmed 2026-07-20]
3. **Reels for reach, carousels for saves.** 30-day reel median 26K plays vs carousel scores in the 3-30K engagement range. Post a reel AND a carousel on the same topic days apart (chase.h.ai's play). [confirmed 2026-07-20]
4. **Designed static feed images do not perform.** 1 of 179 winners. Statics belong in flash-video reels or carousel slides only. [confirmed 2026-07-20]
5. **Series branding compounds.** "Illegal Claude Tips Part 37" = binge-able, repeatable, algorithm-friendly. Tyler should own a named series. [confirmed 2026-07-20]
6. **On-image title: 5 words max, pill background.** All winning covers are readable at feed size. [confirmed 2026-07-20]

## Cover formulas (ranked by evidence)

1. Real terminal / product UI screenshot top half + talking head bottom + white rounded pill with short bold black title ("Claude Code 5 best tips"). Authentic UI beats designed graphics.
2. Logo-stack on black (ChatGPT / Claude / Gemini logos large, face small at bottom). Instant recognition.
3. JARVIS aesthetic: face + glowing blue dashboards. Top emotional hook in the agent niche; usually shallow content, so real substance wins here.
4. Lo-fi UGC selfie + small pill title + Claude asterisk logo pinned top. Low production, series-branded.

## Format strategy

- Reels: 30-60s screen-recording or split face+screen. Duration of winners: 33-115s, sweet spot around 35-60s.
- Carousels: 6 slides, gate the full guide behind a comment keyword. Pair each carousel with a reel on the same topic.
- Flash videos: list layouts with a stat line; keyword CTA in caption.
