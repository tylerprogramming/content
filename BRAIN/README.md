# BRAIN

Central knowledge base of what's working per platform. One folder per platform, each with a `brain.md` as the main playbook (add extra files per platform as needed, e.g. `hooks.md`, `competitors.md`).

```
BRAIN/
  tyler-voice.md       <- Tyler's voice guide, applies to ALL written content
  instagram/brain.md   <- updated by /ig-research, read by /instagram-writer, /flash-video, /social-copy
  linkedin/            <- future: LinkedIn research skill
  tiktok/              <- future: fold in /tiktok-analytics learnings
  youtube/             <- future: fold in youtube-channel-playbook learnings
```

Rules:
- Research skills WRITE here (distilled rules with [confirmed YYYY-MM-DD] stamps + changelog, never raw data).
- Creation skills READ here first, before creating anything for that platform.
- Rules that stop being true get retired, not left to rot. Stale brains are worse than no brains.
