# Carousel Ideas - Based on Shorts & Long-Form Research

## Format Guide

| Platform | Format | Notes |
|----------|--------|-------|
| **Instagram** | Images + video slides in carousel | Mix static slides with short video/gif clips for higher engagement. IG favors carousels with video slides. |
| **LinkedIn** | PDF carousel (static) + gif as first slide | Upload PDF for swipeable carousel. Can also post a single gif/video with a carousel-style caption. |
| **TikTok** | Photo carousel mode | 2-10 images, swipeable. Add music. No video slides in carousel mode. |

### Video/GIF Slide Ideas
For any carousel, create 2-3 second screen recording clips showing:
- Claude Code terminal typing a command
- Nano Banana generating an image
- A carousel being built in the app
- Blotato scheduling posts
- Kling 3.0 generating a video

These can be slide 2 or 3 in the carousel (after the static cover) to boost engagement.

## How to Create the Video/GIF Slides

### For Instagram video slides:
1. Screen record the tool in action (3-5 seconds)
2. Crop to 1080x1350 (4:5)
3. Export as .mp4
4. Add as a slide in the Instagram carousel post

### For LinkedIn gifs:
1. Screen record the best moment (3-5 seconds)
2. Convert to gif: `ffmpeg -i input.mp4 -vf "fps=15,scale=1080:-1" -loop 0 output.gif`
3. Or keep as short .mp4 - LinkedIn auto-loops videos under 10 seconds
4. Post the gif/video with a text caption (the carousel content as text)

### For TikTok photo carousels:
1. Export slides as 1080x1920 (9:16) images
2. Upload as photo carousel in TikTok
3. Add trending music
4. First slide = hook, last slide = CTA
