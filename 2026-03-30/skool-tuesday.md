# Topic: Claude Code is not a chatbot

most people start using claude code like a better chatgpt. that's the mistake.

chatbots answer questions. claude code takes actions. it can actually touch your computer - create files, run commands, install packages, build things.

the shift that changed how i use it: stop asking it questions, start giving it jobs.

"build this." "automate that." "fix this file."

what's one thing you'd hand off to it today if you knew it would work?
