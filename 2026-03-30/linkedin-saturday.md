# Topic: Why Claude Code prompts keep failing

There's one reason most Claude Code prompts don't work the first time.

You're describing the task instead of the output.

Compare these two:

"Build me a website."

vs.

"Build me a one-page landing page for a consulting business. Green color scheme. Single column layout. Hero section with a headline and subtext. Contact form at the bottom. No navigation bar."

Same request. Completely different result.

Claude Code is powerful but it's not a mind reader.

It fills in every missing detail with assumptions. And usually those assumptions aren't what you wanted.

Here's the fix I use before every prompt:

Can I picture exactly what done looks like?

What does the final output contain?

What format is it in?

What should it NOT include?

Are there examples I can point to?

If I can't answer those, I add more detail until I can.

Takes 30 extra seconds.

Saves 20 minutes of fixing a result that missed the mark.

The more specific you are about the output, the less you need to say about the process. Claude figures out the how.

You just have to be clear about the what.

Specificity is the cheat code. Every time.
