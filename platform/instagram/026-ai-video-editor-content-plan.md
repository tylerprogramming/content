# 3 reels to record tomorrow

All three are screen recordings. No talking head, no lighting. Record all three
in one sitting — that is what everyone we studied does.

Format notes carried from the research: **original audio** (96/99 reels use it),
**gate in the caption**, and a hook that is a *first sentence with nothing before
it*. Duration is not a lever — let each one be as long as it needs.

## Reel 1 — "someone just built" (brody's formula, ~40s)

His exact stem, seven uses, all five of his top posts. We own the repo, so we
can run it in first person or keep it third.

**Hook (spoken, frame one, no preamble):**
> "Someone just built a Claude Code setup that edits video without touching a timeline."

**Body — screen recording, narrate over it:**
1. Show the raw footage folder
2. Type the prompt: *"cut the dead air and add captions"*
3. Cut to the timeline building itself
4. Show the finished export

**Close (spoken):**
> "Comment EDITOR and I'll send you the whole thing."

**Caption:**
```
Comment "EDITOR" and I'll send you the setup 👇

I stopped opening a video editor. Claude Code reads the transcript, finds the
dead air, cuts it, and burns in captions. The whole edit is a prompt.

How do you edit video with Claude Code?
Can AI edit a video automatically?
What is the best AI video editing workflow in 2026?

#ai #claude #videoediting #aitools #automation
```

## Reel 2 — the numbered list (sabrina's shape, ~50s)

Her numbered reels are her best performers. Same source video, different cut.

**Hook:**
> "Five things Claude Code does to my videos that I used to do by hand."

**Body — one screen beat per item, ~8s each:**
1. Pulls the transcript
2. Finds every pause over half a second
3. Cuts them
4. Writes the captions
5. Exports the file

**Close:** same gate.

**Caption:** same template, hook line swapped to "Five things Claude Code does to
my videos that I used to do by hand."

## Reel 3 — the curiosity gap (chase's shape, ~60-90s)

His top reel (214k) is 118 seconds and opens without telling you what you are
looking at. Longer is fine here.

**Hook:**
> "If you don't know what you're looking at here, you're about to lose a lot of hours to something a prompt can do."

Open on the timeline already assembling itself. Do not explain for the first ten
seconds. Then walk it back and show how it was set up.

**Caption — chase's minimal style, worth A/B testing against the full template:**
```
Comment "EDITOR" to get my AI video editing setup
```
That is the whole caption. No tags. He runs this on 23 of 24 posts.
