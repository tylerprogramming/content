# Caption - skills-on-a-schedule  (SKILLS 3/4)

Some of the work on my computer happens while I am asleep, and I did not build an app to do it.

Save this. You'll use it.

So a skill is just a text file with instructions in it. The part people miss is that once you have one, you can put it on a schedule. There is a job on my machine that fires every hour, checks for comments I have not replied to, drafts the easy ones, and drops them into a single inbox file for me.

Same idea with email. Someone joins, the welcome sequence goes out, I am not in the loop for it.

The rule I keep is that everything defaults to draft. It finds the work and it writes the first version, but nothing gets posted without me reading it. You get the speed without handing over your judgment, which for me is the only version of this I actually trust.

Automate the finding and the drafting. Keep the deciding.
