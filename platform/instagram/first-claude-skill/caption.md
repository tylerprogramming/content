# Caption - first-claude-skill  (SKILLS 2/4)

Your first Claude Code skill takes about two minutes, and there is no code in it.

Save this. You'll use it.

So the whole thing is a folder with one file inside it called SKILL.md. At the top you write one or two lines saying what this is and when to use it. Underneath, you write the steps in plain English, the same way you would train a new assistant. Save it, and now it is a command you can run forever.

The mistake I see is picking something too ambitious for the first one. Do not build your whole workflow on day one. Pick the small thing you already did twice this week, write it down, run it, then fix the one line that annoyed you.

Every skill running my business now started as a rough text file I improved a little at a time. None of them were planned, they just got used.
