# swipe

Carousels worth stealing from, saved off the feed. One dated folder per
capture session, one subfolder per account.

These are **raw phone screenshots** - the whole screen, including Instagram's
status bar, story rail, header, and the like/comment/save counts underneath.
That chrome is the point: the engagement numbers are the evidence for whether
a style is worth copying at all, and they only exist in the raw capture.

The working versions live elsewhere. `~/social-studio/themes/references/` holds
the same slides cropped to the artboard, at a tenth the size, next to the
palettes sampled from them and a build recipe per style. Use those to make
something; keep these to check a claim.

Gitignored, like all media here. Roughly 3MB a screenshot, so prune a session
once its lessons are written into `BRAIN/instagram/carousel-styles.md`.
