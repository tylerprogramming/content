## Instagram

So this is the one command I run before every single render.

check opens the composition in a browser and sweeps the timeline looking for
the things you would only ever notice after a slow export. Lint, layout,
motion, contrast, and media that has drifted off the canvas.

That last one saved me the most. You genuinely do not see it while scrubbing.

And it prints JSON, which is the bit that makes it automation rather than a
tool. Claude runs the gate, reads the result, and fixes what it reports without
me sitting there.
