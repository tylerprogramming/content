# LinkedIn — Friday March 27
**Topic:** Claude Code skills — slash commands that do real work

---

I type 12 characters and get a full YouTube competitor research report.

That's not a prompt. That's a Claude Code skill — a markdown file that teaches Claude how to do a specific task your way, called with a slash command.

Here's how it works:

👉 You write the skill once — a markdown file with instructions, workflow steps, and rules

👉 You call it with /skill-name and optional arguments like a topic or file path

👉 Claude runs the full workflow, every time, exactly how you specified

I have skills for YouTube research, transcribing videos, planning scripts, SEO optimization, social media posts, fitness tracking, thumbnail generation, and more. Each one took 30-60 minutes to write. Now each one saves me hours every week.

👉 The key insight: skills are not just prompts. They're workflows. Claude doesn't just answer — it executes a multi-step process, uses tools, reads files, writes outputs, and saves results where you tell it to.

👉 Anyone can build one. If you've repeated a task more than 3 times in Claude Code, it's worth turning into a skill.

The best part — your skills live in a folder on your machine. They work in every project. They get better as you update them.
