# LinkedIn — Wednesday March 25
**Topic:** CLAUDE.md — the one file most Claude users don't know about

---

There's one file that changes how Claude behaves in every single session. Most people have never heard of it.

It's called CLAUDE.md. You put it in your project folder — or in your home directory for global settings — and Claude reads it automatically at the start of every session. No prompting required.

What can you put in it? Anything Claude needs to know to work the way you want.

👉 Behavior rules: "Never use em dashes." "Always ask before running a terminal command." "Be concise."

👉 Workflow context: "I make YouTube content about AI tools." "This is a Next.js app using Supabase." Give Claude the background it needs.

👉 Permissions: Pre-approve safe actions so Claude stops asking. "You can read and write files freely." "Always use npm, never yarn."

👉 Preferences: "Write scripts for spoken delivery, not essays." "Short sentences." "I prefer TypeScript."

The compounding effect is real. Every rule you add is something you never have to repeat again. I started with 3 rules. Mine is now a full page — and Claude works exactly the way I need it to, from the first message of every session.

Start with 3 rules. See what happens.
