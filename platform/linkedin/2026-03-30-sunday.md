# Topic: What a Claude Code skill actually is

A Claude Code skill is just a markdown file.

That's it. No code. No plugins. No API keys. Plain text.

Here's the entire structure:

A few lines of YAML at the top. Name it. Describe what triggers it. List the tools Claude can use when running it.

Below that, step-by-step instructions. Written like an SOP for a new hire.

"Step 1: do this. Step 2: do that. Save the output here."

Save the file to ~/.claude/skills/your-skill-name/SKILL.md

Claude Code picks it up automatically.

Type /your-skill-name. Claude reads the file and follows the steps.

Every single time. The same way. Without you explaining it again.

Here's what mine look like in practice:

A /yt-search skill that does competitor research in 30 seconds.

A /content skill that turns any video into a full week of social posts.

A /fitness skill that tracks workouts and nutrition with a visual grid.

A /chapters skill that generates YouTube timestamps from a final edit.

Each one took under an hour to build. Together they handle most of my workflow automatically.

The power isn't in the technology.

It's in your process.

If you can write down how you do something, you can turn it into a skill. That's it.

Skills aren't for engineers. They're for anyone who does the same thing more than once.

What would your first skill do?
