# LinkedIn Post - Wednesday April 1
# Topic: How to build a Claude Code skill

I built something last week that saves me 2 hours every Monday.

It took 5 minutes to make. No code required.

Every week I was doing the same YouTube competitor research. Opening tabs, sorting by views, looking for patterns.

45 minutes. Every single week.

So I turned it into a Claude Code skill.

Here's the exact process:

Pick one workflow you do manually more than 3 times.

Open a markdown file. Write down what you want Claude to do, step by step, in plain English. Not code. Just instructions.

"Step 1: Search YouTube for X. Step 2: Sort by view count. Step 3: Save a report."

Add three lines of front matter at the top. Name the skill, describe what triggers it, list the tools it can use.

Save the file to ~/.claude/skills/your-skill-name/SKILL.md

Type /your-skill-name in Claude Code. Watch it run.

The first version will be off. That's fine.

Update the file, test again, fix one thing at a time. After 2-3 iterations it runs exactly how you want.

I have 22 of these now. One for each workflow I used to do manually.

The rule is simple: if I've done something in Claude more than 3 times, it becomes a skill.

Most people spend hours perfecting prompts. I spend 5 minutes saving them permanently.
