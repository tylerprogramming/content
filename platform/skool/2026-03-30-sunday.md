# Topic: What a Claude Code skill is

a claude code skill is literally just a markdown file

front matter at top (3 lines), then your workflow written out step by step below. that's it. no code.

save it to ~/.claude/skills/your-skill-name/SKILL.md and type /your-skill-name. claude reads the file and follows the steps.

i have 20 of them now. research, content, thumbnails, fitness tracking, youtube chapters. each one took under an hour to build. together they run most of my week automatically.

if you can write down how you do something, you can turn it into a skill. that's the whole idea.
