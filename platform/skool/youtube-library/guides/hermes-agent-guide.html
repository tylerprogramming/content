Set up Hermes Agent, your always-on agent

Video: https://youtube.com/watch?v=MzwYKfSxToU (33 min)

In this lesson

You'll install Hermes Agent, connect a model, teach it about you, give it a skill and a scheduled job that messages you on Slack, run it free on a local model, and create a second bot.

Good to know

  • Time: 45 to 60 minutes for everything. 10 minutes to say hello.
  • Cost: Hermes is free and open source. You pay for the model: your existing Claude or ChatGPT subscription, or nothing with a local model.
  • Level: Beginner to Intermediate
  • It doesn't replace Claude Code. Claude Code is the specialist you open inside a project. Hermes runs everything around it, even after you close the laptop.

What you need

  • A computer to run it on (more below)
  • One model, pick one:
  • Your Claude subscription, ChatGPT/Codex subscription, or Nous Portal

  • Ollama for free local models: https://ollama.com

  • Slack, optional, for messages on your phone: https://slack.com

1. Pick where it lives (1:35)

Four options:

  • A dedicated machine like a Mac mini or Mac Studio (can also run local models)
  • A VPS. Hostinger has a Hermes setup ready to go.
  • A spare laptop or old computer
  • The computer you already use (it can still run 24/7)

2. Install it (2:30)

Website: https://hermes-agent.nousresearch.com

  • Terminal version (Mac, Linux, Windows WSL):
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
  • Desktop app (what I use for the rest of the video): on the same site, click "Download for macOS".

3. Connect a model and say hello (4:00)

Settings (top right) > Providers. Pick Anthropic (Claude), ChatGPT/Codex, or Nous Portal. For Claude: copy the command it shows, paste it into a terminal, approve in the browser, then click "I've signed in". It says Connected. Start a new session and type hello. You can switch models under the chat box.

4. Tell it about yourself (5:05)

Paste this into Claude (or whatever AI you already use) so it writes your intro for you:

Write a short paragraph about me that I can hand to a new AI assistant. Plain text.

Then paste the answer into Hermes with: "Here's a bit about myself, save this." You'll see "saved to memory".

5. See where memory lives (6:40)

Memory is plain files you can open and edit. They're capped on purpose so they stay short and useful.

6. Connect Slack so it can message your phone (10:20)

Capabilities > Messaging > Slack, and follow the setup steps there.

7. Turn a task into a skill (11:40)

Do a task with it once. Then ask it to save that as a skill. Next time you ask for the same thing, it uses the skill. A skill is just a markdown file.

8. Schedule a job (14:40)

Scheduled jobs (top left) > New cron.

  • Name it, write what it should do (mine checks my GitHub for failed runs and open PRs)
  • Pick when (daily, or something like "weekdays at 9am")
  • Deliver to Slack
  • Click "Trigger now" to test it

9. Run it free on your computer with Ollama (25:25)

Install Ollama, then in a terminal:

ollama launch hermes

It offers to download the model if you don't have it. To use the local model in the desktop app: Settings > Providers > Custom endpoints > add one:

  • Name: Ollama
  • Provider ID: ollama-launch
  • URL: http://127.0.0.1:11434/v1
  • API key: any word (I typed test). It's ignored.

It should say the endpoint is reachable and list your models.

10. Make a second bot (22:40)

Profiles let you create separate bots, each with its own memory, skills and jobs. Mine are a code reviewer and a researcher.

11. Have bots hand work to each other (28:20)

Open a bot's "Bot Chat" session and tell it to message another bot, like "tell @coder to review the latest commit". The other bot does the work and reports back.

If it breaks

  • A bot won't hand off to another bot: you have to be in the session called "Bot Chat". Other sessions, including Slack, can't do hand-offs.
  • Typing @botname in Slack does nothing: each bot needs its own Slack app for that. Slack is where bots message you; the desktop app is where you talk to them.
  • The local model errors out right after you pick it: it's usually the context length. Try the same model with a larger context option, or a smaller model.
  • Claude keeps asking you to log in again: re-run the provider sign-in command from Settings > Providers.
