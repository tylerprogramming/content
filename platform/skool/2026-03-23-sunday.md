# Topic: Stop retyping

---

if you're typing the same thing into Claude at the start of every session, stop

go to your home directory, create a file called CLAUDE.md, write one rule in it. anything. "always be concise" or "ask before running any command" or "never use em dashes"

now open a new Claude Code session. it already knows that rule. every session. forever.

i catch myself adding a rule any time Claude does something i didn't want. any time i type the same instruction twice. it compounds fast. after a few weeks Claude just works the way i work without me having to say anything.

one file. takes 5 minutes to start. probably the most underused feature for people just getting into Claude Code

what's one instruction you keep typing that you could just put in the file?
