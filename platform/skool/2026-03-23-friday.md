i type 12 characters and get a full YouTube competitor research report

/yt-search claude code

that's a Claude Code skill. a markdown file that teaches Claude how to run a workflow your way, called with a slash command. wrote it once, use it constantly.

it searches YouTube, pulls top videos by view count, analyzes title patterns, finds content gaps, saves a full report. under 30 seconds.

i have about 20 of these now. one for each workflow i used to do manually - thumbnails, transcription, video planning, SEO, social posts, scheduling, fitness tracking.

the thing that clicked for me is that skills aren't just prompts. they're full workflows with steps, tool use, file output, rules. Claude doesn't answer, it executes.

if you've done the same thing in Claude more than 3 times it's probably worth turning into a skill

what would you automate first?
