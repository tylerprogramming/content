one file changed how i use Claude more than anything else

it's called CLAUDE.md. you put it in your project folder or home directory, and Claude reads it automatically at the start of every session. no prompting, no copy-pasting, no repeating yourself.

you can put anything in there - how you want Claude to respond, what you're working on, what tools it can use, what it should never do. i have stuff like "never use em dashes" and "write scripts for spoken delivery not essays" and permissions for common safe actions.

every rule you add is something you never have to type again. started with 3 rules. mine is a full page now. Claude just works the way i work from the first message.

start with one rule today. something Claude keeps doing that you have to correct. write it in the file. see what happens

what would your first rule be?
