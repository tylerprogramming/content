# Short #3 — How I Create Thumbnails with AI

**Format:** Screen recording
**Target length:** 45-60 seconds
**Post day:** Friday April 4

---

### Hook (first 3 seconds)
"I generate YouTube thumbnails without ever opening Photoshop."

### Script
Watch this. I open Claude Code and tell it I need a thumbnail for my new video.

It asks me a few questions. What model, what style, how many variants.

I give it a prompt describing what I want. It sends it to Kie.ai, generates 3 different options, and saves them all locally.

The whole thing takes about 30 seconds per variant. Each one costs 9 cents.

If I like one but want to tweak it, I can remix it. Feed the generated image back in with a new prompt. Same style but adjusted.

No Canva. No Photoshop. No templates. Just a text description and AI does the rest.

This is one of 22 skills I've built in Claude Code. Each one automates a task I used to do manually.
