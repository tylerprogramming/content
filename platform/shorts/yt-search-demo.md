# Short #2 — How I Search YouTube for Free with a Skill

**Format:** Screen recording
**Target length:** 45-60 seconds
**Post day:** Wednesday April 2

---

### Hook (first 3 seconds)
"I type 12 characters and get a full YouTube competitor research report."

### Script
Watch this. I open Claude Code and type /yt-search claude code.

That's it. 12 characters.

It searches YouTube, finds every video on this topic from the last 30 days, sorts them by views, and gives me a full report.

Top performing titles. View counts. Which channels keep showing up. What video lengths work best. Content gaps I can fill.

This is a Claude Code skill. A reusable workflow I built once that runs every time I type the command.

No API costs. No third party tools. Just yt-dlp and a markdown file.

I run this twice a week before planning any video. It takes 30 seconds and tells me exactly what's already working.
