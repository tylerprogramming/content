# The Publishing Stack (Video 3)

How I take ONE finished video and push it to every platform without opening a single app. This is the distribution half. (Making the video is the YouTube Workflow doc.)

Free pack + newsletter: https://free.tylerai.dev/youtube/

> On-screen note: show this doc as you run each step, so viewers see the command, the output, and where it gets scheduled.

## Skills used in this video
| Skill | What it does |
|---|---|
| `/yt-upload` | Uploads + schedules the video to YouTube via the API (needs token.json setup) |
| `/repurpose` | Turns the video transcript into short-form scripts (Shorts, TikTok, Reels) |
| `/social-copy` | Writes the LinkedIn, X, Instagram, and YouTube Community posts |
| `/pinterest-writer` | Generates keyword-first Pinterest pins |
| `/instagram-writer` | Builds Instagram carousels |
| `/email` | Sends the newsletter / drip via Resend |
| `/skool` | Posts to the free Skool community |
| Blotato (tool, not a skill) | Schedules TikTok / Instagram / LinkedIn / X at the right times |

## The flow (what you'll see on screen, in order)
1. `/yt-upload` - schedule the finished video to YouTube (thumbnail, description, publish time).
2. `/repurpose <transcript>` - cut the short-form scripts from the video.
3. `/social-copy` - write the LinkedIn, X, Instagram, and Community posts, each in your voice.
4. `/pinterest-writer` - generate the pins.
5. `/instagram-writer` - build the carousel.
6. `/email` - queue the newsletter that points people back to the video + free community.
7. Blotato - schedule the social posts across the week.
8. The payoff: one finished video is now queued everywhere. Show the schedule filling up.

## One-time setup you need
`/yt-upload` needs a `token.json` (10-minute one-time Google setup). Full walkthrough: **`yt-upload-setup.md`** in this same folder. This is the step most people get stuck on, so it's worth showing on screen.

## The honest part (say this on camera)
Nothing auto-posts blind. Everything is scheduled, and you review it before it goes out. The system removes the boring repetitive posting work, it does not remove your judgment.

## Start here
Don't build the whole stack day one. Start with `/yt-upload` - just automating the YouTube upload + schedule is the biggest single time-saver. Add one platform at a time.
