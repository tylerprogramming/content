# Competitive Analysis: Claude Code Getting Started

## Market Overview
There's a flood of Claude Code content, but most either assumes terminal knowledge or buries setup inside a longer tutorial. The pure "zero to installed and building" video in under 12 minutes is an open slot.

## Key Competitors

| Competitor | Format | Length | Strengths | Weaknesses | Threat |
|-----------|--------|--------|-----------|------------|--------|
| **David's video** (3 things beginners wish they knew) | YouTube tutorial | ~15 min | Covers install on Mac + Windows, VS Code integration, builds a real app (chore tracker) | Mixes setup with intermediate concepts (CLAUDE.md, architecture changes, YOLO mode), not purely beginner | Medium |
| **CodeWithMukesh** | Blog post | 15 min read | SEO-optimized, covers install + CLAUDE.md + plan mode, comparison with Copilot/Cursor | Text-only — no visual walkthrough, harder for true beginners | Low |
| **Anthropic Skilljar course** | Official course | Multi-module | Official source, thorough, structured learning path | Feels corporate, requires sign-up, not YouTube-native | Low |
| **Udemy courses** | Paid courses | 1-4 hours | Deep, comprehensive, structured | Paid ($15-30), way too long for "just get me started," assumes dev background | Low |

## Content Gaps
- No one does a **pure 10-minute "never touched a terminal" to "built my first app"** video
- Most skip the "don't be afraid of the terminal" pep talk that true beginners need
- Windows vs Mac differences are often glossed over
- No one connects setup directly to a workflow video as a clear part 1 → part 2 pipeline

## Tyler's Angle
- **Free, fast, zero assumptions** — 10 minutes, no coding knowledge required
- **Addresses the fear** — terminal doesn't have to be scary
- **Immediate payoff** — build something visual (countdown timer) in the video
- **Funnel to part 2** — links directly to the Claude Code for Beginners workflow video
- **Both platforms** — covers Mac and Windows installation clearly

## Target Audience
- **Primary**: Non-technical people curious about AI coding tools (heard about Claude Code on Twitter/YouTube)
- **Secondary**: Developers who use browser-based AI tools (ChatGPT, Claude chat) but haven't tried terminal-based agents
- **Not for**: Experienced devs who already use CLI tools daily — they can skip to the workflow video
