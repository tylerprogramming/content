# Thumbnail Analysis — Build a Claude Code Skill from Scratch

## Reference Thumbnail: Ben AI "How to build Claude Skills Better than 99%"

### Layout
- **Left half:** Massive bold white text "AUTOMATE ANYTHING" — dominates frame
- **Bottom-left:** Salmon/orange folder icon (Anthropic-branded) with "SKILLS" text label, white arrow pointing down to it from the text
- **Right third:** Host — face/upper body, confident slight smile, black t-shirt, sandy hair
- Very clean, minimal — only 3 elements: text, arrow+folder, face

### Color Scheme
- Background: Near-black charcoal with very subtle texture (#1a1a1a-ish)
- Text: Pure white — maximum contrast
- Accent: Salmon/orange (#c47c5a-ish) for the Anthropic folder icon — brand signal
- Overall: Dark, cool, minimal

### Typography
- "AUTOMATE ANYTHING" — massive, all-caps, heavy sans-serif (likely Impact or similar), pure white
- "SKILLS" — medium bold text inside the folder icon
- Nothing else — extremely restrained

### Visual Elements
- One arrow: curved white arrow from text pointing down to the skills folder
- One icon: the Anthropic-branded file folder in salmon/orange
- No other decoration — zero noise

### Face/Person
- Right third of frame, shoulder-height crop
- Smiling confidently, looking slightly left (toward the content)
- Takes up maybe 30% of the frame width
- Minimal, not the star of the thumbnail

### What Makes It Clickable
- **"ANYTHING"** — infinite scope, impossible not to click if you want automation
- **Arrow directing attention** — guides eyes from the claim to the proof (the skills folder)
- **Ultra-clean** — stands out in a sea of busy, cluttered thumbnails
- **Dark background** — great contrast, reads well at small size
- **The folder visual** — instantly signals "this is something you can have"
