# Claude Code Tutorial #10 - Hook Options

## Hook Option 1 (RECOMMENDED)

> What if Claude could do your entire job — not just answer questions, but actually execute complex workflows perfectly every single time?
>
> That's what Skills do. And in this video, I'm going to show you how to build one from scratch. Then I'll show you some of my personal custom skills — like one that generates YouTube thumbnails and another that transcribes entire videos with a single command.
>
> By the end of this video, you'll have your own custom skill running. Let's get into it.

**Tone:** Confident, slightly mind-blown. Deliver the first line like a genuine question, not hype.

---

## Hook Option 2

> I have twelve custom skills in Claude Code. One generates thumbnails. One transcribes YouTube videos. One even tracks my workouts in a GitHub-style grid.
>
> Skills are probably the most underrated feature in Claude Code. They turn Claude from a smart assistant into a team of specialists — each one trained to do exactly what you need.
>
> In the next fifteen minutes, you're going to build your first skill from scratch. And trust me — once you see what's possible, you're going to want to build a dozen more.

**Tone:** Casual flex, then genuine excitement. The list at the start creates curiosity.
