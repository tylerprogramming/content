# Claude Code Tutorial #11 - Hook Options

## Hook Option 1 (RECOMMENDED)

> What if you could say "create a GitHub issue for this bug" — and Claude just... does it? No browser. No clicking. No copy-pasting. Just done.
>
> That's MCP. Model Context Protocol. It's how you connect Claude Code to your actual tools — GitHub, Notion, Slack, databases, whatever you use.
>
> In the next thirteen minutes, I'm going to set up a GitHub MCP server from scratch and show you Claude interacting with real repos, real issues, real pull requests. Let's go.

**Tone:** Start with the "what if" question — deliver it like you're letting someone in on a secret. Speed up energy for "Let's go."

---

## Hook Option 2

> Claude Code is powerful. But right now, it's stuck inside your terminal. It can't see your GitHub repos. It can't read your Notion docs. It can't check your Slack messages.
>
> MCP servers fix that. They're bridges that connect Claude to the tools you already use. And setting one up takes about sixty seconds.
>
> Let me show you.

**Tone:** The first paragraph is slightly disappointed — like pointing out a limitation. Then the energy shifts when you introduce the solution. "Let me show you" is delivered casually, like it's no big deal.
