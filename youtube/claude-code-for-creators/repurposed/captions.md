## Caption 2: The CLAUDE.md Secret

The reason most people's AI workflow breaks down: the AI forgets everything between sessions.

The fix is a file called CLAUDE.md. You create it once. You fill it with your rules - posting schedule, hashtag rules, brand voice, platform preferences, where to save files. Claude Code reads it every single time you open a new session.

No re-explaining. No inconsistent formatting. No starting from scratch.
