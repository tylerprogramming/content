## What's Working

### 1. "Master X% in Y Minutes" Format
Skill Leap AI's "Master 80% of Claude Code in 26 Minutes" hit 95K views. The Pareto framing (80/20) instantly communicates value density. Viewers know they'll get maximum ROI on their time.

### 2. Real Workflow Demos Beat Theory
Matt Pocock (249K) showed his actual daily skills with real screenshots. Dan Martell (498K) showed his team using Claude across real businesses. The videos that perform best show REAL use, not toy demos.

### 3. Non-Developer Positioning is Underserved
Almost every top video targets developers. Teacher's Tech (97K) was the only one explicitly for non-coders, and it still performed well. Dan Martell (498K) targeted business owners and crushed it. The creator/business-owner audience is wide open.

### 4. Numbered Concepts Drive Clicks
"5 Claude Code Skills" (249K), "8 Things You Must Do" (125K), "Every Workflow Explained" (67K). Numbered lists set clear expectations and create a mental progress bar for viewers.

### 5. Time-Promise Titles Win
"Build Apps 10x Faster" (227K), "Master 80% in 26 Minutes" (95K). Specific time savings or time investments in the title create urgency.

## What's Missing (Our Opportunity)

### 1. Creator/Business Owner Focus
Zero videos teach Claude Code specifically for content creators. Every tutorial builds a to-do app or landing page. Nobody shows: thumbnail generation, content scheduling, carousel creation, Skool automation, or video planning.

### 2. Skill-Based Workflow (Not Just Commands)
Matt Pocock showed developer skills (TDD, PRDs). Nobody has shown non-technical skills: content planning, social media automation, image generation, research workflows. Tyler has 25 of these.

### 3. The "Full System" Video
Everyone teaches individual features. Nobody shows the complete system: how CLAUDE.md, skills, MCP servers, hooks, and memory all connect into a content machine that produces 32 pieces per week.

### 4. 30-Minute Sweet Spot
There's a gap between 15-minute overviews and 3-hour courses. The 25-30 minute format (Skill Leap at 27min, Teacher's Tech at 26min) performs well and doesn't scare viewers away.

## Key Insights from Reference Transcripts

### Matt Pocock (249K) - What to Learn
- Skills don't have to be long to be impactful. His "grill me" skill is 3 sentences.
- Process matters more than the tool itself. He says: "Process has never been more important."
- Each skill builds on the last (grill me -> PRD -> issues -> TDD -> refactor). This cascading structure keeps viewers watching.

### Dan Martell (498K) - What to Learn
- He targets CEO/business-owner audience and makes Claude Code feel accessible: "You don't need to know code. Just describe what you want in plain English."
- He shows escalating use cases: Chat -> Chrome -> Cowork -> Code. Each one builds excitement.
- His CTA is a challenge, not a pitch: "Use Claude as your main AI for one week."

## Our Positioning

**"The Claude Code course for people who create content, not code."**

Differentiation:
- Real workflow (thumbnails, carousels, Skool, scheduling) vs. toy demos
- 25 custom skills shown in action vs. theoretical explanations
- 32 pieces of content per week as the concrete outcome
- 30-minute format, 10 concepts, each one actionable
- Business owner/creator audience, not developers

## Risk Factors

- freeCodeCamp's 12-hour course (256K) could make "course" feel overdone in search. Counter: our angle is completely different (creators, not coders).
- Source code leak videos (4 in top 20) show the audience craves "insider knowledge." We deliver that with real production workflows nobody else shows.
