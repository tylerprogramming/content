## Product truth (verified against ElevenLabs docs - cite if asked)

**What ElevenAgents is** (docs: https://elevenlabs.io/docs/eleven-agents/overview): ElevenLabs' platform for building voice and chat agents that complete tasks through natural dialogue. Formerly called Conversational AI.

**How you build an agent (4 pillars, shown on camera):**
- **System prompt** - the personality + policy (role, goals, guardrails). Max 2MB incl. knowledge base.
- **Voice** - 5,000+ voices across 31 languages (used for voice-note / call replies).
- **LLM** - pick a supported model, ElevenLabs-hosted or your own.
- **Knowledge base** - upload documents, enable RAG for grounded answers.
- **Tools** - let the agent call APIs to take actions (booking, lookups). Optional; mention as the next step.

**WhatsApp integration** (docs: https://elevenlabs.io/docs/eleven-agents/whatsapp ; announcement: https://elevenlabs.io/blog/elevenlabs-agents-whatsapp-support):
Connect a WhatsApp Business account to one ElevenAgent. Same agent, same knowledge, across web / phone / WhatsApp.

Setup steps (VERIFY LIVE - UI may shift):
1. Prereqs: a WhatsApp Business account + access to WhatsApp Manager (business.facebook.com) + a payment method (needed for outbound calls).
2. ElevenLabs dashboard -> WhatsApp page -> **Import account** -> complete the Meta authorization flow (select account, grant permissions).
3. On the account settings page, **assign your agent**. Without an assigned agent, inbound messages are ignored and calls rejected.
4. Profile: WhatsApp Manager -> Phone numbers -> select number -> **Profile** tab (set business profile picture).
5. Voice calls: WhatsApp Manager -> Phone numbers -> **Call settings** tab to enable calling.
6. Outbound calls need a payment method: WhatsApp Manager -> Overview -> Add payment method.

Supported interactions (verified):
- Inbound: text messages, audio / voice notes (auto-transcribed), images, documents, locations, contacts, inbound voice calls.
- Outbound: text via templates, voice calls (require user permission).
- Config: set a Max conversation duration timeout message; choose whether audio messages get audio or text replies.

Honest limits (say these on camera - this is the trust beat):
- Needs a real WhatsApp Business account + Meta authorization. Not one-click; there is a setup + approval flow.
- Costs money: ElevenLabs usage/credits, plus Meta charges for outbound messages sent outside the 24-hour customer-service window.
- Outbound calls require user permission and a payment method on file.
- Zero-Retention Mode limits functionality (it ignores messages and disallows outbound calls).
- The agent is only as good as its system prompt + knowledge base. Garbage in, garbage out.
