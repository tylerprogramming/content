# Creator Hooks Reference Library
**Source:** Creator Hooks newsletter (jake@creatorhooks.com)
**Purpose:** Store proven thumbnail examples, title frameworks, and hook data for reference when planning new videos.

---

## Structure

```
creator-hooks/
├── README.md          — this file (index + how to use)
├── frameworks.md      — all title/hook frameworks extracted from emails
├── thumbnails/        — saved thumbnail images from newsletter examples
└── emails/            — raw extracted text from Creator Hooks emails
```

---

## How To Use

When planning a new video:
1. Read `frameworks.md` for proven title structures + hook scores
2. Browse `thumbnails/` for layout/text/color inspiration
3. Match your topic to the highest-scoring framework
4. Apply the thumbnail pattern from the closest-performing reference
