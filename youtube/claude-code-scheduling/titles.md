## Options

### 1. ⭐ RECOMMENDED
**I Let Claude Code Run My Research While I Slept (Here's What It Did)**
- Works because: Personal story open, curiosity gap ("what did it actually do?"), broad appeal — anyone can imagine waking up to done work. Under 70 chars.

### 2.
**Claude Code Can Work While You Sleep (Most People Don't Know This)**
- Works because: "Most people don't know" triggers FOMO + insider framing. Clear promise. Broad audience immediately gets the concept.

### 3.
**I Built a Morning Briefing That Runs While I Sleep (Claude Code)**
- Works because: Specific, aspirational, the word "built" appeals to makers. Bracketed keyword for search.

### 4.
**The Claude Code Feature Nobody Is Talking About**
- Works because: Curiosity gap, contrarian. Slightly shorter, works as a punchy title. Risk: vague without thumbnail context.

### 5.
**Claude Code Works 24/7 Now — Here's How to Set It Up**
- Works because: Clear benefit, "24/7" is a power phrase, direct promise. More SEO-friendly. Less emotional but very clickable with a strong thumbnail.

## Creator Hooks Frameworks (from newsletter analysis)

### 6. — "ADDICTED" framework (+1930 hook score)
**3 Claude Code Workflows That Will Make You ADDICTED to Scheduling**
- Works because: "ADDICTED" is an extreme word that adds emotion and desire. Lists feel tangible. Broad audience gets the promise immediately. Highest-scoring Creator Hooks format.

### 7. — "What Actually Triggers" framework (+466 hook score)
**What Actually Triggers Claude Code to Work While You Sleep**
- Works because: "What Actually" opens a curiosity loop and signals insider knowledge. Feels like you're about to learn something most people don't know. Broad appeal — doesn't assume technical knowledge.

### 8. — "5 Things Get WRONG" framework (+670 hook score)
**5 Things People Get WRONG About Claude Code Automation**
- Works because: "WRONG" creates mild tension — everyone wants to know if they're making a mistake. Speaks to both beginners and existing users. Specific number makes it feel tangible.

### 9. — "Never Made Sense — Until Now" framework
**Claude Code Automation Never Made Sense — Until Now**
- Works because: Pattern interrupt for anyone who tried automation before and gave up. "Until Now" implies a breakthrough. Creates strong curiosity gap. Contrarian angle stands out in feed.

### 10. — "Why 90% Are Garbage" framework (+756 hook score)
**Why 90% of Claude Code Users Are Leaving This Feature Unused**
- Works because: Negativity + counterintuitive. Makes the viewer feel like they're in the 10% who'll know better after watching. Strong FOMO. "Leaving this feature unused" is specific enough to be believable.

### 11. — "I Tried X, These Y Will" framework (+992 hook score)
**I Tested 10 Claude Code Automations — These 3 Actually Work**
- Works because: Experience = credibility. The implicit promise of filtering bad ones for you. "Actually work" signals real-world validation vs. hype. Strong curiosity about which 3 made the cut.

### 12. — Story + outcome (hybrid)
**I Stopped Doing Research Manually. Claude Code Does It For Me Now.**
- Works because: Relatable pain (manual research is tedious), personal transformation, broad appeal. The period at the end adds confidence. Works especially well paired with a strong thumbnail.
