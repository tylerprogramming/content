# Description

---

Hermes Agent is the free, open-source AI agent from Nous Research that runs on your own machine, remembers every session, writes its own skills as it works, and keeps running on a schedule after you close the laptop. If you already use Claude Code, this is the always-on other half. In this video I get you fully set up and walk through the three features that actually matter: persistent memory, self-written skills, and scheduled jobs, plus how to run it 100% local and free with Ollama.

Free setup notes and every command from this video are in the community below.
