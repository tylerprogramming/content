# Hooks: 3 Skills + Live Build

**Revision goal:** Open with proof (3 outputs landing), promise both showcase and build, set the stakes.

---

## Hook A (RECOMMENDED) — Triple Receipt

[SHOW: Split screen montage — left third: terminal running `/yt-search` and a folder filling up with thumbnails. Middle third: `/transcribe` showing a transcript file landing in `~/content/scripts/`. Right third: `/yt` running and a video package folder cascading with files (analysis.md, titles.md, script.md, etc.). All three appearing in parallel over 6 seconds.]

> *(VO at 0:03)*
> Research, transcripts, video packages. Three Claude Code skills, three outputs, total time about 8 minutes.

> *(at 0:10)*
> I'm going to show you all three working, then I'm going to build a brand new one from scratch live on camera. By the end you'll know what a skill can do and how to build your own.

**Why it works:**
- **Three receipts in 6 seconds** — proof before the claim, AntiGravity-pattern
- **Specific numbers**: 3 skills, 8 minutes
- **Dual promise**: showcase + live build = two reasons to keep watching
- **Concrete deliverable**: "build a brand new one from scratch live"

---

## Hook B — The Pattern Reveal

[SHOW: Empty VS Code with one file open: an example SKILL.md, ~50 lines. Quick zoom on the frontmatter and the body.]

> Every Claude Code skill in my entire system looks like this. About 50 lines. Plain English. No SDK, no framework, nothing to install. I'll show you three of mine running, then we'll build one together. Stay with me.

**Why:** Inverts the structure — open with the SIMPLICITY, then show the power. Different beat than Hook A. Could work better for technical-leaning audiences.

---

## Hook C — The Time Math

[SHOW: Split screen — left: old workflow (clicking around YouTube, copying titles, writing scripts manually). Right: terminal cycling through 3 slash commands and outputs landing. Time stamp comparisons appear on screen.]

> 2 hours of YouTube research becomes 60 seconds. 30 minutes of watching becomes 5 minutes of reading. A weekend of scriptwriting becomes 5 minutes. Three Claude Code skills. I'll show you each one work, then build a fourth live.

**Why:** Time-savings hook, three verifiable deltas, then the live build promise.

---

## Hook D — The Companion Pitch

> Most people use Claude Code like a chatbot. The unlock isn't a better prompt. It's skills. I have 43 of them. I'll show you 3 in action and build a brand new one in front of you in the next 30 minutes.

**Why:** Demolish the misconception fast, drop the credential, set the agenda. Slightly heavier on talking head than visual receipt.

---

## Recommendation

**Use Hook A.** It's the most aligned with the proven pattern — receipts first, claim second, dual promise to retain. Tests Hook C if you want to lead with the time-saving angle for a non-developer audience.

**Avoid Hook D as cold-open** — too much talking head before proof. Better as the framing at 0:30 after the visual receipt lands.
