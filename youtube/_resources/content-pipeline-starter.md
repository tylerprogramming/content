## Skills used in this video
These are custom Claude Code skills. A skill is just a workflow you taught Claude Code once, triggered with one command. Build it once, run it forever.

| Skill | What it does |
|---|---|
| `/yt-search` | Researches what's actually working on YouTube for a topic right now, ranks by views |
| `/yt-deep-research` | Searches YouTube, transcribes the top videos, returns a deep analysis of hooks and structure |
| `/transcribe` | Pulls the transcript from reference videos so you learn from what's proven |
| `/yt-package` | Writes the full video package: titles, hooks, script, description, filming guide |
| `/yt-seo` | Optimizes the title, description, and tags against what's ranking |
| `/yt-shorts` | Turns the research into 5 short-form scripts + 2 Instagram carousel outlines |
| `/social-copy` | Writes the LinkedIn post, X posts, Instagram caption, and YouTube Community post |
| `/yt-thumbnail` | Generates thumbnails with the Claude image models (Nano Banana) |
| `/yt-chapters` | Builds accurate chapters from the final edited video |

## The mental model
One research kickoff flows through the chain above and comes out as ~32 pieces of content for the week. You are not writing 32 things from scratch. You make one strong thing and let the pipeline reshape it for every platform, in your voice, using rules you set once.

## Build your first skill (the template)
Start with ONE annoying, repetitive thing you do every week. A skill is a folder with a `SKILL.md` file that describes the steps in plain English. Copy this and fill it in:

```markdown
---
name: my-first-skill
description: What this does and when to trigger it
---

# What this skill does
[One sentence.]

# Steps
1. [First thing to do]
2. [Second thing]
3. [Where to save the output]

# Rules
- [Anything it should always/never do]
```

That's it. If you can describe your process in plain English, you can build a skill. Then build the next one.

## Start here
Pick the most repetitive part of your week and teach Claude Code to do it once. The whole system above got built one skill at a time.
