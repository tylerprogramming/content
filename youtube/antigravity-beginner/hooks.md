# Hook Options (First 30 Seconds)

## Hook 1: The Reveal (Pattern Interrupt)

> This is an empty folder. No files, no code, nothing. And in the next 12 minutes, I'm going to turn it into a fully working app — with charts, a database, and a polished UI — without writing a single line of code. This is Google AntiGravity. It's free. And almost nobody knows how to use it properly.

**Technique:** Pattern interrupt. Opens with a visual (empty folder) and immediately sets up the transformation. "Without writing a single line of code" is the hook within the hook. Ending with "nobody knows how to use it properly" creates a curiosity gap.

[SHOW: Screen recording of an empty folder in AntiGravity. Quick flash-forward cut to the finished expense tracker dashboard.]

---

## Hook 2: The Speed Run (Bold Claim)

> Google just dropped the most powerful free coding tool ever made — and I'm going to prove it. I'm starting a timer right now. By the time it stops, we'll have a fully working expense tracker with charts, categories, and a clean UI. Ready? Let's go.

**Technique:** Bold claim + urgency. The timer creates tension. Viewer stays to see if you deliver. Works especially well if the actual build is fast.

[SHOW: Start a visible timer on screen. Split with AntiGravity open to an empty project.]

---

## Hook 3: The Comparison (Curiosity Gap)

> Last year, I'd spend a full day building something like this. A dashboard with charts, input forms, data tracking. Today, with AntiGravity, I built the same thing in under 5 minutes. Let me show you exactly how — step by step — so you can do it too.

**Technique:** Before/after comparison. Grounds the claim in personal experience. "Step by step" signals beginner-friendly and earns trust. "So you can do it too" is inclusive.

[SHOW: Brief flash of the finished dashboard, then cut to the empty AntiGravity project.]
