## Instagram Carousel #2: "How to Build a Claude Code Skill (in 5 Steps)"

**Concept:** Step-by-step walkthrough of creating a skill from scratch - visual process guide
**Why this format:** A process with discrete steps is perfect for slides. Each step gets its own visual focus without rushing.

---

**Slide 1 (Intro - dark background)**
Headline: Build a Claude Code skill in 5 steps
Subtext: No code required

**Slide 2**
Headline: Step 1 - Pick your workflow
Body: What do you do manually more than 3 times? Research, writing, data cleanup, scheduling - anything repeatable works.

**Slide 3**
Headline: Step 2 - Write it down step by step
Body: Open a new markdown file. Write what Claude should do, in order, in plain English. This becomes your skill.

**Slide 4**
Headline: Step 3 - Add the front matter
Body: Three lines at the top: name (the skill name), description (what triggers it), allowed-tools (what Claude can use).

**Slide 5**
Headline: Step 4 - Save it to the right place
Body: Drop the file in ~/.claude/skills/your-skill-name/SKILL.md. Claude Code picks it up automatically on next launch.

**Slide 6 (Closing)**
Headline: Step 5 - Type /your-skill-name and watch it run
Body: Save this and build your first one today

---

**Caption:**
you can build a claude code skill in under an hour - here's the exact 5-step process
no code required. just your workflow written down in a markdown file
the rule: if you've done the same thing 3 times in claude, it's worth building a skill for
