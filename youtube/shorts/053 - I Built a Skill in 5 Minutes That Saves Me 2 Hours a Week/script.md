### Script
I spent 5 minutes building this. Now it saves me 2 hours every week.

This is a Claude Code skill. It's a markdown file that teaches Claude how to run a workflow - your way, every time.

Watch this. I type /yt-search claude code - and it searches YouTube, pulls the top videos by view count, analyzes title patterns, finds content gaps, and saves a full research report. Under 30 seconds.

That used to take me two hours manually.

The skill is just instructions. No code. I wrote what I wanted Claude to do, step by step, in plain English. Now I trigger it with a slash command.

I have 20 of these now. One for each workflow I kept doing manually.

The rule I use: if I've done the same thing in Claude more than three times, I turn it into a skill.

What workflow would you automate first?
