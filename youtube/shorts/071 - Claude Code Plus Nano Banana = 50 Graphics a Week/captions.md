## LinkedIn
Claude Code plus Nano Banana equals 50 social media graphics a week with zero design cost.

Here is the stack. Claude Code handles the copy. The /instagram-writer skill generates a full 6-slide carousel in seconds with platform-tuned captions. Nano Banana generates the backgrounds — terracotta, cream, dark mode, or whatever matches the brand palette for the week. Claude Code then composites the final PNGs and exports a PDF for LinkedIn plus individual images for Instagram and Pinterest.

I run this 3 to 4 times a week. 50 plus graphics go out across Instagram, LinkedIn, and Pinterest with no Canva subscription, no Photoshop file, and no designer on retainer.

The cost I replaced — roughly $300 a month in design tool subscriptions plus whatever I was paying a freelancer for carousel design. The cost now — $0 in tools, about a dollar in API credits per week.

If your business runs on content and you are still bottlenecked by design labor, this stack removes the constraint.
