I just planned an entire YouTube video in 5 minutes. Here's exactly what happened.

I type /yt into Claude Code with a reference transcript and my topic idea.

Watch what it does. It researches the topic online, analyzes what's already performing on YouTube, asks me about my angle, then generates the full package.

Titles. Hooks. Full script. Description. Filming guide. All of it.

This used to be my entire Monday. Research, outlining, scripting - four to six hours minimum.

Now I type /yt, answer a few questions, and I've got a complete video package ready to film.

The script even has cue card sections built in for my teleprompter. And a filming guide that tells me exactly what to show on screen for each section.

This is one command. It does all of this because I built it as a skill - a set of instructions that tells Claude exactly how I plan videos, every time.
