## Script

**[HOOK — 0-1.5s]**
> Claude Code now has plugins. Here's what that actually means.

**[BODY — 2-30s]**
> A plugin is a bundle of skills, hooks, slash commands, and MCP servers that someone else built — and you can install with one command.

> Think of it like npm install but for Claude Code. Instead of building every skill yourself, you can pull a whole pack — say, a "content creator" plugin that gives you /transcribe, /shorts, /seo all at once.

> The platform team at Anthropic is building this so the community can ship reusable workflows without everyone reinventing them.

**[CTA — 30-45s]**
> If you're already building skills, plugins are how you'll distribute them. If you're not — they're how you'll go from zero to a working setup in 30 seconds. Subscribe for the deep dive on building one.
