### LinkedIn
A Claude Code skill is a markdown file. Plain text. No code required.

You write your process step by step. Claude follows it every time you call the skill with a slash command. The config is a few lines at the top - skill name, what triggers it, what tools it can use.

Skills aren't for engineers. They're for anyone who does the same thing more than once.
