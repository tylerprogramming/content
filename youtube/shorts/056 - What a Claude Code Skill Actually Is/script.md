### Script
A Claude Code skill is just this. That's it.

[SHOW: open a SKILL.md file in VS Code or terminal]

It's a markdown file. Plain text. No code required.

At the top, a few lines of config - the skill name, what triggers it, what tools it can use. Then below that, step-by-step instructions for exactly what Claude should do when you call it.

[SHOW: scroll through the file slowly]

That's the whole thing. When I type /yt-search in Claude Code, it reads this file and follows the steps. Every single time. Exactly the same way.

The power isn't in the tech. It's in your process. If you can write down how you do something, you can turn it into a skill.

I've built 20 of these. Each one took under an hour. Together they handle most of my content workflow automatically.

Skills aren't for engineers. They're for anyone who does the same thing more than once.
