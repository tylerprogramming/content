## LinkedIn
Claude Code skills are the single most underrated feature in the AI toolchain, and almost nobody is using them yet. Here is how to build your first one in 2 minutes.

Step one. Open the skills folder at ~/.claude/skills. Create a new directory named after what the skill does.

Step two. Create a file called SKILL.md. That is all you need. No Python file. No API keys. No SDK.

Step three. Paste the frontmatter. Name, description, trigger words the user would type to invoke it. Then write the instructions in plain English. What should Claude do when this skill fires.

Step four. Open Claude Code. Type slash your-skill. It runs.

That is the entire setup. A skill is a markdown file.

I have 25 skills running my entire content business. One generates YouTube video packages. One writes Instagram carousels. One builds UGC ads. One transcribes and chapters long-form videos. Every repeatable workflow I used to do manually is now a slash command.

If you are a knowledge worker, founder, or creator, the question is not whether to build skills. The question is which repeatable task you automate first.
