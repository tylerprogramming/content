## LinkedIn
There is a Claude skill whose only job is to build other Claude skills, and almost nobody is using it yet. This one plugin changed how I think about automation in Claude Code.

It is called skill-creator. Anthropic ships it in the official plugin marketplace. One command to install.

Here is the workflow. You ask Claude to build you a skill, in plain English. Build me a meal-log skill that reads a food photo and logs the calories and protein to a CSV. skill-creator asks clarifying questions about triggers, inputs, and outputs. Then it writes the SKILL.md file, any helper scripts, the frontmatter, the instructions. All of it.

Two minutes later you have a working skill. You did not write a line of it.

The second thing it does is just as valuable. It can improve your existing skills. Point it at a skill you already built and it will audit the instructions, tighten the trigger phrases, and suggest rewrites that actually measurably improve performance. It even runs evals to benchmark skill quality.

I built 25 of my skills by hand before this existed. Every one of them took an hour or two. If I had skill-creator from day one, I would have built 50 in the same time and they would have been sharper.

If you are serious about agent workflows, this is the force multiplier most creators are missing. Install the plugin, ask it to build the first skill you have been putting off, and ship it tonight.
