## Instagram Carousel #2: What to Put in Your CLAUDE.md

**Concept:** Step-by-step guide to setting up CLAUDE.md — the most common beginner question after they learn it exists
**Why this format:** It's a setup guide — naturally sequential, great for saving. Each slide = one category of instructions.

---

**Slide 1 (Cover — dark background)**
Headline: What to put in your CLAUDE.md
Subtext: The one file that changes how Claude works forever

**Slide 2**
Headline: What is CLAUDE.md?
Body: A markdown file in your project folder (or home directory). Claude reads it automatically at the start of every session — no prompting required.

**Slide 3**
Headline: #1 — Behavior rules
Body: How you want Claude to respond. Examples: "Always be concise." "Never use em dashes." "Ask before running any terminal command."

**Slide 4**
Headline: #2 — Workflow context
Body: What you're working on. Examples: "I make YouTube content about AI tools." "This is a Next.js app using Supabase." Give Claude the background it needs.

**Slide 5**
Headline: #3 — Permissions
Body: Pre-approve common safe actions so Claude stops interrupting. Examples: "You can read and write files freely." "Always use npm, never yarn."

**Slide 6**
Headline: #4 — Your preferences
Body: Tools, formats, style. Examples: "I prefer TypeScript over JavaScript." "Write scripts for spoken delivery, not essays." "Short sentences."

**Slide 7 (Closing)**
Headline: Start with 3–5 rules
Body: You don't need a perfect CLAUDE.md on day one. Add a rule every time Claude does something you didn't want. It compounds fast.
