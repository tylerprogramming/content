## LinkedIn
One Claude Code command replaced my graphic designer. I was paying $1,500 a month for 4 Instagram carousels.

The command is /instagram-writer. I give it a topic. It returns a full 6-slide carousel — cover, pain point, solution, how-to, results, CTA — with a platform-tuned caption and a comment-bait hook at the bottom. Nano Banana handles the background images for each slide. Claude Code composites the final PNGs and exports the PDF.

Total time from command to exported file is about 2 minutes.

My old designer did 4 carousels a month at $1,500. This does 4 a week at essentially zero cost. Same quality, same design language, and the voice is mine instead of a freelancer's interpretation of mine.

If you are a creator, coach, or founder paying for carousel design on a retainer, the economics flipped. A 50 line skill file replaced what used to be a $20K a year line item in my business. And the turnaround dropped from 5 days to 2 minutes.

The question is not whether to automate this. The question is which other design function you automate next.
