## YouTube Shorts
I built a Claude Code skill that creates a complete ad from one command.

It's a markdown file that chains three AI tools together - Nano Banana for the product image, Kling 3.0 for the video, and ElevenLabs for the voiceover.

One command. 4 minutes. No code required.

You describe the product, and the skill handles the rest - generates the visual, animates it, adds narration, and exports a finished ad.

This is what Claude Code skills were built for.
