### LinkedIn
Your Claude sessions degrade over time. Here's why.

Claude has a context window - a fixed memory limit. Every message, file read, and response fills it up. When it hits the limit, Claude starts dropping what you said earlier. Output gets worse.

The fix: start a fresh session when switching tasks, or every 1-2 hours. One of the most common "Claude is getting dumb" complaints has this as the root cause.
