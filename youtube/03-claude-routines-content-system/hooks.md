## Pattern Interrupts (Visual + Verbal)

Drop these at drop-off points to wake viewers up.

- **Cut to a close-up** right after each section break
- **Zoom in on dollar numbers** when they appear (195 hours, $3,000 VA, $800 social media manager)
- **B-roll interrupt** when switching between Routines and Claude Code (terminal shot, desk shot)
- **Direct-to-camera aside**: "Hey, quick note on this part..." resets attention mid-section
- **Verbal checkpoint**: "Alright, quick recap..." before each new major point
