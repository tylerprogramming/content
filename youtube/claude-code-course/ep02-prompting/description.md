# Episode 2 — YouTube Description

## Title
Claude Code Tutorial #2 - Write Prompts That Actually Work

## Description

Your prompts are the bottleneck. In this episode, I show the exact formula I use to get great results from Claude Code every single time. I build the same project twice — once with a vague prompt, once with a specific one — so you can see the difference for yourself.

No coding required. This is about writing clear instructions in plain English.

**In this video:**
- Side-by-side demo: vague prompt vs specific prompt (same project)
- The 4-part prompt formula: Context + Task + Constraints + Format
- 3 common prompting mistakes beginners make
- How to iterate and refine with follow-up prompts
- When to start a new conversation vs keep going
