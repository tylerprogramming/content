# YouTube Description - Claude Code Tutorial #5 - Permissions & Safety

## Description

Tired of approving every single action in Claude Code? In this episode, I show you how to set up permissions so Claude stops interrupting you for safe actions -- while still protecting you from anything risky. This one simple change makes Claude Code dramatically faster to work with.

This is Episode 5 of my Claude Code course for non-technical founders and complete beginners.

In this video:
- Why Claude Code asks for permission (it changes your actual computer)
- The approval flow: once, session, or deny
- Setting up permissions with /permissions
- The allow list and deny list in settings.json
- What to pre-approve: reading files, running tests, git commands
- What to keep gated: installs, deletes, API calls
- Having Claude set up permissions for you (pro tip)
- Live demo: the speed difference before and after permissions
