# YouTube Description - Claude Code Tutorial #4 - Context Window Mastery

## Description

Ever notice Claude Code's outputs getting worse mid-conversation? That's context rot -- and it's the #1 thing beginners don't understand. In this episode, I break down the context window (Claude's short-term memory), show you how to monitor it in real time, and teach you the two commands that fix everything: /compact and /clear.

This is Episode 4 of my Claude Code course for non-technical founders and complete beginners. No coding experience needed.

In this video:
- What the context window is and why it matters
- How to read the context bar at the bottom of your terminal
- What "context rot" is and how to spot it
- Using /compact to compress your conversation (with custom focus instructions)
- Using /clear for a complete fresh start
- How auto-compaction works (and why you shouldn't rely on it)
- A live demo showing context filling up, outputs degrading, and then fixing it
