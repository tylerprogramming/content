# Episode 3 — Hook Options (First 30 Seconds)

## Hook A (RECOMMENDED) — "Without vs With"

> I'm going to ask Claude Code to add a feature to this project. But first — watch what happens without a CLAUDE.md file.
>
> **[SHOW: Terminal. Claude Code uses the wrong framework, wrong file structure, wrong coding style. Messy output.]**
>
> Wrong framework. Wrong structure. It's guessing. Now I'm going to add one file. Just one. And ask the exact same thing.
>
> **[SHOW: Terminal. Same prompt. Claude nails it — right framework, right conventions, clean output.]**
>
> That file is called CLAUDE.md. And after this video, you'll never start a project without one.

---

## Hook B — "The Instruction Manual"

> Imagine hiring a new developer. Day one, you sit them down. You don't explain how your project works. You don't tell them what tools you use. You don't tell them your coding style. You just say "add a feature" and walk away.
>
> That's what you're doing to Claude Code every time you skip the CLAUDE.md file.
>
> This file is Claude's instruction manual for your project. And in the next 12 minutes, I'll show you exactly how to set one up — even if you have no idea what to put in it.

---

**Notes:**
- Hook A has a visual demo built in — strongest for retention
- Hook B uses an analogy that non-technical viewers will immediately get
- Both under 30 seconds
