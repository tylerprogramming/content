# YouTube Description - Claude Code Tutorial #6 - Models & Memory

## Description

Claude Code has THREE different AI models and a built-in memory system. Most beginners never touch either one. In this episode, I break down Haiku (fast/cheap), Sonnet (balanced), and Opus (powerful) -- when to use each, how to switch mid-conversation, and how the cost differences add up. Then I show you Claude's memory: tell it your preferences once and it remembers them forever.

This is Episode 6 of my Claude Code course for non-technical founders and complete beginners.

In this video:
- The three Claude models: Haiku, Sonnet, and Opus
- When to use each model (match model to task)
- Switching mid-conversation with /model
- Live comparison: same question, different models
- Claude's memory system: remembering your preferences
- Manually telling Claude to remember things
- Reviewing and editing what Claude remembers (CLAUDE.md)
