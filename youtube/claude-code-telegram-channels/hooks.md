# Hook Options: Claude Code Telegram Channels

Each hook is a word-for-word script for the first ~30 seconds.

---

## Hook 1 ⭐ RECOMMENDED — Pattern Interrupt / Contrast
**Technique:** "Normally X... but now Y" + instant demo

> "Normally, to use Claude Code you have to be at your terminal. Sitting at your desk. Logged in. Present.
>
> But this morning — while I was running — I pulled out my phone, sent a message, and got my fitness stats back. My YouTube research done. A social post drafted and ready to publish.
>
> All from Telegram. While I was mid-run.
>
> That's what Claude Code Channels does. And I'm going to show you how to set it up in five minutes."

[SHOW: Phone screen — Telegram chat open, message sent, response coming in with real data]

---

## Hook 2 — Bold Claim
**Technique:** Lead with the most surprising fact

> "Claude Code just got a phone number.
>
> Seriously. You can now text it. Like texting a person. You send a message, it does the work, and it texts you back — with real results.
>
> I asked it to check my nutrition macros mid-run this morning. It ran my fitness skill, pulled the data, and sent it back before I hit the next mile marker.
>
> This is Claude Code Channels. It just dropped. Let me show you how it works."

[SHOW: Split screen — running footage + phone notification coming in with Claude response]

---

## Hook 3 — Story Open
**Technique:** Put the viewer in the moment

> "So I'm at mile four of a half marathon this morning. Phone in hand.
>
> I open Telegram, type 'check my fitness stats', and hit send.
>
> By mile five, I had my nutrition breakdown, my workout log, and a YouTube research report — all done. All from my phone. While running.
>
> No laptop. No terminal. No session to reconnect to.
>
> That's the new Claude Code Channels feature. And it changes how you use AI completely."

[SHOW: Start with a still or short clip of running path/phone, then cut to Telegram demo]
