# LinkedIn Post — Claude Code Channels

---

Your AI just got a phone number.

Claude Code Channels is a new official feature that connects Claude Code to Telegram - giving it an address you can text from anywhere.

I set it up in under 5 minutes this week and it changed how I think about what AI workflows can be.

👉 BotFather + plugin install + token takes about 4 minutes total

👉 Once paired, you can trigger any Claude Code skill from Telegram - yt-search, thumbnail generation, social posting, fitness logging, anything you have set up locally

👉 Claude works in the background on your machine and texts you back when done - fully async

👉 Allowlist mode locks it to your Telegram ID so no one else can access it

👉 This is different from Remote Control - you initiate from your phone, Claude does the work, you get a notification when finished

The shift here is the paradigm. Persistent, async, notification-driven AI. You're not babysitting a terminal session. You send a message and get results later.
