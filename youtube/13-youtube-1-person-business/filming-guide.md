# Filming Guide: How I Run a 1-Person YouTube Business with Claude Code (Full Course)

**Target runtime:** 60-90 min final cut
**Estimated filming:** batch across 2-3 sessions (this is a course, do not try to one-take it)
**Style:** proof-first, show the real terminal, riff don't read.

---

## Why batch this
A 60-90 min course films best in blocks, not one sitting. Suggested batching:
- **Block A - On camera (film first, energy fresh):** Module 0 hook (3-5 takes), Module 1 (why now), the 30-day plan + CTA (Module 12 close), and all the short transition/retention punch-ins.
- **Block B - Screen recordings, research half:** Modules 3, 4, 5 (`/yt-search`, `/transcribe`, `/yt` + `/seo`).
- **Block C - Screen recordings, production half:** Modules 6, 7, 8 (`/thumbnail`, `/ai-video`, `/chapters`, `/shorts`).
- **Block D - Screen recordings, growth half:** Modules 9, 10, 11 (`/youtube`, `/analytics`, `/yt-replier`, funnel + `/email`).
- **Block E - The live build:** Module 12 capstone skill from scratch (one clean take if possible - authenticity sells).

## Pre-recording checklist
- [ ] Each skill pre-tested the morning of, returns a strong + safe result, then filmed fresh
- [ ] A real, safe research topic chosen for Modules 3-5 (nothing client-sensitive)
- [ ] Terminal 14pt+, clean theme, no secrets/API keys visible, notifications off
- [ ] The capstone skill decided in advance (simple + useful = the lead magnet you give away)
- [ ] Funnel page (free.tylerai.dev/youtube/) loads and the opt-in works (you'll show it in Module 11)
- [ ] Backup screen-recordings of each skill's good output in case a live run fails
- [ ] Pipeline diagram graphic ready for Module 1 (research → script → thumbnail → shorts → email)

## Retention rules for a long course
- **Signpost every module:** "chapters are in the description, skip ahead if you know this." (Olgaard's move - it's why a 3.5hr video holds.)
- **Open ON proof** (the machine running), never on setup.
- **Cut dead air aggressively.** Speed-ramp any generation longer than ~10s.
- **Mini-recap at the end of each module** ("so that's research, one command, proven topics") - helps long-form retention.
- **A punch-in every module** to reset attention.
- **Show the actual prompt typed** in each demo so viewers can verify and copy.

## Privacy
- Blur anything sensitive that surfaces in research/analytics/comments demos (real channel data, viewer names in comments, any email addresses in the `/email` demo).

## Must-nail modules (if you run long)
1. Cold open (0:00-3:00) - CTR/retention
2. The live skill build (Module 12) - perceived value + the lead-magnet payoff
3. The research engine (Module 3) - the "oh, that's the unlock" moment
4. Email module (Module 11) - the differentiator from every generic 1-person-business video
5. The 30-day plan + CTA (Module 12 close) - drives funnel signups

## Post-production
- Run `/chapters` on the final cut to true up the timestamps in description.md (placeholders are in there now).
- Run `/seo` to finalize title/description/tags before upload.
- Generate thumbnails via `/thumbnail` (directions in titles.md); test 2 (proof+face vs system-map). Avoid money-stack/revenue-dashboard styles - those signal the faceless cash-cow niche and pull the wrong audience.
- After upload, run `/repurpose` + `/shorts` to cut the week of Shorts from the course footage.
- Upload + schedule via the `/youtube` skill. Save the video_id to `youtube_video_id.txt`.
