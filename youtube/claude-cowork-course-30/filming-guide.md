# Filming Guide: Claude Cowork Course (30 min)

**Date:** 2026-04-14
**Estimated filming time:** 2-3 hours (screen recordings first, talking head second)
**Editing style:** Fast cuts, no dead air, screen recordings fill 60% of runtime

---

## Pre-Production Checklist

### Folders to Prepare

Before filming, create and populate these folders in your Cowork directory:

1. **~/Documents/Cowork/competitor-research/**
   - 15-20 screenshots of competitor YouTube channels (about pages, analytics if visible, top videos)
   - Screenshots of competitor websites and pricing pages
   - Use 5 real AI YouTube channels Tyler actually follows

2. **~/Documents/Cowork/client-files/**
   - 30+ files to simulate a messy client folder
   - Mix of PDFs (contracts, proposals), images (receipts), text files (intake forms)
   - Name them messily: "final_v2_REVISED.pdf", "invoice_maybe.pdf", "Contract (1).docx"

3. **~/Documents/Cowork/analytics/**
   - Export YouTube Studio analytics as CSV or take clean screenshots
   - At least 2 weeks of data so Cowork can show week-over-week comparison
   - Include: views, CTR, traffic sources, top videos

4. **~/Documents/Cowork/emails/**
   - Export 10 real email threads as text files (redact sensitive info)
   - Mix of: coaching inquiries, collab requests, Skool questions, newsletters

5. **~/Documents/Cowork/competitor-transcripts/**
   - 5 competitor video transcripts (use /transcribe skill beforehand)
   - Pick videos on similar topics to Tyler's content

6. **~/Documents/Cowork/content-audit/**
   - Copy of current week's content folders so the Friday audit has real data
   - Should show a mix of published and scheduled content

### Cowork Configuration

- CLAUDE.md file with simplified business instructions (show on camera)
- MEMORY.md with some pre-existing entries (show it's been used)
- Gmail connector already connected
- Google Drive connector already connected
- Notion connector connected (if Tyler uses it, otherwise swap for Google Sheets)
- At least 2 scheduled tasks already set up and running with real output files

### Software to Have Open

- Claude desktop app (Cowork tab active)
- Finder windows showing the prepared folders
- A text editor to show CLAUDE.md and MEMORY.md
- YouTube Studio (for showing analytics comparison)

## Filming Order (Efficiency)

Film in this order to minimize setup changes:

### Round 1: Screen Recordings (60-90 min)
1. Run ALL Cowork demos in sequence while screen recording
2. Start each demo fresh so the interface looks clean
3. Let tasks run in real time, you'll speed them up in editing
4. Record: competitor analysis, client folder org, analytics report, email triage, content gap analysis, Gmail triage, Drive analysis, Notion cross-ref, scheduled task outputs, Code skills list, content folders
5. Make sure outputs are saved so you can re-open them for close-up shots

### Round 2: Talking Head (45-60 min)
1. Film all talking head segments in sequence
2. Use the CueCard section from the script as reference
3. Script the first 30 seconds word-for-word on the teleprompter
4. After the intro, use bullet points and speak naturally
5. Film re-engagement lines as separate clips so they're easy to insert

### Round 3: Pickups (15-20 min)
1. Close-up shots of specific outputs (spreadsheets, reports, draft emails)
2. The weekly workflow diagram (whiteboard or tablet drawing)
3. Any b-roll of the desktop app interface
4. End screen pointing gesture

## Key Production Notes

- **Pace:** Cut aggressively. No silence longer than 0.5 seconds. This is a course but it should feel like a fast tutorial.
- **Music:** Low background music during screen recordings. Slightly louder during transitions.
- **Text overlays:** Add capability numbers (1/5, 2/5, etc.) as lower thirds during each section.
- **Zoom:** During screen recordings, zoom into the key parts. Don't show the full desktop, show the prompt, then the output.
- **Timer:** Consider adding a small elapsed-time counter during Cowork demos to show "this took 4 minutes" in real time.
- **Thumbnail elements to capture:** Get a clean shot of Tyler pointing at the Cowork interface with a good expression. Also capture a clean Cowork dashboard screenshot for the thumbnail background.
