MEMORY.md is where Cowork saves what it learns about you over time. After a few sessions, it knows your preferences, your business context, your writing style. Jeff Su showed this really well in his video, and he's right, this is the most important feature in Cowork.

### Setting Up Connectors

[SHOW: Cowork interface, clicking Customize, then Connectors, then the + icon]

To connect your tools, click Customize on the left, then Connectors, then the plus icon. You can search for Gmail, Google Drive, Google Calendar, Notion, and more. I recommend connecting at least Gmail and Google Drive to follow along.

[SHOW: Connecting Gmail - the OAuth flow, granting permissions]

Once connected, Cowork can read from these tools and work with that data directly. It can't send emails for you or edit your Google Docs yet, but it can read everything and create local files based on what it finds.

[SHOW: Cowork accessing Gmail through the connector, then generating the triage report]

This right here is what Jeff Su showed in his video, and I'll be honest, it's the feature that sold me on Cowork. Because it's not just reading my emails. It knows my business context from the CLAUDE.md file. It knows my writing style from MEMORY.md. So the draft replies actually sound like me.

### Transition with strong hook

This is the capability that turns Cowork from a cool tool into a business employee. And honestly, I'm shocked more people aren't talking about this. ChatGPT and Gemini both have scheduled tasks, but Claude Cowork's implementation is the only one I've found that actually works reliably, and it's because of everything we just covered: file access, memory, and connectors all working together.

### How Scheduled Tasks Work

[SHOW: Cowork interface, clicking into Scheduled Tasks]

Scheduled Tasks lets you set up recurring jobs that Cowork runs automatically. Every morning at 6 AM. Every Monday at noon. Whatever you need.

[SHOW: The scheduled tasks panel with Tyler's existing tasks visible]

I have 3 scheduled tasks running right now. Let me walk you through each one.

### Demo 4A: Daily Inbox Triage (6 AM)

[SHOW: Opening the daily inbox triage scheduled task]

This one runs every morning at 6 AM before I wake up. It connects to my Gmail, triages everything that came in overnight, drafts replies, and saves a report to my Cowork folder. By the time I open my laptop, there's a file waiting with everything categorized and draft replies ready to review.

[SHOW: An actual output file from a morning triage]

Here's what this morning's report looked like. 14 emails processed. 3 need my reply, and the drafts are already here. 6 were newsletters I can skim later. 5 were notifications I can ignore. Instead of spending 30 minutes going through my inbox, I spent 5 minutes reviewing the drafts and hitting send.

### Demo 4B: Weekly YouTube Analytics (Monday 8 AM)

[SHOW: Opening the weekly analytics scheduled task]

Every Monday morning, this task pulls my YouTube analytics, compares them to last week, and creates a performance report. It knows what metrics I care about because of my CLAUDE.md instructions. And because of MEMORY.md, it remembers the benchmarks from previous weeks.

[SHOW: A weekly report output with week-over-week comparisons]

Look at this. Views are up 12% week over week. My best-performing video was the Claude Code skills tutorial. CTR on shorts is higher than long-form. And it's recommending I do a follow-up to the skills video because the retention curve was strong.

This report used to take me 45 minutes. Now it takes zero minutes because it's done before I wake up on Monday.

### Demo 4C: Weekly Content Audit (Friday 5 PM)

[SHOW: Opening the content audit scheduled task]

Every Friday at 5 PM, this task goes through my content folders and creates a status report. What was published this week, what's scheduled for next week, what's missing.

Prompt that powers this task: "Review my content folders. List everything published this week with platform and engagement if available. List everything scheduled for next week. Flag any gaps in the schedule. Compare against my target of 32 pieces of content per week and tell me where I'm behind. Save the audit to my Cowork folder."

[SHOW: The Friday audit output]

There it is. 28 out of 32 pieces published this week. I'm missing a Thursday LinkedIn post and 2 Instagram carousels. For next week, all 5 shorts are scripted but only 3 have been filmed.

### Setting Up Your Own Scheduled Task

[SHOW: Creating a new scheduled task step by step]

To set one up yourself, go to Scheduled Tasks, click New, and describe what you want. Pick your schedule, daily, weekly, whatever. Make sure Cowork has access to the folders and connectors it needs. And here's my biggest tip: start with the task manually first. Run it 3-4 times, give feedback, let the memory file build up. Then convert it to a scheduled task once the output is consistently good. Don't start with automation, start with getting the output right.

## CAPABILITY 5: Cowork + Claude Code - The Full System (25:00 - 29:00) ~800 words

### Transition

Now here's the part nobody else is showing you. Because I don't just use Cowork. I use Cowork AND Claude Code together. And the difference is everything.

### Cowork vs Code (Simple Explanation)

[SHOW: Side by side - Cowork tab and Code tab in the Claude desktop app]

Here's the simplest way to think about it. Cowork is for business tasks you'd give to an assistant. Organize these files. Analyze this data. Draft these emails. Triage my inbox. You describe the outcome, it does the work.

Claude Code is for building custom tools and automations. It writes actual code. It creates skills, which are reusable processes you can trigger with a single command. If Cowork is your assistant, Code is your engineer.

[SHOW: Tyler's terminal with Claude Code and the list of 25 skills]

I have 25 custom skills built with Claude Code. They handle everything from YouTube research to thumbnail generation to scheduling social media posts. But here's the thing, I use Cowork for the everyday stuff that doesn't need a custom skill. And when I find myself doing the same task in Cowork over and over, that's when I build it into a Claude Code skill.

### The Workflow

[SHOW: Diagram or whiteboard showing the flow]

Here's how my week actually works. Monday morning, my scheduled Cowork task has already triaged my inbox and created a YouTube analytics report. I review both in 10 minutes.

Then I switch to Claude Code and run my yt-search skill to research video topics. That creates a research report. I feed that into my yt skill which builds a full video package: script, titles, hooks, description, filming guide.

Back in Cowork, I have a scheduled task that audits my content calendar every Friday and tells me what's missing.

The point is, they're not competing tools. They're complementary. Cowork handles the recurring business operations. Code handles the custom creative workflows.

[SHOW: Tyler's actual content output folder showing the 32 pieces of content pipeline]

This system produces 32 pieces of content per week. 2 long-form YouTube videos, 5 shorts, 5 TikToks, 5 Reels, 4 Instagram carousels, 7 LinkedIn posts, 2 X posts, and 2 YouTube Community posts. I couldn't do that without both tools working together.

[NOTE: This is the "aspirational" section. Don't make it feel braggadocious. Frame it as "this is what's possible when you commit to the ecosystem." The viewer should feel inspired, not intimidated.]
