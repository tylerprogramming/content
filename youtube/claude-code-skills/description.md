# YouTube Description

Claude Code skills let you save any workflow as a reusable slash command. In this video, I show three skills I actually use every day — transcribing YouTube videos, daily journaling, and scripting out videos — then I open the files to show you exactly what a skill looks like, and finally build a brand new meal planning skill from scratch on camera.

## In this video:
- Three real skill demos: `/transcribe`, `/journal`, `/yt`
- What a skill actually is under the hood (opening the actual SKILL.md files)
- Why skills matter and save you time
- Live build: creating a meal planner skill with recipe tracking and shopping lists
- Global vs. project skills — how to make skills available everywhere
