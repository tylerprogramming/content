## Email Body

```
Hey [first_name],

Quick story from making this week's video.

I was 22 minutes in when I had a small panic.

I'd just shown 3 Claude Code skills doing real work. Research in 60 seconds, a transcript in 90 seconds, a full video package in 5 minutes.

Then I was supposed to open a SKILL.md file and reveal: "all 3 of these are just markdown files. About 50 lines each."

And right before I hit record on that segment, I thought: "Wait. Is this going to feel anticlimactic? They just watched all this impressive stuff. If I tell them it's just plain English in a text file, does the air come out of the room?"

Almost cut it.

Then I remembered every Claude Code question I've ever gotten from beginners:

"Don't I need to learn the SDK?"
"What framework do I use?"
"How do I write a plugin?"

None of those are required.

A skill is a markdown file. About 50 lines of YAML frontmatter and plain English instructions. That's the whole system.

So I kept the segment. And on rewatch, it's the strongest moment in the video.

If you haven't watched yet, that moment is at the 21:30 mark.

[VIDEO_LINK]

And if you have watched, here's the 15-minute exercise I dropped in my Skool community yesterday:

1. Pick the most annoying repetitive thing you do in Claude Code right now.
2. Create a folder at ~/.claude/skills/<name>/
3. Drop a SKILL.md file with frontmatter and body.
4. Restart Claude Code. Test it.

Even a tiny skill counts. The first one I built was a 30-line transcribe wrapper. Took me 90 minutes. Now I have 43 of them.

If you build one tonight, reply and tell me what it does. I'll share the best ones in next week's email.

- Tyler
```
