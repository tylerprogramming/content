## Post Copy

**Title:** Try this. 15 minutes. Tonight.

**Body:**

The biggest realization in Monday's video wasn't about the 3 skills I showed.

It was the moment I opened a SKILL.md and showed it's just a markdown file. About 50 lines. Plain English instructions.

Most people overestimate what it takes to build a Claude Code skill. By a lot.

Here's a 15-minute exercise you can do tonight after work:

1. Pick the most annoying repetitive thing you do in Claude Code right now. Something you type out longer than 2 sentences and have done more than 3 times.

2. Create a folder at ~/.claude/skills/<name>/

3. Drop a SKILL.md file inside with the frontmatter and the body. The format from Monday's video works for anything.

4. Restart Claude Code. Type /<name>. Test it.

If it doesn't work the first time, iterate. The skill is just a file you can edit.

Drop a comment with the skill you build. Even if it's tiny. Especially if it's tiny.

The first 5 people to share what they built, I'll personally review the SKILL.md and suggest 1 improvement.

[Link to the Monday video if they missed it]

— Tyler
