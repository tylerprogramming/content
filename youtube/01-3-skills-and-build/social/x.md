## Standalone insight tweets (spread across the week)

**1 (hot take)**
Most people use Claude Code like a chatbot.

The unlock isn't a better prompt. It's skills. A skill is a markdown file that turns "do this for me every time" into one command.

**2 (proof)**
YouTube research used to take me 2 hours a week.

One command now does it in 60 seconds: pulls the last 30 days of videos, sorts by views, downloads the thumbnails, writes a report.

**3 (tip)**
Don't watch your competitors. Read them.

Transcribe the video, then ask the model for the hook, the beats, and the CTA. You'll get through 5 videos in the time it takes to watch one.

**4 (hot take)**
I never start a video with a blank doc. Ever.

I point a skill at a transcript and 5 minutes later I have titles, hooks, a full script, and a filming guide. It writes the 80% draft. I make it mine.

**5 (the aha)**
People think building a Claude Code skill needs an SDK or a framework.

It's a markdown file. Frontmatter on top, plain English below. Some are 50 lines, some generate their own Python. That's the whole thing.

**6 (practical)**
Three patterns make any skill robust:

1. When input is missing, ask instead of erroring
2. Write output to predictable paths so skills cooperate
3. Put hard rules at the bottom: never overwrite, always confirm
