# Skool - Claude Code Skills Changed How I Use AI

**Video:** https://youtu.be/lfwt5tFfaSo

---

I kept explaining the same thing to Claude over and over, and skills are what finally fixed it.

Here's the idea. A skill is just a saved way of working with Claude. You write down what you want once, and from then on it's one command instead of a paragraph.

I have three I use every single day. One pulls a clean transcript from any YouTube video. One asks me a few journal questions and saves a dated file. And one helps me script out my videos. I built each of them in about a minute.

The part that surprised me is there's no code. Open the folder and a skill is a single file called SKILL.md. A name at the top, the tools it can use, and plain English instructions below. That's the whole thing.

And you can put them in your home directory so they work everywhere, in every project. You can also update them just by asking, like telling your journal skill to start asking about your mood.

In the video I show three of mine, open the actual files so you can see what they look like, then build a brand new one from scratch on camera.

It's an older one, but the idea hasn't changed at all, so if you missed it, it's worth ten minutes.
