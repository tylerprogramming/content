I kept explaining the same thing to Claude over and over.

Resize these images. Transcribe this video. Ask me my journal questions. Same instructions, every single day.

Then I found the feature in Claude Code that fixed it, and I haven't gone back.

They're called skills.

A skill is just a saved way of working with Claude. You write down what you want once, and from then on it's one command instead of a paragraph.

I have three I use every day. Slash transcribe pulls a clean transcript from any YouTube video. Slash journal asks me a few questions and saves a dated file. And one scripts out my videos, including this kind of thing.

I built each one in about a minute.

Here's the part that surprised me. There's no code involved.

I opened my skills folder to see what one actually looks like. Each skill is a folder, and inside is a single file called SKILL.md.

At the top it lists a name, the arguments it takes, and the tools it's allowed to use. Below that is just instructions in plain English. That's the whole skill.

There's one detail that makes them powerful. If you put a skill in a project folder, it only works there. If you put it in your home directory, it works everywhere, every project, every conversation.

And you can update them by asking. If my journal skill isn't asking the right questions, I say update it to also ask about my mood. Done.

I'll be honest, this isn't magic and it won't replace knowing how you work. You still have to know what you want. Skills just save you from typing it out again.

But that's the whole point. You explain something once, and then you never explain it again.

The pattern is simple. Do something with Claude. Like the result. Say make a skill out of this.
