## Caption
What Claude Code skills actually are, and why I use three of them every day.

Swipe to see how they work.

A Claude Code skill is just a saved way of working with Claude. Instead of typing the same long prompt every day, you write it down once and run it with a single command. I have three I use daily: one transcribes videos, one runs my daily journal, and one scripts my videos.

The part that surprised me is there's no code. Open the folder and a skill is one file called SKILL.md, with a name, the tools it can use, and plain English instructions. Put it in your home directory and it works in every project.

This is the original Claude Code tutorial I made on skills, and the idea hasn't changed, so it's still the best place to start. In it I open the actual files and build a brand new skill from scratch on camera.

Save this for when you're ready to build your first one, and send it to someone who uses Claude Code every day.
