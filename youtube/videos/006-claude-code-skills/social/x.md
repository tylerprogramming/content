## POST 1 - Thread (what a skill is)

**Main tweet:**
People think building a Claude Code skill needs an SDK or a framework.

It's a markdown file. I use three every day and each took about a minute to make. Here's how they work:

**Reply 1:**
A skill is a saved way of working with Claude. You write down what you want once, and after that it's one command instead of a paragraph you retype every time.

**Reply 2:**
Open the folder and a skill is one file called SKILL.md. A name at the top, the tools it's allowed to use, then plain English instructions below. That's the whole thing.

**Reply 3:**
Two places to put them. In a project's .claude folder it only works there. In ~/.claude/skills it works everywhere, every project, every chat.

**Reply 4:**
You update them by asking. My journal skill wasn't asking the right questions, so I said add one about my mood. It rewrote itself. The tools grow with you.

**Reply 5:**
The pattern is simple. Do something with Claude. Like the result. Say make a skill out of this. Next time it's one command.

**Reply 6 (CTA):**

## POST 2 - Standalone, the honest line (no link)

Skills did not make Claude smarter. They made me stop retyping myself.

I still have to know what I want and what good output looks like. The skill just remembers the steps so I don't explain them again.

## POST 3 - Standalone, the twice rule (no link)

If you've explained the same process to AI twice, stop and write it down as a file.

Name it, list the steps in plain English, save it. Now it runs the same way every time and you never teach it again.

## POST 4 - Standalone, plain explainer (link)

A Claude Code skill is a markdown file with instructions in it.

You describe a task the way you'd explain it to someone new on your team. Then Claude does it that way every time you ask.
