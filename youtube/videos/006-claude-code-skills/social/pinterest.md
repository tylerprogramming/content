## PIN 2 - The Concept (Explained)

**Board:** Claude Code Tutorials (`1121537182144784091`)
**Destination link:** https://youtu.be/lfwt5tFfaSo
**Title:** Global vs Project Skills in Claude Code (Explained)
**Description:**
A Claude Code skill can live in two places, and the spot decides where it works. Put it in your home folder and it runs in every project on your machine. Keep it in the project folder and it stays with that one repo. Same markdown file either way. Save this reference card.
