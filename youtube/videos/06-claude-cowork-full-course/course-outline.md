# Claude Cowork Full Course - 10 Modules + Examples

Quick-reference outline. Each module lists the example(s) you put on screen. Safe sample files are scaffolded in `demo-assets/`; full staging notes are in `demo-prep.md`.

---

**Module 1: Setup - Get Cowork Running the Right Way** (3:00)
- Install the desktop app, create your `Cowork` folder - framed as a "memory folder" that holds info about you and your business, reused on every task - point it there, tour the interface.
- First task on camera: "Create an about-me.md, interview me, and write the first piece of memory about my business." (the first brick in the memory folder)

**Module 2: File Management and Document Creation** (10:00)
- Organize a messy client onboarding folder (contracts, invoices, intake, proposals) into clean subfolders. → `demo-assets/messy-client-folder/`
- Receipts: drop in 5-6 phone photos of business receipts → Cowork builds an expense spreadsheet (vendor, date, amount, category) + a summary that flags a duplicate subscription. → `demo-assets/receipts/`

**Module 3: The Memory System - Train Your AI Employee** (19:00)
- Build on the memory folder from Module 1: turn the about-me into a full `CLAUDE.md` instructions file (have Cowork interview you), living in that folder and read on every task.
- Prove it with a before/after report (it formats your way without being told), then an email draft that already sounds like you.

**Module 4: Research and Analysis** (28:00)
- Weekly performance report with week-over-week trend + 3 recommendations. → `demo-assets/analytics/` CSVs
- Gap analysis: read competitor material, output a ranked content-opportunities spreadsheet.

**Module 5: Connectors - Gmail, Drive, Notion** (36:00)
- Gmail inbox triage from the last 48 hours with draft replies in your voice (real Gmail, blur sensitive subjects).
- Two sources at once: read scripts from a Google Drive `Scripts` folder + cross-reference your local analytics report.

**Module 6: Claude in Chrome - Let It Browse the Web** (45:00)
- Have it drive your real logged-in Chrome to pull a report off YouTube Studio analytics.
- Show the orange tab highlight and the permission prompts; verify live behavior on camera.

**Module 7: Skills and Plugins - Make Your Best Work Reusable** (52:00)
- Save the weekly-report workflow as a reusable skill, then run it by name with one command.
- Open the plugins area and add one ready-made capability that fits a real task.

**Module 8: Scheduled Tasks - Works While You Sleep** (58:00)
- Show real prior outputs: a past morning Gmail triage and a past Monday analytics report.
- Build one live: "Every Monday at 8am, build my analytics report and save it to my folder." (uses the safe sample CSVs, not private email)

**Module 9: Cowork + Claude Code - The Full System** (68:00)
- Show your real Claude Code skills list in the terminal (blur any keys/tokens).
- Walk a simple flow diagram: Monday scheduled task → 10-min review → Code skills for production.

**Module 10: Your First Week + Starter Prompt Pack** (73:00)
- The 7-day on-ramp: install + one task today, CLAUDE.md + Gmail this week, first scheduled task by the weekend.
- Hand viewers the 5 starter prompts (organize, report, triage, research, schedule).
