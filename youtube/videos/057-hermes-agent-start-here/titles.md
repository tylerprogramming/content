Written 2026-09-15 against `BRAIN/youtube/packaging-rules.md`. Supersedes the v3 list in `_v3-13min/titles.md` (those were written for a 10-minute cut).

## Gate check

"Hermes Agent" passes the search-demand gate. The 08-25 research pull has 20 long-form videos on the term in 120 days, all six figures (Nate Herk 349,120, Tina Huang 313,962, CodeHead 195,894). Contested, not empty.

## Rules this lane has to obey

| Rule | What it forces here |
|---|---|
| Course lane: put the runtime in the title (brain 08-18, 08-19, 08-20) | "30 Minutes" is in every option. It is also the length test: if 30 does not fit, the cut is too long. |
| Write the query, not the capability (brain 08-21) | "Hermes Agent" is in every option, not just "AI agent". |
| Duration barbell: 35 to 60 min is the dead zone | 30:00 is the ceiling, not the target. Hard stop at 33. Cut section 9 first if over. |
| Second person, not "I" | Every option is an instruction or an address. |
| No money, no "Explained", no em dash, never imply Tyler is not a developer | Checked. |

## Recommended

1. **Set Up Hermes Agent in 30 Minutes (Claude Code Users Start Here)** (64 chars)
   Second-person instruction (rule 1), head term up front, time box (rule 3 and the course-lane rule), identity named in the parenthetical (rule 7). This is the title the whole package is built on: the hook, the description's first line and the thumbnail all pay it off. If you want the one caps word, it is `START HERE`, and that is the thumbnail text anyway.

## Alternatives

2. **Your Claude Code Setup Is Missing Its Other Half (Hermes Agent)** (63 chars)
   Second-person accusation (rule 5, the one the brain says to try once a quarter). Names the identity and the head term. Weakness: no time box, so it reads as an opinion video, not a course. Good B-test after day 7, since swapping strategy (accusation vs term-led) is the only swap the brain allows.

3. **Turn One Computer Into a Team of AI Agents in 30 Minutes (Hermes)** (65 chars)
   Transformation verb (rule 2, the biggest lever in the competitor set) plus time box. Weakness: "Hermes" only fits as a parenthetical and "Hermes Agent" does not fit at all, so it is weaker in search. Use if the video ends up being about the bots more than the setup.

4. **Hermes Agent for Claude Code Users in 30 Minutes** (48 chars)
   The plainest query-shaped title. Head term, identity, time box, nothing else. Lowest ceiling, highest floor. Fallback if 1 feels long on mobile.

5. **The Hermes Agent Setup Claude Code Users KEEP MISSING** (53 chars)
   Identity plus one late caps word (rules 4 and 7), the shape of the channel's 1.81x video. No time box, so it fights the course-lane rule; keep it as a Shorts or Community post title, not the upload.

## Do not use

- "Hermes Agent Explained in 10 Minutes" (the old working title). Breaks rule 2 and the runtime is wrong now.
- Anything with "Fundamentals" or "In 29 Minutes". That is Tina's title and YouTube will treat it as a duplicate.
- Any "I set up" or "I built" phrasing. Seven "I ..." videos, 15 subs.
- Do not retitle inside 7 days (brain 08-25: a retitle recovers nothing once the push is spent).
