# Hooks, video 057 (v4, 30-minute course)

Three word-for-word opens, each about 30 seconds. Pick one. Do not blend them.

Rules applied from `BRAIN/youtube/brain.md`:
- Cold open admits four openings: a number in sentence one, an insider name, a named villain, or **a working artifact already on screen**. The 08-19 entry says the artifact is the strongest of the four, and it is the one we actually have.
- Name a withheld payoff around 0:20 and hold it to the end. Tina never does this. Our payoff is the bot that opens a real pull request.
- Never imply Tyler is not a developer.
- No hype words, no em dashes.

## Hook 2, the wedge
*Technique: contrast against the tool they already run*

>
> So here is the other shape. Hermes is a process that starts once and does not stop. It remembers across every session, it writes its own skills as it works, and it keeps running with the laptop closed.
>
> [Slack card on the phone]
>
> That is not a promise, that is this morning. One of my agents posted that at eight while I was asleep.
>
> Claude Code is the specialist you call into a repo. This is the one that runs the day around it. In the next thirty minutes I will get you set up, and at the end I will show you four of them handing work to each other until one opens a pull request on GitHub on its own.

Use this if the cold open shot list falls through and you only have one card to show. It carries the same promise with less footage.
