# Description

Hermes Agent is the free, open-source agent from Nous Research that runs on your own machine, remembers every session in files you can open and edit, writes its own skills as it works, and keeps running on a schedule after you close the laptop. If you already use Claude Code, this is the always-on other half: Claude Code is the specialist you open inside a repo, this is the one that handles everything around it. In this video I set it up from scratch in about thirty minutes.

We go through the install, the memory model and why those files are capped, skills it writes for itself, scheduled jobs that deliver to Slack, and running the whole thing locally and free on Ollama. Then the part I actually built this for: a roster of named bots that hand work to each other, ending with one of them opening a pull request on GitHub and another one telling me about it on my phone.

Setup notes and every command from this video are in the free community below.
