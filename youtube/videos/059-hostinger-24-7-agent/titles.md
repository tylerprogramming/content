# Titles, video 059 (Hostinger 24/7 agent)

Written 2026-09-21 against `BRAIN/youtube/packaging-rules.md`. Target runtime 18 to 20 min, so the time box is "20 Minutes" and it is also the length veto: if the cut runs past 20, the title changes before the video does.

## Gate check

"Hermes Agent" passes the search-demand gate: 20 long-form videos over 20K views in the last 30 days on the term (Metics 375,037, Tina 184,472, AI LABS 115,094). Contested, not empty.

"Hostinger" and "VPS" do not carry the video. Same channel, same host, same month: Metics' VPS-titled video did 21,303 against 375,037 for the general one. Hostinger goes in a parenthetical, the description and the thumbnail, never up front.

"24/7" is dominated by trading titles (Nate Herk 449,898). "While you sleep" without money stays under 30K. Both are fine as words inside a title that leads with Hermes Agent; neither is the head term.

## Rules this video has to obey

| Rule | What it forces here |
|---|---|
| Second person, not "I" | Every option is an instruction or an address. "I Built an AI Agent That Works While I Sleep" did 0.27x on a 253K channel. Not that shape. |
| Write the query, not the capability (brain 08-21) | "Hermes Agent" in every option. "AI agent" alone is a capability. |
| Time box on a course-lane video (brain 08-18, 08-19) | "20 Minutes" where it fits. Matteo's "In 15 Minutes" did 2.56x on a 5.6K channel. |
| Status claims cap (brain 08-13: "Runs Itself" sits with "Works While I Sleep") | "Runs while you sleep" is a status claim in second person. Kept as an option because the handoff asked for it, but not the recommendation. See the note on option 2. |
| No money, no "Explained", no em dash, under 70 chars | Checked on every line. The price goes on the thumbnail. |

## Recommended

1. **Create Your First 24/7 Hermes Agent in 20 Minutes (Hostinger VPS)** (65 chars)
   Second-person instruction, head term, a small number that caps effort, the time box the course rule wants, and the host in a parenthetical where it does search work without leading. "First" names the viewer's situation (they have Claude Code, they do not have a server). This is the title the cold open and the thumbnail pay off: the thumbnail shows the phone and the price, the title promises the build.

## Alternatives

2. **Your First AI Agent That Runs While You Sleep (Hermes Agent + Hostinger)** (72 chars, over)
   The handoff's working title. Two problems: 72 characters truncates on mobile, and "Runs While You Sleep" is the status-claim shape the brain closed on 08-13 ("Runs Itself" 0.51x, "Works While I Sleep" 0.27x). The second-person version has not been tested, so it is not proven dead, but it is not the safe first pick. Trimmed version under 70: **Your First Hermes Agent That Runs While You Sleep (Hostinger VPS)** (65 chars). Use as the day-8 B-test: it swaps strategy (outcome-led vs instruction-led), which is the only swap the brain allows.

3. **Turn a Hostinger VPS Into a Hermes Agent That Never Sleeps** (58 chars)
   Transformation verb, the single biggest lever in the competitor set (Chase AI 5.10x). Weakness: leads with the VPS, and the VPS-led title is the one that did 21K. Keep it for the Short or the Community post where the VPS is the whole point.

4. **Your Hermes Agent Dies When the Laptop Closes. Fix It in 20 Minutes** (67 chars)
   Second-person accusation, the shape the brain says to try once a quarter. Names the real problem (057 viewers' agent lives on a Mac that sleeps). Weakness: two sentences in a title reads busy on mobile. Good LinkedIn hook line even if it is not the upload title.

5. **Hermes Agent on a Server in 20 Minutes (Claude Code Users, Part 2)** (66 chars)
   Identity-led, ties to 057 for the subscriber notification. Weakness: "Part 2" tells a new viewer they missed something. Use only if 057 breaks out and the channel wants a visible series.

## Do not use

- "Create Your First 24/7 AI Agent (Hostinger VPS)" as the upload title. No head term, no time box. It is the task name, not the title.
- Anything with "Full Guide" or "Full VPS Setup Guide". Both Metics titles. YouTube will treat it as a duplicate and his has 21K on it already.
- Any price in the title ("Five Dollar Server"). Thumbnail and description first line only.
- "Explained", "Ultimate", "INSANE".
- Do not retitle inside 7 days. Read the B-test on day 8.
