## POST 1 - The drop

I described an ad in one sentence and the whole pipeline built itself. New video is up.

Quick disclosure first, this is a paid partnership with ElevenLabs and I'm one of their ambassadors. Which is exactly why I show the costs in it.

Here's the thing. ElevenCreative has a piece called Flows, a canvas where every node is a generation. Image node feeds a video node, voiceover and music come in beside it, and it all lands in a composition node that assembles the finished ad. Normally you wire that canvas up yourself.

The Flows Agent builds it for you. You describe what you want, it asks what it needs to know, then it picks the models, creates the nodes, connects them, and runs the generations.

In the video I build a 30 second coffee ad live. Five campaign images, animated clips, a voiceover I picked, a music bed, all composed into one ad. I never dragged a node.

Two things stood out. Iterating is just talking, I asked for cinematic on-screen text and it added it and re-ran only the composition. And once the pipeline exists you can swap the product at the top and get a new ad out of the same flow.

## POST 2 - The tactic (try this today)

If you're running any agent that can spend money, do this before your next session.

Give it a ceiling instead of a babysitter.

Here's where I learned it. I've been building video ads with the Flows Agent in ElevenCreative, which is a paid partnership with ElevenLabs. The agent creates the pipeline and then runs it, and every generation inside it costs credits.

There's a permission setting with three positions. Auto run, where it does everything without asking. Confirm, where it stops before every step. And the middle one, where it runs anything under a credit threshold you set and only asks when a step goes over.

I run the middle one. My threshold is 300 credits and a typical image node lands around 178, so most of the pipeline moves without me. The expensive steps still stop and wait.

The reason I like this more than confirm-everything is that I stopped being the bottleneck. When I was approving every step I batched fewer variations and iterated less, which is the opposite of why I'm using an agent.

And it generalizes. Tokens, credits, API calls, any agent that spends is easier to trust when the limit is a number instead of your attention.

So how are you capping your agents right now? Curious if anyone has a rule they actually stick to.

## POST 3 - The discussion (no link)

I want to ask you all something I've been going back and forth on.

I've been building video ads by describing them to an agent, and the piece that changed how I think isn't the generation quality. It's that once the pipeline exists, the input at the top is swappable. Same flow, different product, new ad. Build it once, run it ten times.

Which makes me think the valuable thing was never the output. It was the pipeline.

That's a weird shift to sit with. I used to think of AI work as one-off, ask for a thing, get a thing, move on. Now I'm trying to notice which of my one-offs are secretly the same shape repeated, because those are the ones worth turning into a flow.

Ads are obvious. A format, ten products. But I don't think it stops there. Anything where the structure is fixed and only the content changes probably qualifies.

So here's my question for you.
