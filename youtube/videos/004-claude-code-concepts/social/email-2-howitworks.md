Hey [first_name],

Following up on the Claude Code concepts video, because a few of you replied saying 23 feels like a lot to learn at once. It is. So do not.

If you are just getting started, you only need three to feel a real difference. Here they are, plainly.

Context window. This is Claude's short-term memory, and it fills up as you work. Every message and file you feed it piles up. When it gets full, Claude starts forgetting what you told it earlier and the answers get worse. Watch the bar at the bottom of the terminal, and start a fresh session for a new task. That one habit fixes half of what feels broken.

CLAUDE.md. A plain markdown file in your project where you write your rules once, how you like things done, and Claude reads it first every session. Things like always use TypeScript, or use this brand voice, or never use em dashes. Without it, Claude is guessing every time.

Plan Mode. Before Claude builds anything, you can have it think first. It goes read-only, explores your code, and tells you the approach before it touches a thing. You approve the plan, then it builds. Think first, build second.

Get comfortable with those three and the other 20 concepts get a lot easier.

https://www.youtube.com/watch?v=MVr2GrAjrgQ
