Most people install Claude Code, get confused, and give up.

That's not a skill problem. It's a knowledge problem. There are 23 concepts that take you from "what is this terminal" to building real projects - and most tutorials skip half of them.

So I made a video covering all 23, with a live terminal demo for every single one.

Here's what actually matters:

👉 The context window is Claude's short-term memory. When it fills up, outputs degrade. Most people never notice this is happening. Managing it is the difference between sessions that work and sessions that don't.

👉 CLAUDE.md is the most important file in your project. Write your rules, preferences, and constraints once. Claude reads it first every session and follows it forever. No CLAUDE.md means Claude is guessing.

👉 Plan Mode, /compact, /rewind, and session history are the commands that change how you work. Learn these before anything else.

👉 MCP Servers, Sub-Agents, Hooks, Custom Agents, and Remote Control are where Claude Code becomes genuinely powerful. These aren't advanced extras - they're the whole point.

If you're just getting started, focus on concepts 1-10 first. Bookmark the rest.
