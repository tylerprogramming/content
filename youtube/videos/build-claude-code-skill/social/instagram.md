## Slide Content

**Slide 1 (Intro — dark #1a1a1a background)**
Headline: How to Build a Claude Code Skill
Subtext: Front matter to working slash command.

**Slide 2**
Headline: Start with SKILL.md
Body: Every skill is a markdown file. Front matter at top: name, description, allowed-tools. The description is how Claude knows when to trigger it.

**Slide 3**
Headline: Write the Instructions
Body: Think SOP for a new hire. Step 1, Step 2, Step 3. What to do, in what order, what the output looks like. Add a Rules section for everything that went wrong.

**Slide 4**
Headline: Test It Immediately
Body: Type the slash command. Watch Claude read your file and follow it. First version will be off. That's normal - that's the loop.

**Slide 5**
Headline: Add a Reference File
Body: Real examples of outputs you liked. "Match this tone. Avoid this." One line pointing to it in your instructions. Output shifts immediately.

**Slide 6**
Headline: Two Files. Complete Skill.
Body: SKILL.md + one reference doc. That's it. Complexity scales from here - but every skill starts the same way.
