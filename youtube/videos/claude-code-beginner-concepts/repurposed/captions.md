## Caption 1 — Context Rot (Recommended for Reels/TikTok)

Your Claude Code sessions feel sharp for 20 minutes and then fall apart. Here's why.

It's called context rot.

Claude has a memory limit called the context window. Every message, every file it reads, every response - it all lives there. When it fills up, Claude starts forgetting what you said earlier.

The fix:

Watch the green bar at the bottom of your terminal. That's your context meter.

When it starts getting full, type /compact. Claude summarizes the conversation and clears the noise. You can even tell it what to keep.

Or start a fresh session when you switch tasks. Don't try to do everything in one conversation.

Context rot was behind almost every "Claude is getting weird" complaint I had in my first month. Now you know how to stop it before it starts.

## Caption 2 — CLAUDE.md

Most Claude Code users are starting from scratch every single session. There's a better way.

It's a file called CLAUDE.md.

Every time you open Claude Code, before it does anything else, it reads this file. Your preferences, your workflow rules, your writing style - all in there.

I wrote mine once. Now every session starts with Claude already knowing how I work.

Without it, Claude is guessing. Every. Single. Time.

How to create one: open Claude Code and type "Help me create a CLAUDE.md for my project. Ask me questions about my preferences and workflow."

Claude will interview you and build the file for you in about an hour.

One hour of setup. Pays back every day after.
