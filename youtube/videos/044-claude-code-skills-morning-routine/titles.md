# Titles - 044 Claude Code Skills Morning Routine

> Formula: specific number + specific tool + specific outcome.
> Constraints: under 70 characters, no dollar amounts, no hype words.
> Research context: no video in the top 20 for "ai agents" hit all three parts of the formula. The #1 video (241K) came closest and dropped the tool.

---

### 1. 3 Claude Code Skills That Replaced My Entire Morning Routine
**60 chars.** The working title, and it already hits the full formula: number (3), tool (Claude Code), outcome (replaced my morning routine). "Entire" does the heavy lifting - it upgrades a tip into a replacement. Closest structural sibling to the 241K performer, which was "4 AI Agents To Automate 99% Of Your Life," except that one never named its tool.

### 2. I Built 51 Claude Code Skills. I Only Use 3 Before 9AM.
**55 chars.** The confession. Two sentences create a built-in curiosity gap - the 51 sets up an expectation and the 3 breaks it. Runs with the grain of r/ClaudeCode sentiment, which is actively anti-hoarding right now ("most developers do not need more skills on day one"). Highest ceiling of the five, slightly higher risk because the number has to be true at film time.

### 3. My Entire Morning Runs on 3 Claude Code Skills (No Coding)
**57 chars.** The parenthetical is doing real work now that the audience decision is fully non-technical. It's the same move Sandeep made in his first ten seconds ("you don't need any technical skills") and it's a large part of why his video outran better tutorials. Widest reach of the five.

### 4. 3 Claude Code Skills I Run Before 9AM Every Day
**47 chars.** Shortest and most concrete. "Before 9AM" beats "morning routine" because it's a specific time, not a category. The #1 video in the research set was also the shortest title in its top five at 40 characters, so brevity is not costing anything here.

### 5. I Automated My Morning With Claude Code (Email, Community, Analytics)
**68 chars.** Names the three payoffs explicitly for search and for the scanner who needs to know what's in it. Your proven "I automated my X" shape, which the tracker notes was your best subscriber driver. Weakest hook of the five, strongest for search.

---

## Recommended

**3 Claude Code Skills That Replaced My Entire Morning Routine**

It's the only one that lands number, tool, and outcome without a compromise, and no competitor in the 30-day research window is holding that position. Keep #2 as the A/B test at upload - the confession framing has a higher ceiling and Studio Test & Compare is the right place to find out.

**Before publishing:** verify the skill count. `ls ~/.claude/skills | wc -l` returned **51** on 2026-08-02. If you use title #2, the number on screen must match the number in the title.
