## The positioning problem this solves

There are already two skills videos in the catalog. This one has to be clearly different or it cannibalizes them:

| Video | Angle | What it is |
|---|---|---|
| `067-3-skills-and-build` (shipping Jun 14) | "Watch 3 skills + build one" | Showcase + first build. Tight, 30 min. |
| `7-skills-run-my-business` | "My content business workflow" | The 7 skills I run every week. |
| **THIS (R2 Masterclass)** | **"Everything about skills, the complete education"** | **The authoritative course. Anatomy + ecosystem + proof + new build + Cowork.** |

**The one-line promise:** By the end of this video you will understand Claude Code skills completely, you will have built your own from scratch, and you will have seen it run in both Claude Code and Claude Cowork. Write once, run everywhere.

## Why this wins

1. **Authority gap in the market.** Most skills content is a flashy 5-minute demo (the "TikTok cooking problem" - looks great, can't reproduce). Nobody teaches the full SKILL.md anatomy AND the ecosystem clearly. This video is the one people bookmark and send to teammates.

2. **The #1 misconception is the hook.** Everyone confuses skills with MCP. The clean analogy (a skill is knowing how to write a professional email; MCP is opening Gmail to send it) clears it up in 60 seconds and instantly positions Tyler as the person who actually understands this.

3. **Proof it is not a toy.** Anthropic's own June 3, 2026 blog: they run hundreds of skills internally across 9 categories, and "verification skills have had the most measurable impact on Claude's output quality." Community packs (superpowers, anthropics/skills, 1000+ in awesome lists). This kills the "cute trick" objection.

4. **The Cowork payoff is unique.** Cowork went GA April 9, 2026 on Mac + Windows for all paid plans. Skills use the SAME SKILL.md and an org owner can push them org-wide. Showing one skill run in Claude Code (dev) AND Cowork (knowledge work) is a payoff no other creator is showing well. This is the screenshot moment.

## What NOT to do (avoid cannibalizing 067)

- Do NOT re-demo `/yt-search`, `/transcribe`, `/yt` as the core content (067 owns those). Reference them as examples, do not rebuild the pipeline tour.
- Do NOT build `/meeting-notes` live again (067 + the 15-min video both did it). Build a NEW skill: `/standup`.
- Do NOT lead with the content-business workflow (that is the 7-skills video). Lead with the universal teaching.

## The new live-build skill: `/standup`

Chosen deliberately:
- **Universal** (devs and knowledge workers both do standups) so it sets up the Cowork payoff naturally.
- **Distinct from `/meeting-notes`** so no duplication.
- **Touches every concept**: frontmatter, arguments, AskUserQuestion, Bash (date + optional git), file write, rules section.
- **Has real-world proof**: Anthropic's internal `standup-post` skill is cited in their own blog, so Tyler can say "this is literally one of the categories Anthropic uses internally."

## Target outcome (90-day priority alignment)

ONE CTA: the Skool waitlist. Every segment funnels there. The free deliverable is the starter pack (the `/standup` SKILL.md built on camera + 5 more starter skills + all the SKILL.mds referenced).

## Tone & energy (Tyler's conventions, locked)

- Proof-first cold open. No "hey what's up guys."
- Show the actual commands and the actual files on screen. No hand-waving.
- Riff the script, do not read it.
- Let demos breathe. Cut pauses in edit, never apologize on camera.
- When a skill asks a question on camera, ANSWER it on camera (show the human-AI loop).
- No em dashes anywhere, spoken or written.
- ONE CTA at the end.

- Re-check current SKILL.md frontmatter field names against docs the morning of recording (the spec is evolving in 2026).
- The "Anthropic runs hundreds of skills" stat is from the June 3, 2026 claude.com blog. Pull it up on screen as the receipt.
