Claude Code skills are the highest-leverage feature in the whole tool, and most people barely use them. In this guide I explain what a skill actually is, how it's different from MCP and plugins, then we build skills live and run one in Claude Cowork.

A skill is just a markdown file. No SDK, no framework, nothing to install. In about 30 minutes you'll understand Claude Code skills completely, you'll watch me build them from scratch, and you'll see the part almost nobody is showing: taking a skill you built in the terminal and running the exact same file inside Claude Cowork. Write it once, run it everywhere.

Here's what we cover:
- What a Claude Code skill really is (name, description, instructions) and why the description is the part that matters
- Skills vs MCP vs plugins, explained simply so you never confuse them again
- Building the /standup skill live, just by talking to Claude
- Improving an existing skill (/yt-search) with Anthropic's skill-creator plugin
- Building a skill that ships its own code (a YouTube comment replier)
- Importing a skill into Claude Cowork and scheduling a weekly TikTok scrape
