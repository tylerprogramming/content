# Description

I built a self-hosted assistant on top of Claude Code that watches my real
numbers, runs six agents on a schedule, and talks back with a local voice. The
part that makes it different from every other Claude Code dashboard is small:
one agent reviews what happened after the fact and writes what it learned into
a playbook file, so next week's decisions read this week's evidence.

It is free and public domain. No account, no cloud, and nothing leaves your
machine unless you give it a key that makes it leave.
