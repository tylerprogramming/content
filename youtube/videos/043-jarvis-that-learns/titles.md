# Titles

The differentiator is the feedback loop, so most of these lead with it. Keeping
the subject on Claude Code automation, not on growing a channel.

### 1. I Built an AI Assistant That Learns From Its Own Mistakes ⭐ RECOMMENDED
59 characters. Leads with the one thing nobody else in this lane has. "Its own
mistakes" is concrete and slightly uncomfortable, which pulls the click, and
the video pays it off literally with a file that gets rewritten on camera. No
tool name, so it survives past this month.

### 2. Everyone's Building AI Assistants. Nobody's Building This.
58 characters. Contrast setup, and it is defensible: OpenPaw, Chase, and the
rest genuinely have no feedback loop. Risk is that "This" is vague, so the
thumbnail has to carry the specificity.

### 3. My Claude Code Assistant Rewrites Its Own Rules
47 characters. Most specific and most technical. Best for search and for the
existing Claude Code audience, weakest for reach. Strong second if the goal is
the community rather than the browse tab.

### 4. The Part Everyone Skips When Building an AI Assistant
54 characters. Curiosity gap framed as a gap in other people's work rather than
a claim about ours. Reads a little like a listicle, which cuts both ways.

### 5. I Gave Claude Code a Face, a Voice, and a Memory
47 characters. Rule of three, and it maps exactly to the three demos: the HUD,
the local voice, the playbook. Warmest option and the most "him." Slightly less
click-forward than #1.

---

**Recommendation: #1**, with #5 as the A/B if the first week underperforms.
The thumbnail should carry the HUD itself since none of the competitors have a
photogenic artifact to show.

**Avoid:** anything with hours-saved or money in it. We have not measured hours
saved, and the house rule is no money amounts in titles.
