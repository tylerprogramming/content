**Title:** Prompts vs Loops in Claude Code (Explained)
**Description:**
This is the mental shift that changed how I use Claude Code. A prompt is a vending machine: one thing in, one thing out, and you are the one standing there feeding it. A loop is an employee that keeps working until the job is actually finished. Write the loop once and step away. Save this reference card.
