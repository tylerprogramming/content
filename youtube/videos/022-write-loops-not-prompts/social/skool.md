# Skool - This Claude Code Plugin Is My Favorite (Ralph Wiggum Loop)

**Video:** https://www.youtube.com/watch?v=RQ57cUcGDGg

---

I finally stopped prompting Claude Code one thing at a time.

The guy who built Claude Code said he doesn't prompt anymore, he writes loops that prompt for him. I'm not a developer, but that one idea changed how I run my whole content business.

Here's the simplest way I can put it. A prompt is a vending machine. One coin in, one thing out, then it's over. A loop is an employee. You tell it what good looks like once, and it keeps working until the job is actually done.

My favorite version has a funny name, the Ralph Wiggum loop. It just runs the same instruction over and over until the work is finished. Claude Code turned it into a little plugin, /loop.

My real one runs every morning at 7, before I'm awake. It runs my research, drafts the week's short scripts, then stops and shows me the drafts. I read them with my coffee and thumbs-up the good ones. That's my content engine for the day.

The one honest note: a loop is only as safe as its guardrails. A good one knows the intent, has something that can say no, has skills worth calling, and can always stop.

You don't need to code to start. Pick the most boring thing you do every week, get one good result by hand, then wrap it in /loop.
