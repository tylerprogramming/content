Getting set up is fast. You paste one command to install it, one on Mac and one on Windows. You make a free Claude account, log in, and type claude to start. About two minutes.

Two things that make it feel safe when you are new. Plan Mode, which is Shift+Tab, shows you the plan before it touches anything. Escape cancels whatever it is doing if you change your mind. And slash commands give you quick shortcuts so you are not memorizing anything.
