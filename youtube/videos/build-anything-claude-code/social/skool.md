## POST 1 - The drop

If you have never opened a terminal before, start with this one. Seriously, do not skip it because it says beginner.

I made it for exactly that person. No coding background, no idea what any of this is.

We start from zero. First I show you what Claude Code actually is, which is a tool that lives in your terminal where you talk to it in plain English. You tell it what you want and it writes the code and builds it for you.

Then we install it together. One command on Mac, one on Windows. I walk through the pricing so you know what is free and what is not. You make a Claude account, log in, and type claude to start. That part is about two minutes.

Then we build something real. A countdown timer app. I type what I want in plain sentences and it builds the whole thing. When the timer hits zero, confetti. About ten minutes, and no code written by hand.

I also cover the small things that make it feel safe when you are new. Plan Mode with Shift+Tab lets you see the plan before anything happens. Escape cancels whatever it is doing. Slash commands give you the built in shortcuts so there is nothing to memorize.

## POST 2 - The tactic (try this today)

Here is the one keyboard shortcut I would give a new Claude Code user before anything else.

Shift+Tab.

It turns on Plan Mode. In Plan Mode, Claude does not touch anything. It writes out exactly what it intends to do, step by step, and then waits for you. You read the plan, and if you do not like it you press Escape and nothing ever happened.

That sounds like a small tip but it is the thing that makes people stop being nervous about the tool.

And the idea travels way past a first app. Most people use AI by asking, getting a result, and then working out whether the result was any good. You are checking the work after the fact, which is the slowest place to catch a mistake.

Plan Mode moves the check to the front. You approve an approach instead of auditing an output.

I do this on real work now. Before I let anything run on something that matters, I ask what it is about to do and why. Nine times out of ten it is fine and I say go. The tenth time it saves me twenty minutes of undoing.

Never expect these tools to be a hundred percent right. Plan mode is just the cheapest place to find out that they are not.
