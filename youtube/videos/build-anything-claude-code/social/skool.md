# Skool - Build ANYTHING With Claude Code (Beginner Tutorial)

**Video:** https://www.youtube.com/watch?v=XAcqU3zuZmE

---

I made this one for the person who has never opened a terminal before. If that is you, do not skip it.

We start from zero. I show you what Claude Code actually is, which is a tool that lives in your terminal where you just talk to it in plain English. You tell it what you want, and it writes the code and builds it for you.

Then we install it together, one command on Mac and one on Windows. I walk through the pricing plans so you know what is free and what is not. You make a Claude account, log in, and type claude to start. That part takes about two minutes.

Then we build something real. A countdown timer app. I type what I want in plain sentences, and it builds the whole thing. When the timer hits zero, you get confetti. About ten minutes, no coding.

I also show you the small things that make it feel safe when you are new. Plan Mode with Shift+Tab lets you see the plan before anything happens. Escape cancels whatever it is doing. Slash commands give you quick shortcuts so you are not memorizing anything.

This is a small first app and I know that. The point is not to impress you. It is to show you the door is already open.

So pick something small and just try it. What would you build first?
