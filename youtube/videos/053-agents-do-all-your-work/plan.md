## The concrete agents / real-work demos (what actually goes on screen)

All of these are things Tyler genuinely runs from this machine, so the demo is real, not staged.

1. **The morning briefing agent.** Reads Gmail overnight, checks Google Calendar for today,
   pulls open ClickUp tasks, and writes one short briefing: what happened, what is on today,
   what is slipping. This is the cold-open payoff, it is already sitting there before he wakes.
2. **The inbox triage agent.** Categorizes the last 24h of email (Action / Waiting / FYI /
   Promo) and drafts replies to the ones that need one. Admit live: it drafts, it does not
   send, you approve. That honesty is the trust beat.
3. **The content pipeline agent.** Updates `status.md`, syncs the matching ClickUp task, and
   drafts the social copy for a video that just went out. The boring ops job, done.
4. **The calendar agent.** Finds a free block and schedules the next recording session, in
   the right timezone, without the back-and-forth.
5. **A research subagent.** Kicked off in the background, goes and researches a topic, and
   returns just the report while the main agent keeps working. Shows the subagent pattern.

The spine that ties them together: an agent is just a markdown file plus a set of tools
(MCP). Once viewers see that, every demo feels doable, which is the whole point.

## Recommended runtime / format

**Recommended: a tight showcase-led build, target 30 to 40 minutes. NOT a 2-hour course.**

Reasoning:
- The 2025 original was a 2:08 course. The remake competes on retention against agent-demo
  videos that open with the payoff and move fast. A 2-hour course buries the hook.
- Format: cold-open payoff montage (agents already did the work) -> "here is what just
  happened" -> the one idea (an agent is a markdown file + tools) -> build agents 1 through 4
  live on screen, each one shown doing real work on his real apps -> the subagent pattern ->
  honest limits -> "steal my setup" CTA.
- Keep it a build, not a lecture. Every section ends with the agent actually running and a
  real result on screen. No slide-only stretches.
- If it overperforms, the natural follow-up IS the long-form "Full Agent Course" using the
  same title frame, so we keep the course option alive without spending the ceiling on it now.
