# Title Options

## 1. I Automated My Entire YouTube Workflow with Claude Code *(Recommended)*
- **Why it works:** "Entire" implies completeness, "YouTube Workflow" is immediately relatable to the target audience, and "Automated" is the dream state. Mirrors the proven format of Liam Ottley's "How to Automate Your Life & Work" (61K views).

## 2. I Run My YouTube Channel From a Terminal
- **Why it works:** Pattern interrupt. Nobody expects a YouTube channel to run from a terminal. Creates a curiosity gap — "how is that even possible?"

## 3. Claude Code Skills That Have Nothing to Do with Coding
- **Why it works:** Subverts the expectation that Claude Code = coding. Taps into the trending "non-coding use cases" content gap. Broad appeal.

## 4. The AI System Behind Every Video I Make
- **Why it works:** "Behind every video" implies a system worth seeing. Positions you as someone with a repeatable process, not just a one-off trick.

## 5. 3 Claude Code Skills Every Creator Needs
- **Why it works:** Numbered list with specific audience ("every creator"). Proven format on YouTube. Sets clear expectations for the viewer.
