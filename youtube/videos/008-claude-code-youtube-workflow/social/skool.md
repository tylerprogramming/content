# Skool - I Automated My Entire YouTube Workflow with Claude Code

**Video:** https://www.youtube.com/watch?v=MLfyfNj1JrI

---

I finally turned my whole YouTube research and planning into four commands.

It used to take me two or three hours before I even started writing. Open YouTube, click through a dozen videos, take notes, then outline everything from scratch in a Google Doc. Every single video, the same routine over again.

So I built four Claude Code skills to do it for me.

The first searches YouTube and hands me the newest videos on a topic sorted by views, so I can see what's working and what nobody has touched. The second pulls a full transcript of a top video, then I talk to Claude about its structure and where the gaps are. The third takes my topic and angle and writes the whole package, titles, hooks, a full script, and a filming guide. The fourth generates the thumbnail with Kie.ai.

Here's the fun part. This video was planned by that same system. The script came out of it, and so did the thumbnail.

I'm not selling a tool. These skills are just markdown files with instructions, so any of you can build the same thing for a workflow you repeat.

I dropped the setup and the exact skills in here. What part of your content process would you hand off first?
