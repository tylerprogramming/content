**Main tweet:**
I run my whole YouTube channel from a terminal. Research, competitor breakdowns, the full script, even the thumbnail. Four Claude Code skills do it, and this video was planned by the same system. Here's the pipeline:

**Reply 1:**
Skill one is /yt-search. One command hits YouTube, pulls the newest videos on a topic, and sorts them by views. I get a clean report of what's working, and just as useful, what nobody has covered yet. That gap is my angle.

**Reply 2:**
Skill two is /transcribe. I feed it a top video's URL, it pulls the audio and runs Whisper, and I get the full transcript. Then I actually talk to Claude about the structure and where the gaps are.

**Reply 3:**
Skill three is /yt. I give it a topic and my angle, it does its own web research, asks a few questions, then writes the whole package. Titles, hooks, script, filming guide. This script came out of it.

**Reply 4:**
Skill four is /thumbnail. It calls Kie.ai to generate options from a prompt, and I can remix any of them until one lands. The thumbnail you clicked to get here was made this way.

**Reply 5:**
Here's the honest part. These skills aren't magic and they aren't a tool I sell. They're just markdown files with instructions. Any of you can build the same thing for a workflow you repeat every week.
