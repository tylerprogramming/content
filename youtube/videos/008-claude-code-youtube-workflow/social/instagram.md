## Caption
How I do all my YouTube automation from one terminal, with a Claude Code workflow anyone can copy.

Swipe to see the full pipeline.

Starting a video used to mean hours of research. Open YouTube, click through a dozen videos, take notes, outline from scratch. So I built four Claude Code skills to handle it.

The first searches YouTube and sorts videos by views, so I can see what's working. The second pulls a top video's transcript so I can study the structure. The third writes the whole package, titles, hooks, script, and filming guide. The fourth generates the thumbnail.

The fun part is this whole video was planned by that same system, script and thumbnail included. This is content creation with AI where you keep every creative call, the skills just do the repeatable parts.

They're not a tool I sell. They're just markdown files, so you can build your own.
