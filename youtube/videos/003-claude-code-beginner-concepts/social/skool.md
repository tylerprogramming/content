# Skool - 10 Claude Code Concepts I Wish I Knew From the Start

**Video:** https://www.youtube.com/watch?v=ZlDnsf_DOzg

---

I used Claude Code for weeks before it actually clicked for me.

I was typing prompts, getting okay results, and quietly wondering why everyone else seemed to be getting so much more out of it. The tool wasn't the problem. I just didn't understand the concepts sitting underneath it.

So I put together the 10 that would have saved me all that time. CLAUDE.md, the one file Claude reads every session so you stop repeating yourself. Context rot, which is why Claude feels sharp for a bit then starts going weird. Permissions, so it stops interrupting you for the safe stuff. Then skills, hooks, MCP, sub-agents, git worktrees, and memory.

None of it is hard. It's just that nobody puts it in one place for a beginner. I demo every one with my real setup, not toy examples.

If you've been using Claude Code for a few weeks and still feel like you're guessing sometimes, this is probably why.
