**Main tweet:**
I've used Claude Code daily for months. And the first few weeks, I was doing it completely wrong. No CLAUDE.md, vague prompts, marathon sessions that slowly got worse. Here are 10 beginner concepts I wish I knew from the start:

**Reply 1:**
CLAUDE.md is the one file that changes everything. Claude reads it at the start of every session. Write your rules and preferences once, and you stop repeating yourself in every new chat.

**Reply 2:**
Context rot is why Claude feels sharp for 20 minutes then starts going weird. Its memory window fills up. Watch the little meter at the bottom. Run /compact, or just start a fresh session when you switch tasks.

**Reply 3:**
By default Claude asks before every action, which kills your flow. Pre-approve the safe stuff in settings.json, like reading files and running tests. It keeps asking before anything actually risky.

**Reply 4:**
Skills are the upgrade from slash commands. A markdown file that teaches Claude exactly how you do a task, once. Then you just invoke it. This is where Claude Code stops being a chatbot and starts being a system.

**Reply 5:**
Two more that clicked late for me. Hooks run automation without using any AI tokens, so formatting and logging just happen. And memory lets Claude remember how you work across every session.
