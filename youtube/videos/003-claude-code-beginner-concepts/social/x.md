# X/Twitter Thread — 10 Claude Code Concepts

**Main tweet:**
I've been using Claude Code daily for months. The first few weeks, I was doing it completely wrong. Here are 10 concepts I wish I knew from day 1:

---

**Reply 1:**
👉 CLAUDE.md - a file Claude reads every session automatically. Put your rules and preferences there once. You never have to repeat yourself again.

**Reply 2:**
👉 Context rot - after 2-3 hours Claude's output degrades. Your context window fills up. Start fresh sessions. This is why Claude seems to get dumber mid-project.

**Reply 3:**
👉 Skills - turn any workflow into a slash command. I type /yt-search and get a full research report in 30 seconds. Built it once, runs forever.

**Reply 4:**
👉 3 types of memory: context window (temporary), CLAUDE.md (permanent), memory skill (cross-session). Most people only ever use the first one.

**Reply 5:**
👉 Hooks run automation without using a single AI token. File saves, session starts - anything can trigger them. Separate from Claude entirely.
