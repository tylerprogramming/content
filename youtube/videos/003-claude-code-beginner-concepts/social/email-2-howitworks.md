## Email Body (paste into Resend)

```
Hey [first_name],

Following up on that Claude Code video, because a few of you asked which concepts actually matter most if you're just starting. Here are the three that changed everything for me, plainly.

First, CLAUDE.md. It's a file Claude reads at the start of every session. You write your rules and preferences in it once, and every new chat already knows how you work. Before I had one, Claude was guessing every single time.

Second, context rot. Ever notice Claude feels sharp for twenty minutes then starts going weird? That's the memory window filling up. There's a little meter at the bottom of the terminal. When it gets full, you run /compact to summarize the session, or you just start fresh when you switch tasks. That one fix explains most of the "Claude is getting worse" complaints.

Third, permissions. By default Claude asks before every action, which kills your flow. You pre-approve the safe stuff once, like reading files and running tests, and it only stops to ask before anything actually risky.

That's the foundation. Skills, hooks, MCP, sub-agents, git worktrees, and memory all sit on top of it, and I demo every one on my real setup here:

https://www.youtube.com/watch?v=ZlDnsf_DOzg

The starter guide and the skills I use every week are in my free community if you want to copy them:
```
