### Key Patterns

**What's performing:**
- Long-form courses (266K, 36K) — but these are 1-4 hours
- Interview/podcast format (215K, 126K) — Boris Cherny is the draw
- Short practical tutorials (204K, 92K, 66K) — specific, actionable, under 20 min
- Tips compilations (159K, 92K) — numbered lists perform well

**What's NOT there:**
- Nobody is showing Claude Code for content creation workflows
- Every video is about coding, app building, or general AI automation
- No creator-specific use cases
- No "full pipeline" demonstrations showing multiple skills chained together
- No meta/self-referential videos

**This is the gap.** The angle of "I run my YouTube channel from my terminal" is completely unoccupied.

## Web Research Findings

### Claude Code Skills Ecosystem (2026)

The skills ecosystem has matured significantly:
- SkillsMP marketplace has 60-87K+ skills available
- Anthropic published an official "Complete Guide to Building Skills for Claude"
- Boris Cherny (Claude Code creator) uses slash commands for every inner-loop workflow
- Skills can execute code, call external APIs, and automate research across platforms

### Non-Coding Use Cases Are Trending

Multiple articles and guides document non-coding use cases:
- "50+ Mind-Blowing Things People Are Using Claude Code For (That Have Nothing to Do With Coding)" — MasteringAI
- "How to Use Claude Code for Everyday Tasks—No Programming Required" — Every.to
- "Claude Code Without the Code" — Nate's Newsletter
- Anthropic's own teams use Claude Code for marketing automation, content creation, and data analysis

This validates the angle: there's written content about non-coding uses, but very little YouTube content.

### AI YouTube Automation Landscape

83% of creators now use AI in some part of their workflow (Digiday 2025 report). But the tools landscape is fragmented:
- Separate tools for scripts (Jasper, ChatGPT)
- Separate tools for thumbnails (Canva, Kie.ai)
- Separate tools for editing (FireCut, Munch)
- Separate tools for research (manual browsing)

**Nobody is showing a unified system.** Claude Code with custom skills is the integration layer that connects all of these into one pipeline. That's the pitch.

### Community Sentiment

- Reddit r/ClaudeAI is active with workflow discussions
- Skills are being called "the most underleveraged feature" (Matt Maher's video title)
- Content creators are a growing segment of Claude Code users but underserved by tutorials
- The "awesome-claude-skills" GitHub repos have hundreds of community-contributed skills

---

## Content Gaps & Opportunities

1. **Creator-specific workflows** — Nobody is showing research → planning → scripting for content
2. **Multi-skill pipelines** — Individual skills are covered; chaining them together is not
3. **Meta/self-referential format** — No video has used "this video was made with the system I'm showing you"
4. **Non-coder audience** — Written content exists but YouTube is underserved
5. **Real workflow vs. demo** — Most tutorials use toy examples; showing YOUR actual workflow is differentiated
