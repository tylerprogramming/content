## Recommended

1. **Run OpenAI's Agents API on Your Own Mac in 3 Steps** (50 chars)
   Second person, transformation verb, the product noun that has demand, and a small number that caps perceived effort. It names the gap: every English video uses OpenAI's hosted sandbox, and the docs say the environment "can be a laptop." The build is exactly three steps on camera, so the number is checkable.
   Variant if the dry run lands under ten minutes: **Run OpenAI's Agents API on Your Own Mac in 10 Minutes** (52). Do not use the time box until it has been timed once; the research flags it as unverified.

## Alternatives

2. **You Don't Need OpenAI's Agents API (Hermes Does This on Your Mac)** (64 chars)
   Second-person accusation plus replacement framing. Converts 057 viewers directly. Weakness: it spends the title on Hermes, so the Agents API search click is weaker, and it reads as an opinion video. Best B-test after day 7, because it swaps strategy (accusation vs term-led), which is the only swap the brain allows.

3. **I Tested OpenAI's Agents API vs Claude Managed Agents vs Hermes** (62 chars)
   The allowed "I Tested X vs Y" shape. Nobody has compared runtimes on camera (0 of 14). Weakness: it needs a real Claude Managed Agents run, which adds a day of prep. Use if Tyler wants the wider net and has the day.

4. **Turn Your Mac Into an OpenAI Cloud Agent in 3 Steps (Agents API)** (64 chars)
   Transformation verb, the biggest lever in the competitor set. Product noun only fits as a parenthetical, so it is weaker in search than option 1. Use if the thumbnail carries "AGENTS API" and the title can afford to be the promise.

5. **OpenAI's Agents API Runs on Your Mac. Nobody Showed You HOW** (59 chars)
   Curiosity gap with the one late caps word. Weakness: "nobody showed you" is a claim about other videos, which is meta, and no ease qualifier. Shorts or Community post title, not the upload.

## Do not use

- Anything with bare "OpenAI Agents" (rogue-agent news pollution).
- "OpenAI Agents API Explained" (rule 2; Mathify and One Layer Down already are the explainers at 7.5k and 152).
- A straight launch title ("OpenAI Just Launched..."). Day 5, and OpenAI's own 2:18 has 276k.
- "in 10 Minutes" before it has been timed.
