# Filming Guide: Claude Code Getting Started

---

## Screen Recordings Needed

### SR-01: Terminal Introduction
- Open a fresh terminal (Mac: Terminal.app or iTerm; show both briefly)
- Show the blank screen — "this is it, just a text prompt"
- Type `ls` to show it does something, `pwd` to show where you are
- **Pace: real-time, ~30 seconds**

### SR-02: Node.js Installation
- Open browser, go to nodejs.org
- Click download button, run installer
- Open terminal, type `node -v`, show version output
- **Pace: speed up the installer at 4x, real-time for the terminal verification**

### SR-03: Claude Code Installation
- Type `npm install -g @anthropic-ai/claude-code`
- Show it installing (speed up)
- Type `claude`, press enter
- Choose dark mode
- Sign in with Claude account
- Show the success screen
- **Pace: speed up npm install at 4x, real-time for setup prompts**

### SR-04: Project Setup
- `mkdir my-first-app && cd my-first-app`
- `git init`
- Type `claude`
- Trust directory prompt — press 1
- **Pace: real-time, ~20 seconds**

### SR-05: First App Build (THE MONEY SHOT)
- Type the countdown timer prompt
- Show Claude working — creating files, writing HTML/CSS/JS
- **Pace: real-time for typing the prompt, 2-3x speed for Claude generating code, real-time when it finishes**

### SR-06: App Running in Browser
- Open the HTML file in browser (or run dev server if Claude sets one up)
- Show the countdown timer working with animations
- Interact with it briefly
- **Pace: real-time, let it breathe — this is the payoff moment**

### SR-07: Key Concepts Demo
- Show Shift+Tab toggling plan mode on/off
- Show a permission prompt appearing (Claude asking to run a command)
- Type `/clear` and show context resetting
- Type `/help` briefly
- Press Escape to cancel something
- **Pace: real-time, ~60 seconds total**

## Face-to-Camera Segments

### FTC-01: Hook [0:00 - 0:30]
- High energy, direct eye contact
- "Claude Code is the most powerful AI coding tool right now..."

### FTC-02: What is Claude Code [0:30 - 1:30]
- Explanatory tone, slightly more relaxed
- Can use hand gestures to emphasize "it reads your whole codebase" / "writes across multiple files"

### FTC-03: Terminal Pep Talk [1:30 - 2:30]
- Reassuring energy — "I know the terminal looks like a hacker movie..."
- Lean in slightly, like you're letting them in on a secret

### FTC-04: Post-Build Celebration [after SR-06]
- Genuine excitement — "You just built your first thing with AI. That's it. That's how easy it is."

### FTC-05: Outro [9:30 - 10:30]
- Wrap energy — recap, plug part 2 video, CTA

## Editing Notes

| Section | Speed | Notes |
|---------|-------|-------|
| Hook | Normal | Hard cuts, no fancy transitions |
| Terminal intro | Normal | Let it breathe — viewers need to see it's not scary |
| Node installer | 4x speed | Nobody needs to watch an installer progress bar |
| npm install | 4x speed | Same — speed through the package download |
| Claude setup prompts | Normal | Viewers need to follow along |
| Typing the first prompt | Normal | This is a key moment — let them read it |
| Claude generating code | 2-3x | Show enough that it's impressive, not so much it's boring |
| App in browser | Normal | THE PAYOFF — hold on this, let it land |
| Key concepts | Normal | Quick demo of each, don't linger |

### Transitions
- Hard cuts between sections (no dissolves or wipes)
- Use subtle zoom-ins on important terminal commands
- Text overlay for key commands viewers should remember (`Shift+Tab`, `/clear`, etc.)

### Audio
- Upbeat but not distracting background music during screen recordings
- No music during face-to-camera explanations
- Satisfying "click" or "whoosh" SFX when the app first appears in browser

## Pre-Production Checklist
- [ ] Uninstall Node.js so you can show a fresh install on camera
- [ ] Clear terminal history (`history -c` or fresh profile)
- [ ] Clean desktop — no distracting files/folders visible
- [ ] Test the countdown timer prompt beforehand to make sure Claude builds something visually impressive
- [ ] Have VS Code open as a backup to show terminal integration
- [ ] Prepare both Mac terminal and mention Windows equivalent commands
- [ ] Have nodejs.org bookmarked for quick navigation
- [ ] Test screen recording software — make sure terminal text is readable at YouTube resolution
- [ ] Set terminal font size to at least 16pt for readability on screen
