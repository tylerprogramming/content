# LinkedIn Post — Claude Code for Beginners

## Text Post (with video link)

Most people are using Claude Code wrong.

They open the terminal, type something like "build me an app," and wonder why the output is a mess.

Here's the truth: the model isn't the problem. The plan is.

Garbage in, garbage out — and Claude Code is no different.

Here's the workflow that actually works:

**1. Plan before you code.**
Use Claude's AskUserQuestion tool to have it interview you about your project before writing a single line. The questions feel tedious. That's the point. Every question Claude asks is a decision you'd have had to make later — except later, Claude would have guessed wrong.

**2. Build feature by feature.**
Don't prompt "build the whole app." Prompt "build feature one." When it works, write tests. When tests pass, commit. Then move to feature two. This rhythm saves hours of debugging.

**3. Earn autonomous mode.**
The viral "Claude built my entire app while I slept" videos are real — but they only work if your plan is bulletproof. Run Claude autonomously on a bad plan and you're just burning tokens. Get your reps in manually first.

**4. Treat it like a senior engineer.**
Don't say "make it work." Say "implement this feature using this approach, handle these edge cases, write tests for these scenarios." Specificity wins. Always.
