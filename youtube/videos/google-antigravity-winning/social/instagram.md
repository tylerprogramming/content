## Caption
How I built an agentic AI workflow with Google Antigravity, without writing the code myself.

Swipe to see the full build.

Google Antigravity is a platform for AI workflow automation. You describe the outcome you want, and it figures out the steps, writes the code, and runs it. The goal I gave it was simple. Pull data from YouTube, evaluate it, and save a summary into a Google Sheet.

I downloaded Antigravity, made a project folder, and added an agent markdown file with the goal in plain language. Then I let it plan. It laid out every step before touching anything, which APIs it needed, where the keys go, how it would wire up the Sheet.

Setup wasn't zero. I turned on the YouTube Data and Google Sheets APIs in Google Cloud and added the keys, and it walked me through it. Then I ran it. It hit a problem partway through and fixed itself. The final output was clean.

If agentic AI is something you've wanted to try, this is a solid place to start.
