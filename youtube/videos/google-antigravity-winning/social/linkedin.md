**Best time:** Tue-Thu 10-11 AM ET. Put the link in the first comment if reach dips.

I didn't think I'd be writing this about a Google product.

But I built an agentic workflow with Google Antigravity this week, and it genuinely impressed me.

Here's what an agentic workflow actually is. You describe the outcome you want. The AI figures out the steps, writes the code, and runs it for you.

The goal I gave it was simple. Pull data from YouTube, evaluate it, and save a summary into a Google Sheet.

I started by downloading Antigravity, creating a project folder, and adding an agent markdown file.

That file is just me writing the goal in plain language. No code yet.

Then I let it plan.

And the planning is the part that got me. It laid out every step before it touched anything. Which APIs it needed, how it would wire up the Sheet, where the keys would go. I could read its thinking the whole way through.

Setup wasn't zero effort. I had to turn on the YouTube Data and Google Sheets APIs in Google Cloud and add the credentials. That's usually where people get stuck, and it walked me through it.

Then I ran it.

It hit a problem partway through, and it fixed itself. No panic on my end, no digging through errors.

The final output was clean. Real data pulled, evaluated, and summarized into a Sheet.

I'm not saying Google has won everything. But on this, with this tool, they're further ahead than I expected.

If you build agentic workflows, or you've wanted to, this is worth a look.
