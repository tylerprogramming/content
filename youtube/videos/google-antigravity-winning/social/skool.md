# Skool - Google is Winning With Antigravity

**Video:** https://www.youtube.com/watch?v=B5eDktBzXMg

---

I didn't expect to be impressed by a Google tool this week, but here we are.

I built a full agentic workflow with Google Antigravity, and I want to walk you through it because it's more doable than it sounds.

An agentic workflow is a simple idea. You describe the outcome you want, and the AI figures out the steps, writes the code, and runs it. The goal I gave it was to pull data from YouTube, evaluate it, and save a summary into a Google Sheet.

I started by downloading Antigravity, making a project folder, and adding an agent markdown file. That file is just me writing the goal in plain language. No code. Then I let it plan.

The planning is the part that got me. It laid out every step before touching anything, which APIs it needed, how it would wire up the Sheet, where the keys go. I could read its thinking the whole way.

Setup wasn't zero. I had to turn on the YouTube Data and Google Sheets APIs in Google Cloud and add the keys. That's usually where people get stuck, and it walked me through it.

Then I ran it. It hit a problem partway through and fixed itself. The final output was clean, real data pulled, evaluated, and summarized into a Sheet.

I dropped the agent markdown and the exact prompt in here so you can copy it.
