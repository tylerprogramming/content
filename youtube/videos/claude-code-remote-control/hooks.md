# Hook Options: Claude Code Remote Control

---

## Hook 1: The Demo-First Hook (Recommended)

**Technique:** Show don't tell — immediate proof

> I'm on my couch right now. My laptop's in the other room. And I'm about to push code to production.
>
> Watch this.
>
> [SHOW: Phone screen — typing a message in Claude app, Claude responds, runs a command, shows output]
>
> That's not a remote desktop app. That's not SSH. That's Claude Code running on my laptop — and I'm controlling it from my phone.
>
> Let me show you how this works.

**Why it works:** Immediate visual proof. The "couch to production" contrast is relatable and slightly absurd. Sets up the "how is this possible?" question.

---

## Hook 2: The Problem-Solution Hook

**Technique:** Pain point → relief

> You know that thing where you start a task in Claude Code, and then you have to leave your desk? Maybe it's a meeting. Maybe it's lunch. Maybe you just need to use the bathroom.
>
> And the whole time you're thinking — is it done? Did it break? Should I go back and check?
>
> I don't have that problem anymore.
>
> [SHOW: Phone notification, open Claude app, see the session running]
>
> Now I just check my phone.

**Why it works:** Universal developer experience. The bathroom line adds humor. "I don't have that problem anymore" is a strong transformation statement.

---

## Hook 3: The Bold Claim Hook

**Technique:** Provocative statement that demands explanation

> Claude Code just turned my phone into a terminal.
>
> [SHOW: Phone screen with Claude Code session active]
>
> Not a toy terminal. Not a read-only dashboard. An actual terminal where I can run commands, approve changes, and ship code — all while my laptop is in another room running the session.
>
> This changes how I work. Let me show you.

**Why it works:** "Turned my phone into a terminal" is a strong reframe. The "not a toy" clarification preempts skepticism. Short, punchy, gets to the point.

---

## Recommendation

**Go with Hook 1.** The couch-to-production visual is immediately compelling, and starting with the demo mirrors the energy of your skills video. It also creates the "wait, how?" moment that keeps people watching.
