# Hook Variations: Claude Code Getting Started

---

## Hook 1: "The Terminal Isn't Scary"
> Claude Code is the most powerful AI coding tool right now, but most people never get past the install screen. The terminal freaks them out. Today I'm going to fix that. In the next ten minutes, you're going to install Claude Code and build your first app — even if you've never opened a terminal in your life.

[SCREEN: Quick montage — terminal opening, Claude Code running, countdown timer app appearing in browser]

---

## Hook 2: "Everyone's Using It Wrong"
> Everyone's talking about Claude Code but nobody's showing you how to actually get started. They assume you know what a terminal is. They assume you know what npm means. I'm assuming nothing. By the end of this video, you'll have Claude Code installed and you'll have built something with it. Let's go.

[SCREEN: Face to camera, then cut to clean empty terminal]

---

## Hook 3: "10 Minutes"
> Ten minutes. That's all it takes to go from "I've never used a terminal" to "I just built an app with AI." I'm going to walk you through every single step — installing Claude Code, understanding the basics, and building your first project. No experience needed. Let's do it.

[SCREEN: Timer overlay showing 10:00, quick flash of the finished app]

---

## Hook 4: "What If I Told You"
> What if I told you that you could build a fully functional web app without writing a single line of code yourself? Not with some drag-and-drop builder — with an AI agent that actually writes real code for you. That's Claude Code, and I'm going to show you exactly how to set it up from scratch right now.

[SCREEN: Split — left side shows Claude Code writing code, right side shows the finished app]

---

## Hook 5: "I Was You"
> I remember the first time I saw someone use Claude Code. They typed a sentence into a black screen and a full app appeared. I thought, there's no way I can do that. But here's the thing — it's way easier than it looks. And today, I'm going to prove it to you.

[SCREEN: Face to camera, genuine energy, then cut to terminal]

---

## Recommendation
**Hook 1 or Hook 3** — both directly address the viewer's fear and give a concrete time promise. Hook 3 is punchier for retention. A/B test Hook 3 (short, punchy) vs Hook 5 (relatable, story-driven).
