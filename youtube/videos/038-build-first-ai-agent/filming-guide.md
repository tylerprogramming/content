# Filming Guide - Build Your First AI Agent (The Easy Way, No Code)

Target runtime: 10-13 min. Showcase build, warm and reassuring energy. The whole job of this video is to make a total beginner feel "oh, I can actually do this." Kill intimidation at every beat.

## The exact agent you're building live
A Research Agent. One job: you give it a topic, it searches the web, reads real sources, and writes a one-page brief with the key points and links back to where each point came from.

Why this one: useful to everyone, clearly an agent (goal + a tool + it picks its own steps), and clean to film (no personal inbox, no auth, no API keys on camera).

It is three things, and that's the whole build:
1. A folder to live in (e.g. research-agent).
2. One plain-English instructions file (the "who you are and what to do" file). Real text used in the script's Step 1.
3. One tool turned on: web search.

Then you run it with a real topic, read the output, and nudge it once on camera.

## Before you hit record (do this, it de-risks the whole shoot)
- Pre-run the exact topic prompt once off-camera to confirm the agent behaves and the brief comes out clean. Use the same topic on camera.
- Save a real backup brief from that pre-run. If the live run stalls or hangs, you cut to the real backup, never a mockup.
- Pick a relatable, non-technical topic so the audience stays with you. Suggested: "the best free tools for someone starting a newsletter in 2026." Swap to whatever feels most on-brand, just keep it beginner-relatable.
- Clean desktop. Close everything except Claude Code and the folder. Nothing on screen should look intimidating.
- Have the free doc / lead magnet ready (the instructions file + setup) so the CTA points somewhere real.

## Shot list

### Talking-head (camera on Tyler)
- Cold open (word for word from script). Warm, confident, a little "let me settle this for you."
- The "what an agent actually is" explainer (three parts). Calm, teaching a friend.
- The zoom-out / "what you just built" beat.
- The honest limitations beat. This one slows down, straight to camera, no B-roll. Most sincere moment in the video.
- The CTA + "build one this week" close.

### Screen recording (the build - this is the retention zone)
Record clean at high res, cursor visible, font size bumped up so it's readable on a phone. Capture:
1. Making the folder (name it something plain).
2. Creating the instructions file and typing it out in plain English (say each line as you type, per script Step 1).
3. Turning on / confirming the web search tool. Keep it non-technical on screen.
4. Running the agent live with the real topic. Let the web-search steps be visible so viewers see it "thinking" and choosing its own steps.
5. The finished one-page brief, scrolled slowly, sources visible. Read a couple of real lines.
6. The nudge: type the plain-English correction live, show it fixing the brief.

### Cutaways / graphics (editor)
- Cold open: an intimidating framework diagram / wall of code that gets swept off screen. Sets up the reframe visually.
- The three-part graphic: goal / a tool / plain English. Build it on screen during the explainer, bring it back in the zoom-out.
- Simple lower-thirds for each build step (Step 1: give it a job, Step 2: give it a tool, Step 3: run it).

## Energy and pacing notes
- Warm and reassuring, not hyped. Never "this is insane." Always "see, that wasn't bad, right?"
- The build must feel FAST and easy. Speed-ramp or cut Claude's thinking time so nothing drags, but never fake the output. If it stumbles live, keep it and narrate the nudge. Honest beats polished here.
- Use the Fortune-500 credibility line exactly twice (cold open + the explainer). Keep it plain both times. Authority, not a flex.
- Slow down only once: the honest limitations beat. Let it breathe. It earns the trust for the whole video.
- Keep returning to the same idea: an agent is just a goal, a tool, and plain-English instructions. That repetition is what makes the beginner feel they've truly got it.

## Honesty checklist (do not ship without these)
- No dollar amounts, no income claims, anywhere on screen or in narration.
- No "set it and forget it." It's a fast assistant you steer, said out loud.
- The "don't make things up, tell me when you're unsure" instruction is visible in the real file and called out on camera.
- The nudge beat shows the agent being imperfect and getting corrected. Keep it in.
- The limitations section stays in full. It is the brand.
