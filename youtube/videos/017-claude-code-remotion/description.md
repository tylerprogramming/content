# YouTube Description

Claude Code + Remotion is a free, open-source combo that lets you build animated video content from your terminal. In this video I build animated text overlays for YouTube Shorts from scratch, show my reusable component library (WordByWord, SlamText, GradientReveal, and more), render everything with a single terminal command, and show how it fits into a full content automation pipeline.

## In this video:
- Why programmatic video beats traditional video editors for creators
- Installing Remotion from scratch (one command)
- Building animated text overlay components with Claude Code
- The reusable component library: WordByWord, SlamText, HighlightText, CountUp, GradientReveal, StrikeReplace
- Composing a full 30-second YouTube Short from components
- Rendering to MP4 from the terminal in 30 seconds
- Swapping text to create multiple versions instantly
- How this fits into a 22-skill content automation pipeline
