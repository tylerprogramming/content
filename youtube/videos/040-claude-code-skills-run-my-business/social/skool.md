## Post 1 - Video day (RECOMMENDED)

Every task I did twice this year turned into a text file.

That is the short version of the new video. I opened up the actual folder that runs my content business, 17 Claude Code skills, and walked through what each one does.

The part I want you to take from it is how unimpressive the files are. A skill is a folder with one file in it called SKILL.md. The top says when to use it, in plain English. Underneath that is just the instructions, the same thing you would tell someone you were training.

No install, no code. You write it once and it is a command forever.

A few of mine run on a schedule when I am not at my desk. Those default to draft mode, so the work gets found and drafted, and I still read everything before it goes anywhere. That balance is the whole trick for me.

They are not perfect either. I would say they get me 80 percent there and I handle the last bit.

In the video I build one from scratch in about two minutes so you can see how little there is to it.

If you are picking a first one, do not go big. Pick the small thing you already did twice this week.

## Post 2 - Discussion starter (no video needed)

Here is a test I have been using for what to automate.

If I did it twice this month by hand, it should be a text file.

Not "is this impressive enough to automate" and not "could AI do this perfectly." Just, did I already repeat it.

Most of the skills running my business now came out of that question. None of them were planned. I got annoyed doing something a second time, wrote the instructions down, and it became a command.

The other half of it is that you stop being the person doing the task and start being the person reviewing the result. That sounds small but it changes how the day feels. The work still needs your judgment, it just does not need your hands for the first pass.

Everything I run defaults to draft mode for that reason. It finds and it writes, I approve.

So what is the thing you did twice this month?

That is your first skill, and it is genuinely just a text file. If you post it below I will help you write it.
