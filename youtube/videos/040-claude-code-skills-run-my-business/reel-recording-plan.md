## BLOCK A — the wall + what a skill is (Finder + editor open)

**Reel 1 — "17 text files run my business" (umbrella, flagship)**
- **Hook:** "This is the actual Claude Code that runs my content business. 17 skills, and none of it is code."
- **Capture:** fast scroll of the skills folder, then 4 quick flashes — a research report, a script file, a scheduled post, the Skool dashboard.
- **Payoff:** "They're just text files. If you can write instructions, you can build every one of these."

**Reel 3 — "What a skill actually is" (demystifier)**
- **Hook:** "Everyone's talking about Claude skills. Here's what one actually is."
- **Capture:** open a real `SKILL.md`, scroll slowly, point at the description line then the instructions.
- **Payoff:** "That's the whole thing. A text file that becomes a command."

**Reel 4 — "Build one in 2 minutes" (live build)**
- **Hook:** "Let me build one right now so you can see how simple this is."
- **Capture:** make the folder, make `SKILL.md`, type the one-line description + instructions, save, run it. Don't cut away from the typing.
- **Payoff:** "Two minutes. Every skill I showed you started exactly like that."

## Recording tips
- Lead every reel with the demo. Command in → hard-cut to the finished result. No dead air, no "so today I'll show you."
- The hook + payoff are voiceover; you can record VO after, over the screen capture.
- Target 45-90s each; Reel 1 and Reel 4 can run to 2 min.
- End on the payoff line. CTA goes in the caption, not the clip.
