# Hooks (first 30 seconds)

> Read/memorize word for word. Each uses a different opening technique.

---

## Hook 1 - Pattern interrupt / anti-demo (RECOMMENDED)
*Technique: call out the genre, then flip it with real proof.*

> "This is the actual Claude Code that runs my content business. 17 skills that research my videos, write my posts, reply to my comments, and run my community. And none of it is code, they are just text files. If you can write instructions, you can build every one of these. Let me show you."

---

## Hook 2 - Bold claim / proof-first
*Technique: lead with the outcome, back it immediately.*

> "This one folder on my computer runs my entire content business. It researches what to make next, writes the script, generates the thumbnail, schedules a week of posts, and replies to comments while I sleep. It's 17 Claude Code skills, and it cost me nothing but a few text files to build. No team, no coding degree. In the next few minutes I'll show you exactly what's inside and how you'd build your own."

---

## Hook 3 - Story open / relatable
*Technique: start in the pain, resolve into the system.*

> "A year ago I was doing everything by hand - researching videos, writing every post, chasing comments, updating my community. It was a full-time job on top of my full-time job. Then I started turning each of those chores into a Claude Code skill. One command instead of an afternoon. Now 17 of them run the whole thing, and none of it is code, it's just text files anyone can write. Let me walk you through the exact system so you can copy it."

---

**Delivery notes:**
- The line that unlocks the audience is "it's just a text file, you don't need to be an engineer." Say it with conviction, early.
- Keep energy up but grounded - the whole edge is that this is *real*, so don't oversell.
- On "17 skills," cut to the actual `~/.claude/skills/` folder or a `/help` list on screen for instant proof.
