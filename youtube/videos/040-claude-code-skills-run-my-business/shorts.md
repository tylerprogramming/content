# Shorts / Reels — 17 Skills (from 040)

Cut from the 040 footage. Target ~1-2 min each. **Lead with the demo** — show the skill running and the result on screen, keep the talking to voiceover. Film the command going in, hard-cut to the finished result, no dead air. All skills below are real (verified against `~/.claude/skills/`).

Priority to post first: **Reel 1 (umbrella), then 2, 3, 5.**

---

## Reel 1 — "17 skills run my whole business" (umbrella, flagship)
**Hook:** "This is the actual Claude Code that runs my content business. 17 skills, and none of it is code."
- **Show:** fast scroll through the skills folder / montage flipping the list.
- Say: they find my ideas, write my videos, make my thumbnails, post everywhere, and answer my comments and email.
- **Payoff:** "They're just text files. If you can write instructions, you can build every one of these. Let me show you a few."

## Reel 2 — `/yt-search` → "AI finds my next video" (demo)
**Hook:** "I don't guess what to make anymore. I ask Claude what will actually work."
- **Show:** run `/yt-search` on a topic → ranked results by views + the content gaps it surfaces.
- Say: it sorts by what's performing and flags what nobody's covered well yet. Zero API cost.
- **Payoff:** point at a gap. "That's my next video, and I didn't guess."

## Reel 3 — `/yt-package` → "AI writes the entire video" (demo)
**Hook:** "One command, and Claude writes the whole video. Titles, hooks, script, even the filming guide."
- **Show:** run `/yt-package` → cut to the package files (`titles.md`, `hooks.md`, `script.md`, `filming-guide.md`).
- Say: it studies a reference, then writes the titles, the hooks, the full script, and a shot-by-shot filming guide.
- **Payoff:** open `script.md`. "That used to take me a full day."

## Reel 4 — `/social-copy` → "One video, every platform" (demo)
**Hook:** "I record one video and Claude writes the posts for every platform."
- **Show:** run `/social-copy` → X, LinkedIn, Instagram, community, and the email all generated into the folder.
- Say: same video, reshaped for each place it lives, in my voice.
- **Payoff:** scroll the folder of finished posts. "I didn't write a single one of these."

## Reel 5 — `/email` → "My inbox drafts its own replies" (demo) [replaces the old hook-maker reel]

- Say: it reads the thread, writes a reply that sounds like me, and waits for my okay.
- **Payoff:** "I read it, hit send, done."
