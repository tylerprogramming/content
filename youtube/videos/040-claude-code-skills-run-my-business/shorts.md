# Shorts / Reels — 17 Skills (from 040)

Cut from the 040 footage. Target ~1-2 min each. **Lead with the demo** — show the skill running and the result on screen, keep the talking to voiceover. Priority order: 1, 2, 4 first.

---

## Reel 1 — "17 skills run my whole business" (umbrella, flagship)
**Hook:** "This is the actual Claude Code that runs my content business. 17 skills, and none of it is code."
- **Show:** fast scroll through the skills folder / a montage flipping the list of 17.
- Say: they research my videos, write my posts, reply to my comments, and run my community.
- **Payoff line:** "They're just text files. If you can write instructions, you can build every one of these."
- Close: "I'll show you a few."

## Reel 2 — "One prompt, a week of content" (demo)
**Hook:** "I type one command and Claude writes a full week of content. Watch."
- **Show:** type `/yt-search`, cut to results → `/yt-package`, cut to the finished package files → `/social-copy`, cut to the posts.
- Keep dead air out: film the command going in, hard-cut to the finished folder.
- Say (VO over the cuts): research, full script, then every platform's posts, from one chain.
- **Payoff:** open the folder full of finished files. "That used to be my whole week."

## Reel 3 — "Claude replies to my YouTube comments" (demo)
**Hook:** "I don't write my own YouTube replies anymore."
- **Show:** run `/yt-replier` → it pulls real comments → drafts replies in my voice (draft mode ON, nothing auto-posts).
- Say: it reads the comment, writes a reply that sounds like me, and I just approve.
- **Payoff:** scroll the drafted replies. "I read them, hit send, done."

## Reel 4 — "I built a new AI skill in 2 minutes, live" (demo)
**Hook:** "Watch me build a brand-new Claude skill from scratch, right now."
- **Show:** run `/hook-maker` (the build-a-skill demo) → a new SKILL.md appears → run it → it works.
- Say: a skill is just a folder with instructions. I describe what I want, and now I have a reusable tool.
- **Payoff:** "That's it. That's a skill. You just watched me make one." High save/share.

## Reel 5 — "What a 'skill' actually is" (demystifier)
**Hook:** "Everyone's talking about Claude skills. Here's what one actually is."
- **Show:** open a real SKILL.md file on screen. Scroll it slowly.
- Say: it's plain English instructions in a text file. That's the whole thing. No code.
- **Payoff:** "If you can write a set of directions, you can build one."

## Reel 6 — "These run while I sleep" (demo)
**Hook:** "There are jobs running on my computer right now that I never touch."
- **Show:** `crontab -l` in the terminal → then a monitor firing (a comment or email job kicking off on its own).
- Say: the comment checker and the email triage run on a schedule, on their own.
- **Payoff:** "I wake up and the work is already drafted."
