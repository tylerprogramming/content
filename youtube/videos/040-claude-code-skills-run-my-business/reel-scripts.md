# Reel Scripts — 17 Skills (from 040)

Word for word, ready to record. Plan and post order live in `shorts.md`.

**How to read these:** everything in **SCREEN** is what you're capturing. Everything under **SAY** is
voiceover you record over it. Say it the way it's written, then say it again looser if the first take
feels stiff, and use whichever one sounds more like you.

**Rules:** the first line lands in the first two seconds, over the demo already running. No "hey guys."
No "in this video." End on the payoff line and stop talking. The CTA goes in the caption, not the audio.

**Nine reels, not ten.** The tenth was `/skool`, which is not a real skill in `~/.claude/skills/`.
Nothing else in the folder fit that slot well enough to force it, so it's parked. See the note at the
bottom — the same gap still sits in Part 3 of the long form.
