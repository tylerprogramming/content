**Title:** Cloud or Local? When to Use /schedule vs /loop in Claude Code
**Description:**
Same model, same instructions, two surfaces, and one question decides which. Ask whether you need to be there. If the job is collect, sort, summarize, deliver, put it on a schedule with /schedule and it runs on the cloud while your laptop is off. If you need to watch it and steer it, run it locally with /loop. Save this reference card.
