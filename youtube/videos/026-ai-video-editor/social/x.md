I'm not a video editor and I didn't build a tool.

My videos still get their dead air cut and captions added. I talk to Claude Code and it edits. Here's the whole thing:

**Reply 1:**
I drop a raw clip into HyperFrames, HeyGen's open-source video tool. Then I ask Claude Code to cut the silence. A 3 minute clip drops to under 2.

**Reply 2:**
For captions I copy a style prompt from the registry and paste it in. It transcribes with Whisper so the words line up, then wires them onto the clip.

## POST 2 - Standalone, the honest line (no link)

I stopped editing my own videos. I did not get better at editing.

I stopped doing the two mechanical parts, cutting dead air and adding captions. A computer should have been doing those the whole time.

## POST 3 - Standalone, the silence tip (no link)

If you need to find silence in audio, don't use the transcript.

Whisper stretches words across the pauses so the gaps vanish inside them. Measure actual loudness instead. That's the difference between clean cuts and garbage.
