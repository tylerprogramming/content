## What Claude Tag is
An AI teammate that lives in Slack. Type `@claude` in a channel to delegate a task. It:
- Remembers the channel, learns the work over time, can pull from other channels + connected tools (with permission)
- Works async — schedules tasks for itself, runs projects over hours/days
- Multiplayer — one Claude per channel, shared context, anyone can tag it and hand off
- Proactive ("ambient") — pings you about things it thinks you need
- Runs on Opus 4.8. Replaces the old "Claude in Slack" app (switchover Aug 3, 2026). Currently beta.
- Headline stat: **65% of Anthropic's product team's code is written by their internal version.**
