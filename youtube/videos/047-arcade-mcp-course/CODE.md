# Course code

The runnable code for this course lives in its own public repo:

**https://github.com/tylerprogramming/arcade-course**

```
git clone https://github.com/tylerprogramming/arcade-course.git
```

It contains all five modules — connect apps to Claude Code (gateway), build your own `arcade-mcp` server, the LangChain + CrewAI agents (`arcadepy`), and the scheduled **Morning Planner** — plus the uv/`pyproject.toml` setup, the VPS deploy notes (`deploy/`), and a copy-paste `INSTALL.md`.

> The code used to be mirrored in this package under `project/`. It now lives **only** in the repo above, so this content repo stays docs-only (script, hooks, research, blueprint, SEO). One source of truth for the code.
