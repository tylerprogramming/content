## Rules for 0:41 - 2:00 (the part that killed the MCP video)

The second minute is where our last video collapsed into a 48-second graphic-free screen-share. Do NOT
repeat that. For the entire first module demo:

- **Keep your webcam as a PIP** bottom-right on every screen-share (Nate's Non-Coders trick) so the
  face never fully disappears.
- **Zoom-punch on every click** - a quick scale-in on the button/element being clicked, so the frame
  is never a static full-screen UI with a drifting cursor.
- **Animated callout labels** on each step: "name it", "pick your tools", "authorize once". A new
  overlay at least every ~5-6 seconds.
- **Cut to a 1-2s talking-head reaction** every ~15-20s to break the screen-share.
- **Re-tease the open loop** once (~1:30-2:00): "and remember, one of these is going to run on a
  server every morning without me - we'll get there." Then keep going.

## The 3 fixes this rebuild bakes in (vs our MCP video)
