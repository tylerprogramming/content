I finally ran the full Claude Design workflow end to end, not just the prototype part.

Most videos on this stop after Claude Design spits out a nice landing page. The part that actually matters, turning that design into real code that ships, is the part they skip. So I did the whole loop and recorded every click.

Here is how it went. First I set up a design system, which is the most slept-on feature. I did not point it at a repo. I just uploaded four screenshots of designs I liked from Google Images, and Claude pulled the palette, the typography, and the spacing from those.

Then I prompted the landing page and iterated right in the canvas. There are four ways to do it: pull the tweak sliders, click and edit an element, drop a comment, or literally draw an arrow on the design. You just point at the thing.

The handoff is one line. Claude Design bundles the design, a readme, and the chat, and hands Claude Code a single command. Claude Code wrote the page into my real Next.js repo, then I deployed it live from inside Claude Code with the Vercel MCP. Live URL in 23 minutes total.

One honest catch: Claude Design has its own weekly usage meter, and one full workflow ate about three quarters of my Pro allowance. Worth knowing before you buy.

I dropped the exact prompts, the design system setup, and the Claude Code handoff template in here. What would you ship with this first?
