## Email Body (paste into Resend)

```
Hey [first_name],

Following up on the Claude Design video, because a few of you asked how the workflow actually goes start to finish. Here it is, plainly.

I start in Claude Design and set up a design system first. I do not point it at a repo. I upload four screenshots of designs I like, and it pulls the palette, the typography, and the spacing from those. Now everything I generate matches that look.

Then I prompt the landing page. Before it builds anything, it asks me clarifying questions, kind of like plan mode in Claude Code. Once it is drafted, I iterate in the canvas. Four ways: pull the tweak sliders, click and edit an element, drop a comment, or draw an arrow right on the design. I never rewrite a full prompt.

Now the handoff, which is the part most videos skip. Claude Design bundles the design, a readme, and the chat history, and hands Claude Code a single command. Claude Code writes the page into my real Next.js repo, using my existing components and tokens. Then I deploy it live from inside Claude Code with the Vercel MCP, no dashboard, no tab switching. A live URL comes back in two minutes.

One useful tip if you go try it. Set up the design system before you build anything, even from a few screenshots. It is what makes the final code come out consistent instead of a one-off HTML dump.

I walk through all of it on real screens here:

https://www.youtube.com/watch?v=aiMZrj4zqo8

The prompts I use and the handoff template are in my community if you want to copy them:

https://www.skool.com/the-ai-agency

- Tyler
```
