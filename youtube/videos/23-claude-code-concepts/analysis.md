# Analysis: 21 Claude Code Concepts Video

## Source Video Analysis

### Video: "Every Claude Code Concept Explained for Normal People" by Simon Scrapes
- **Duration:** 27:24
- **Views:** 144,922 (as of March 6, 2026)
- **Format:** 27 concepts, each ~60 seconds

### Structure Breakdown
| Segment | Time | Duration | Purpose |
|---------|------|----------|---------|
| Hook + promise | 0:00-1:01 | 1 min | Pain points, credibility, "27 concepts in 60s each" |
| Concepts 1-8 (Foundations) | 1:01-8:38 | 7.5 min | Basics: what is CC, terminal, prompts, permissions, tools, context, history, tokens |
| Concepts 9-14 (Configuration) | 8:38-13:31 | 5 min | Claude.md, memory, compact, models, deny lists, flags |
| Concepts 15-23 (Power Features) | 13:31-22:10 | 8.5 min | Extended thinking, slash commands, skills, hooks, MCP, sub-agents, agent teams, screenshots, checkpoints |
| Concepts 24-27 (Practical) | 22:10-27:02 | 5 min | Git, CLI mode, pricing, worktrees |
| CTA | 27:02-27:23 | 20s | Subscribe + course plug |

### What Works Well
- Numbered concept lists perform great on YouTube (he has TWO in the top 15)
- Genuinely accessible language for non-coders
- Good pacing (~60 seconds each)
- Progressive structure: foundations → config → power features → practical

### Weaknesses (Our Opportunities)
- **No demos** — All talking head + slides. Zero screen recordings.
- **Too surface-level** — 27 concepts at 60 seconds each = nothing gets real depth
- **Missing key concepts:** /init, Plan Mode, @ file references, custom slash commands
- **No practical examples** — Says "skills are expert playbooks" but never shows one
- **Targets beginners exclusively** — No bridge to intermediate
- **Course plug interrupts flow** at concept 15

### Our Differentiation
1. **Live demos for every concept** — biggest gap in existing content
2. **Curated 21 vs 27** — we cut the fluff (token usage, flags, pricing, extended thinking)
3. **Added missing concepts** — /init, Plan Mode, @ file references
4. **Custom skill demo** — showing a real skill in action (no other video does this well)
5. **Shorter and faster** — 15-17 min target vs 27 min
