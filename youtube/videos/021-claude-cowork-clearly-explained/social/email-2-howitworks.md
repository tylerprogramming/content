## Email Body (paste into Resend)

```
Hey [first_name],

Want to show you the one part of this week's video that changes how people think about Cowork.

Everything else in the video, I had to ask for. I sat there and typed the request every time. Organize this folder. Build me this spreadsheet. Pull my channel numbers.

Then I did the last demo.

I took that exact "go to my YouTube Studio and write me a performance report" task, and instead of running it once, I set it to run every Monday morning on its own.

That's it. Now every Monday, before I've even had coffee, the report is sitting in my folder. I didn't have to remember it. I didn't have to ask. It just shows up.

That's the moment it clicks for most people. You're not using a chatbot anymore. You've hired something.

So here's the 5-minute exercise. Think about your own week and find the thing you do on repeat:

1. A report you pull every Monday
2. The same few websites you check every morning
3. The same folder you tidy
4. The same numbers you copy into a sheet

Pick one. In the video I show you exactly where the schedule option lives so you can hand it off one time and stop thinking about it.

Here's the part most people get wrong: a scheduled task doesn't run on your computer. When you schedule it, it becomes a routine that runs on Anthropic's servers, so it fires on time even if your laptop is closed. (The app only needs to stay open if you run a live loop instead of a schedule.) Set it once and forget it.

That demo is near the end of the video if you want to jump to it:

https://youtu.be/7ND_buIAQfA

If you set one up, reply and tell me what you automated. I'll share the best ones next week.

- Tyler

https://www.skool.com/the-ai-agency
```
