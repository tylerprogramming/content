# Hooks, video 063

Three word-for-word opens, each about 30 seconds. All three start on a screen, not on camera, per the cold-open rule: a working artifact already running beats a claim. None of them states Duet's output; that is filled in after it runs.

## Hook A: the artifact that rebuilt itself (recommended)

[SHOW: Duet web, Make tab, Channel Pulse open. Scroll to the refresh time. No camera yet. Requires PRE-BUILD 3: the 6:30 weekday refresh has fired on its own at least once. Earliest 2026-10-28.]

So this rebuilt itself at six thirty this morning. I was asleep. I didn't open Claude. I didn't type anything.

It's a dashboard for my YouTube channel. Claude Duet made it on Tuesday, and then this morning it made it again on its own.

[SHOW: camera]

So I gave Claude Duet three real jobs. A dashboard for my channel, a spreadsheet across my GitHub repos, and the lesson deck for my Skool community. All on my real stuff.

And every Duet video I watched this week ends the same way. The creator opens the thing it made, reads two lines out loud, and says "nice." Nobody puts it next to the source. So that's what this is. Three jobs, the output next to the real numbers, and a count of what it got right.

Technique: working artifact on screen, then the stake. The "I was asleep" line is only true if the scheduled refresh ran unattended; if it did not, use the fallback in filming-guide step 1.

## Hook B: the count (bold claim)

[SHOW: Duet web, split: Channel Pulse left, YouTube Studio right, both on the last 10 uploads. Requires PRE-BUILD 4 so the count is known.]

[N] of these ten rows are right. [M] are wrong. That's a dashboard Claude Duet built for my channel, next to the real numbers in Studio.

[SHOW: camera]

So Claude Duet came out last week, and I watched six people demo it. Three of them built something on their own data. Zero of them checked it. I did. Three jobs: a dashboard, a spreadsheet, and a deck. Here's the count on each one.

Technique: a number in the first sentence, per the retention rule. The number has to be real; fill it in on filming morning from `receipts.md`. If the count is 10 of 10, say so and the hook gets stronger, not weaker.

## Hook C: the card (pattern interrupt)

[SHOW: Duet web, Chat. The approval card from PRE-BUILD 6 already on screen, mid-send, not yet approved. Requires that a card actually appeared in the pre-build.]

So this is Claude Duet asking me for permission. It built a spreadsheet of my GitHub repos, I asked it to message me the top three, and it stopped right here. [Read what the card shows: the action, where it's going, what's in it.]

[Do not approve yet.]

Anthropic wrote a whole post about this card. I watched six videos and nobody showed it. We're going to come back and press that button.

[SHOW: camera]

Before that, two other jobs. A dashboard for my channel that refreshes on its own, and the lesson deck for my Skool community. Three real jobs, and I checked every one against the source. Let's go.

Technique: pattern interrupt plus an open loop (the button gets pressed at 6:00). Only usable if the card looks like something; if PRE-BUILD 6 found no card, drop this hook.

## Note on Hook A

The timestamp has to be real. The refresh is asked for at 6:30 ET weekdays (PRE-BUILD 3, Prompt P1). If it ran at 6:34, say six thirty-four. If it ran but the artifact shows no time, show the task history time. If it did not run, the hook changes: "I asked this to refresh at 6:30 and it didn't. So that's receipt number one." The number does not need to be clean, it needs to be true.
