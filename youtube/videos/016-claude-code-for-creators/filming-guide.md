# Filming Guide: Claude Code for Content Creators (Not Developers)

## Pre-Filming Checklist

### Screen Recording Prep
- [ ] Clean desktop, hide personal bookmarks/tabs
- [ ] Terminal font size: 16pt minimum (viewers need to read commands)
- [ ] Terminal theme: dark background, light text (standard)
- [ ] Close all notifications (Slack, Messages, email)
- [ ] Have a fresh terminal session ready
- [ ] Blotato dashboard open in a browser tab with content already scheduled (for the "show result" section)
- [ ] Have the CLAUDE.md template file ready to paste

### Camera Prep
- [ ] Clean background or studio setup
- [ ] Good lighting (key light + fill)
- [ ] Lavalier mic or shotgun mic ready
- [ ] Camera at eye level

### Content Prep
- [ ] Run /yt-search once before filming so results are cached and fast
- [ ] Have a sample video slug ready (e.g., claude-code-for-creators)
- [ ] Pre-generate one set of /content output so you know what to expect
- [ ] Have Blotato accounts connected and ready
- [ ] Prepare a sample week's calendar view (screenshot or live)

## Shot List

### Section 1: Hook (0:00 - 1:00)
**Setup:** Talking head, confident energy
**Notes:** No screen recording needed. This is all Tyler to camera. Practice the credibility stack so it flows naturally, don't read it.
**Duration:** 60 seconds

### Section 2: Show Result (1:00 - 2:30)
**Setup:** Screen recording - Blotato dashboard or content calendar
**Shots needed:**
1. Full week calendar view showing 32 scheduled posts
2. Scroll through 3-4 different platform posts (LinkedIn, Instagram, X, YouTube Community)
3. Quick terminal flash (1-2 seconds of a skill running)
**Notes:** Pre-populate Blotato with a real week of content so this looks authentic. Don't fake it.
**Duration:** 90 seconds

### Section 3: Setup (2:30 - 5:30)
**Setup:** Screen recording with voiceover (or picture-in-picture)
**Shots needed:**
1. nodejs.org download page (5 seconds)
2. Terminal: npm install command
3. console.anthropic.com - API key creation (blur the actual key)
4. Terminal: launching Claude Code for first time
5. Creating CLAUDE.md file
6. Pasting content creator rules into CLAUDE.md
**Notes:** Move fast through install steps. People will pause if they need to. Don't linger. The CLAUDE.md section is the important part, slow down there.
**Duration:** 3 minutes

### Section 4: Framework (5:30 - 7:30)
**Setup:** Talking head, possibly with simple graphics overlay
**Shots needed:**
1. Tyler explaining the 5-stage pipeline
2. On-screen text appearing for each stage: Research, Script, Repurpose, Schedule, Repeat
**Notes:** Keep this conversational. Don't make it feel like a lecture. The 5 stages should feel simple and obvious, not complex.
**Post-production:** Add text overlays for each stage name
**Duration:** 2 minutes

### Section 5A: YouTube Research (7:30 - 10:00)
**Setup:** Screen recording with voiceover
**Shots needed:**
1. Terminal: typing /yt-search claude code tutorial
2. Results loading and displaying
3. Scroll through results table highlighting view counts
4. Point out the gap (all developer-focused)
5. Terminal: typing /yt-search social media ai automation content creator
6. Show second set of results
7. Show saved research file
**Notes:** Narrate while it runs. Don't just sit in silence. Explain what it's doing. Point out insights as they appear.
**Duration:** 2.5 minutes

### Section 5B: Generating Content (10:00 - 14:00)
**Setup:** Screen recording with voiceover
**Shots needed:**
1. Terminal: typing /content claude-code-for-creators
2. LinkedIn post appearing - pause so viewers can read
3. X post appearing - pause
4. Instagram caption appearing - pause
5. YouTube Community post appearing - pause
6. Show Claude iterating on a post after feedback
**Notes:** This is the money section. Let each post sit on screen for 2-3 seconds. Viewers need to read and be impressed. Call out platform-specific formatting rules as they appear.
**Duration:** 4 minutes

### Section 5C: LinkedIn Carousel (14:00 - 17:00)
**Setup:** Screen recording with voiceover
**Shots needed:**
1. Terminal: generating carousel content
2. Each slide appearing (slide 1-6)
3. Blotato carousel preview
4. Mention the 6-slide rule (skip slide 7, use Kie.ai CTA instead)
**Notes:** Carousels are visual, so show the output. If Blotato can render a preview, show it.
**Duration:** 3 minutes

### Section 5D: Scheduling (17:00 - 19:30)
**Setup:** Screen recording with voiceover
**Shots needed:**
1. Terminal: scheduling commands through Blotato MCP
2. Posts appearing in Blotato schedule
3. Full week schedule view
**Notes:** Show posts landing in the schedule in real time. The "magic moment" is seeing content appear on the calendar automatically.
**Duration:** 2.5 minutes

### Section 5E: Full Week Calendar (19:30 - 21:00)
**Setup:** Screen recording, possibly with overlay graphics
**Shots needed:**
1. Calendar/spreadsheet view showing Mon-Sun content breakdown
2. Highlight specific days and content types
**Notes:** Could be a pre-made graphic or a live Blotato view. Make it scannable.
**Duration:** 1.5 minutes

### Section 6: Result + Bonus (21:00 - 24:00)
**Setup:** Talking head for recap, then screen recording for bonus
**Shots needed:**
1. Tyler on camera, ticking off what was built (5 items)
2. Terminal: running /shorts
3. Short-form scripts scrolling by
**Notes:** The bonus (/yt-search + /shorts combo) should feel like a genuine extra, not filler. Show real output.
**Duration:** 3 minutes

### Section 7: Close (24:00 - 26:00)
**Setup:** Talking head, genuine energy
**Notes:** Don't oversell the Skool community. Keep it casual. "It's free to join and we're in there every day." End with energy up, not trailing off.
**Duration:** 2 minutes

## Post-Production Notes

- Add text overlays for the 5 Content Engine stages
- Add chapter timestamp overlays at section transitions
- Zoom in on terminal text during key commands (editor should know which ones)
- Add subtle highlight/box around important numbers (view counts, post counts)
- End screen: subscribe button + link to Skool + next video
- Thumbnail: clean white background, Claude Code icon or terminal, bold text "Not a Coding Tool." or "Creators Are Sleeping on This."

- Talking head: 15-20 minutes
- Screen recording: 45-60 minutes
- Total: ~75 minutes of filming for a 26-minute video
