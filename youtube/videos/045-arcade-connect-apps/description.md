# Description - 042 Arcade Connect Apps

Claude Code is great in the terminal, but out of the box it can't touch your real apps. In this video I connect it to Gmail, Google Calendar, Slack, and GitHub in about seven minutes using Arcade, an MCP runtime that handles the per-user OAuth for you. No server to build, no tokens to hardcode, no scopes to fight. You build a Gateway, run one command, authorize each tool once, and Claude starts taking real actions in your real accounts.

I've built integrations at big companies for years, and the auth layer is always the hard part. That is the piece Arcade removes. I show a Gmail action, a Calendar action, and a Slack action to prove the breadth, keep anything that sends in draft mode first, and explain why this is safe enough for real work: per-user OAuth, tokens you never see, and every action logged.
