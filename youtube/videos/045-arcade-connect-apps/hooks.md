# Hooks - 042 Arcade Connect Apps

Three word-for-word cold opens. Each uses a different technique. Pick one, open fast, no preamble.

---

## Hook 1 - Result-first (RECOMMENDED)
*Technique: show the outcome and the time up front, then promise the how.*

Claude Code just read my calendar, pulled the emails that actually need a reply, and drafted them. Then it posted my standup to Slack. All from the terminal, using my real accounts. And it took about seven minutes to set up. No code. No OAuth headaches. Here is exactly how I did it.

---

## Hook 2 - Pain-first
*Technique: name the frustration the viewer already has, then relieve it.*

Claude Code is great, but out of the box it can't touch your real apps. It can't read your Gmail. It can't check your calendar. It can't post to Slack. And normally, connecting it means fighting OAuth, tokens, and scopes. I've built these integrations at big companies for years, so I know how annoying that is. There is a way to skip all of it. Let me show you.

---

## Hook 3 - Bold claim
*Technique: a plain, confident statement that reframes what is possible.*

You don't build integrations anymore. You assemble them. In the next few minutes I'm going to give Claude Code access to Gmail, Google Calendar, Slack, and GitHub, using prebuilt tools, with the auth handled for me. One command in the terminal. Then Claude is taking real actions in my real accounts. Here is how it works.
