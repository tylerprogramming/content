Scoring key: Clarity / Curiosity / CTR pull, each 1-10. Total out of 30.
CTR pull = how hard the average AI-curious viewer thumb-stops on it.

## Top 3 recommendations
1. **I Post to 7 Platforms and Never Open an App** (26) - highest CTR, real number, vivid claim, kills the "post everywhere grind" pain in one line.
2. **One Video In, 7 Platforms Out (Claude Code)** (25) - cleanest one-to-many promise, best thumbnail pairing, keeps Claude Code for search.
3. **I Automated Publishing My Content With Claude Code** (24) - the proven-lane anchor, safest search, directly extends the winning format.

## FINAL PICK
**I Automated Publishing My Content With Claude Code**

Why the anchor wins as the primary: this video's whole strategic job is to test whether the proven "I Automated My [X] With Claude Code" format still pulls on a NEW topic. To run that test cleanly, the title has to actually BE the format - same skeleton as the #1 video, one variable swapped ("publishing"). If we get clever and ship a different structure, we can't read the result. It nails search ("automated," "publishing," "content," "Claude Code"), it's honest, and it holds both audiences. Use the sharper number-and-claim lines (#2, #3) as the thumbnail text and the A/B challenger, where the CTR upside is highest without polluting the format test.

## A/B plan
- **A (ship first):** I Automated Publishing My Content With Claude Code
- **B (challenger, swap at 48h if CTR is soft):** I Post to 7 Platforms and Never Open an App
- Run this through YouTube Test & Compare (native A/B), not manual swaps. Keep the thumbnail identical across A and B so the test isolates the title.
- Watch first-24h CTR vs. the channel baseline. The anchor should clear baseline given the proven lane. If A clears baseline, keep it and log that the format transfers to new topics. If B beats A meaningfully on CTR without hurting retention, that tells us the "7 platforms / never open an app" pain-and-number framing is the stronger hook for the distribution angle specifically - worth noting for the rest of the arc.
