# Description — 050

I built a Claude Code skill that researches my whole niche before I sit down.
It pulls the top content across YouTube, Instagram, TikTok and X through one MCP
server, reads the winning transcripts, and hands me a ranked brief of what to
make next. Five steps, no framework code, and it runs on a schedule.

Everything I use is linked below. The skill, the Apify MCP setup and the
grilling skill are all free to copy.
