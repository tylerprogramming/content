## Reply 1

👉 Setup takes under 5 minutes: create a Telegram bot via BotFather, install the Claude Code plugin, paste your token, launch with the --channel flag, then enter your access code to pair your phone.

---

## Reply 2

👉 This is async - not a live terminal session. You send a message, Claude does the work in the background, then texts you back with the results. No babysitting required.

---

## Reply 3

👉 I ran yt-search, thumbnail generation, and social post creation all from Telegram while away from my desk. Claude texted me back with the results each time.

## Reply 4

👉 Lock it down with allowlist mode - only your Telegram ID can trigger it. Nobody else gets in.
