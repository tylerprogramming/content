## MODULE 2 - RESEARCH: START FROM WHAT WORKS (2:00-4:00)

[SHOW: `/yt-search <topic>` live - ranked long-form + shorts results, thumbnails downloading. Then `/yt-deep-research` on the top 2.]

`/yt-search` researches what's actually working on YouTube for your topic and ranks it by views, split into long-form and shorts. Then `/yt-deep-research` transcribes the top videos and breaks down the hooks and structure. Point: "You're not guessing what to make. You're starting from proven demand." React to one insight you wouldn't have spotted.

## MODULE 3 - LEARN FROM THE WINNERS (4:00-5:00)

[SHOW: `/transcribe <competitor URL>` -> transcript appears.]

`/transcribe` pulls the full transcript from a proven reference video so you can model the structure and hooks without watching ten videos. Meta moment: "This is how I plan - I learn from what's already ranking, then make it mine."

## MODULE 4 - PLAN THE WHOLE VIDEO (5:00-7:00)

[SHOW: `/yt-package <transcript>` generating titles, hooks, the script, the description, the filming guide. Open the real files. Then `/yt-seo`.]

`/yt-package` is the core planning skill. Feed it the reference and it writes the full package - titles, hooks, the script, the description, the filming guide. Then `/yt-seo` optimizes the title, description, and tags against what's ranking. Point: "Research to a full script in minutes, grounded in what works, not a blank page." Honest beat: "I still rewrite anything that doesn't sound like me. This gives me the draft, not the final."

## MODULE 5 - THUMBNAILS (7:00-8:00)

[SHOW: `/yt-thumbnail` generating variants with Nano Banana, using your likeness.]

`/yt-thumbnail` generates thumbnail options with the Claude image models, using your own face. Make a few variants so you can A/B test. Point: "The one asset that decides if anyone clicks, done from the terminal."
