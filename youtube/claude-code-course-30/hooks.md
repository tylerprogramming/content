# Hook Options: Claude Code 30-Minute Course

Each hook is the FULL first 30 seconds, scripted word-for-word.

---

## Hook 1: Empathy + Promise (Eliot Prince Pattern - 892K)

**Style:** Open with vulnerability, then pivot to authority.

> I'm going to be honest with you. The first three weeks I used Claude Code, I was doing it completely wrong. I was typing prompts one at a time, waiting for responses, fixing errors manually. It felt like I was using a supercar to go to the mailbox.
>
> Then I learned 10 concepts that changed everything. Today I have 25 custom skills that run my entire content business. Thumbnails, scripts, scheduling, carousels, all of it. I produce 32 pieces of content every single week, and most of it happens while I'm filming or editing.
>
> In the next 30 minutes, I'm going to teach you every single one of those 10 concepts using my real setup, not a demo.

**Why it works:** "I was doing it wrong" creates instant relatability. The viewer thinks "I'm probably doing it wrong too." Then the contrast (wrong -> 32 pieces/week) creates a gap they need to close.

---

## Hook 2: Direct Qualification (Jeff Su Pattern - 317K)

**Style:** Qualify the viewer in the first 5 seconds so they self-select.

> You're in the right place if you've heard about Claude Code, maybe even tried it, but you're not a developer and you're wondering how this actually helps you make content or run a business.
>
> I'm not a developer either. But I use Claude Code every single day to plan my videos, generate thumbnails, write scripts, create Instagram carousels, and schedule everything across five platforms.
>
> Here are the 10 concepts you need to know. Each one takes about 3 minutes. By the end, you'll have a system, not just a tool.

**Why it works:** "Not a developer" immediately disarms the viewer who feels intimidated. The list of real outcomes (thumbnails, carousels, scheduling) makes it tangible. "A system, not just a tool" sets the right expectation.

---

## Hook 3: Data + Authority (Dan Martell Pattern - 498K)

**Style:** Open with a surprising stat, then claim authority.

> Every week, I publish 2 YouTube videos, 5 shorts across three platforms, 4 Instagram carousels, 7 LinkedIn posts, and 2 Pinterest pins. That's 32 pieces of content. And I do it in about 2 content days per week.
>
> The system behind all of that is Claude Code. Not the way most people teach it, building apps and writing software. I'm talking about using it as a content engine.
>
> I have 25 custom skills that handle everything from research to publishing. In the next 30 minutes, I'll show you the 10 concepts that make it all work.

**Why it works:** The specific numbers (32 pieces, 2 days) create an immediate "how?" reaction. "Not the way most people teach it" positions this as different from every other Claude Code video. The viewer knows exactly what they'll get.

---

## Hook 4: Counterintuitive Insight (Matt Pocock Pattern - 249K)

**Style:** Reframe something familiar in a way that makes them rethink their approach.

> Here's something nobody tells you about Claude Code. The tool itself barely matters. What matters is the instructions you give it before you ever type a single prompt.
>
> I learned that the hard way. I spent weeks typing commands one at a time, getting mediocre results. Then I set up one file, a CLAUDE.md file, and everything changed. That file turned Claude Code from a chatbot into a system that knows my voice, my workflow, and exactly how I want my content created.
>
> I'm going to show you that file and 9 other concepts that make Claude Code actually useful for creators and business owners.

**Why it works:** "The tool barely matters" is counterintuitive for a tool tutorial. It hooks curious viewers who want to know what DOES matter. The CLAUDE.md reveal gives them a concrete thing they can go set up immediately.

---

## Hook 5: Challenge + Proof (Hybrid Pattern)

**Style:** Challenge a common belief, then prove the alternative with your own results.

> Most Claude Code tutorials teach you to build apps. That's great if you're a developer. But if you're a content creator or a business owner, you've probably watched those videos and thought, this isn't for me.
>
> It is for you. You just need different concepts. I use Claude Code to plan every video on this channel. It generates my thumbnails, writes my social posts, creates my Instagram carousels, and schedules everything through one system.
>
> In 30 minutes, I'll teach you the 10 concepts behind that system. No coding. No terminal commands you don't understand. Just the stuff that actually matters.

**Why it works:** Directly addresses the objection ("this isn't for me") that stops non-developers from watching Claude Code content. "No coding, no terminal commands" removes the final barrier. This hook has the strongest audience-qualifying power.

---

## Recommended Hook

**Hook 1 (Empathy + Promise)** for highest retention. The vulnerability opener combined with the specific "32 pieces of content" number creates the strongest combination of relatability and aspiration.

**Backup: Hook 5 (Challenge + Proof)** if Tyler wants to lean harder into the "not for developers" positioning, which is the strongest differentiator from every other Claude Code video.
