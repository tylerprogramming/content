Claude Code Tutorial #7 - Plan Before You Build

## Description

Stop building blindly. Plan Mode lets Claude explore your code and map out exactly what it will do — before it touches a single file. In this episode, you'll learn the Explore > Plan > Implement > Commit workflow that saves you from wasted time and wrong implementations.

This is part of a free Claude Code course for non-technical founders and beginners. No coding experience needed.

- Live demo: planning a dark mode feature before building it
- The 4-step workflow: Explore > Plan > Implement > Commit
- When to use Plan Mode vs. just building
- Extended thinking — what happens when Claude "pauses"
