Claude Code Hooks: Automate Everything (Course Finale) | Claude Code Tutorial #13

Hooks are shell scripts that fire automatically at specific moments in Claude Code's lifecycle — and they don't use any AI tokens. They're deterministic, reliable, and free. In this finale, I set up three practical hooks: an auto-formatter, a command logger, and a folder protection system.

This is the final episode of the Claude Code tutorial course. We wrap up by combining everything from the series — CLAUDE.md, commands, skills, MCP servers, sub-agents, and hooks — into a complete AI workflow system.

In this video:
- What hooks are and the key difference (deterministic, zero AI tokens)
- Lifecycle events: PreToolUse, PostToolUse, Notification, Stop
- Setting up hooks with /hooks command
- Having Claude write hooks for you (just ask!)
- Demo: Auto-format hook (Prettier runs after every file edit)
- Demo: Command logging hook (every Bash command timestamped)
- Demo: Protection hook (blocking writes to migrations/ folder)
- Exit codes explained (exit 0 = allow, exit 2 = block)
- Hooks in settings.json for portability
- Course recap: combining CLAUDE.md + commands + skills + MCP + sub-agents + hooks
- What to learn and build next
