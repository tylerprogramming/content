# Episode 9 — YouTube Description

## Title
Claude Code Tutorial #9 - Build Your Own Commands

## Description

One slash command. Entire workflow. Custom commands let you save any multi-step workflow as a simple /command in Claude Code. In this episode, you'll learn every built-in slash command and then build your own custom commands from scratch.

This is part of a free Claude Code course for non-technical founders and beginners. No coding experience needed.

**In this video:**
- All built-in slash commands (/help, /clear, /compact, /model, /init, /rewind, /permissions)
- What custom commands are and why they're powerful
- The .claude/commands/ folder structure
- Live demo: building a /deploy command from scratch
- Live demo: building a /report command
- Practical examples (test, review, document, standup, optimize)
- Tips for writing effective command files
