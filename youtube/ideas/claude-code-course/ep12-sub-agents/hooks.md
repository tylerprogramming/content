# Claude Code Tutorial #12 - Hook Options

## Hook Option 1 (RECOMMENDED)

> You know what's wild? When you give Claude a complex task, it doesn't just try to do everything itself. It builds a team.
>
> It spins up separate AI instances — each one focused on a specific piece of the problem. A researcher. A code reviewer. A security scanner. Working in parallel.
>
> These are called sub-agents. And in this video, I'm going to show you how they work, when Claude creates them automatically, and how to build your own custom specialists. Let's get into it.

**Tone:** Genuine amazement at the start. Like you're telling a friend something cool you discovered. The list of specialists should build in intensity.

---

## Hook Option 2

> What if instead of one AI assistant, you had a whole team? A researcher who digs through documentation. A reviewer who audits every line of code. A security expert who catches vulnerabilities before they ship.
>
> That's sub-agents. And Claude Code already knows how to use them. You just didn't know it yet.
>
> In the next twelve minutes, I'll show you sub-agents in action — and teach you how to create custom ones for your own workflows.

**Tone:** Paint a picture with the first paragraph. Deliver "You just didn't know it yet" with a slight grin. Confident and inviting.
