Claude Code Sub-agents: Delegate Tasks Like a Boss | Claude Code Tutorial #12

Sub-agents are separate Claude instances that focus on specific tasks — research, code review, security audits, and more. Instead of one overloaded AI, you get a team of specialists, each with their own context window and focus.

In this video, I explain what sub-agents are, show Claude auto-spawning them on a complex task, and then build two custom agents from scratch: a security reviewer and a research specialist.

In this video:
- What sub-agents are and why they matter
- How sub-agents keep your main context window clean
- When Claude auto-spawns sub-agents on complex tasks (live demo)
- The .claude/agents/ folder structure
- YAML frontmatter: name, description, tools
- Building a security-reviewer agent from scratch
- Building a research agent from scratch
- Running custom agents and reviewing their output
- Tool restrictions for sub-agents (least privilege)
- Best practices for creating effective sub-agents
