## Title
Claude Code Tutorial #1 - Install & Build Your First App

## Description

Claude Code is not a chatbot — it's an AI agent that builds real projects on your computer. In this first episode of my Claude Code course for beginners, I install it from scratch, explain how it works, and build a full landing page live in under 2 minutes.

No coding experience needed. If you can describe what you want in plain English, you can use Claude Code.

**In this video:**
- What Claude Code is (and how it's different from ChatGPT)
- How to install Node.js and Claude Code step by step
- 3 terminal commands every beginner needs to know
- Live demo: building a landing page from one prompt
- Quick tour of the Claude Code interface
