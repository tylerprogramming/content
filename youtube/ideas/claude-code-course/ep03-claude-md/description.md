# Episode 3 — YouTube Description

## Title
Claude Code Tutorial #3 - CLAUDE.md Changes Everything

## Description

CLAUDE.md is a single file that completely changes how Claude Code works on your project. Without it, Claude guesses your tech stack, your conventions, and your preferences — and it often guesses wrong.

In this video, I demo the exact same prompt with and without a CLAUDE.md file so you can see the difference. Then I show you exactly how to create one, what to put in it, and my "every mistake becomes a rule" approach to making it better over time.

**In this video:**
- What CLAUDE.md is and why it matters (with live before/after demo)
- Using /init to auto-generate your first CLAUDE.md
- Exactly what to include: project overview, tech stack, rules, and "do nots"
- Global (~/.claude/CLAUDE.md) vs project-level CLAUDE.md
- The "every mistake becomes a rule" iteration approach
- Quick intro to @imports for larger projects
