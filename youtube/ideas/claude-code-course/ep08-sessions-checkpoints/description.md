## Title
Claude Code Tutorial #8 - Sessions & Checkpoints

## Description

Never lose your work again. Claude Code automatically saves your sessions and snapshots your code before every edit. In this episode, you'll learn how to resume past sessions, name them for easy access, and use /rewind to undo any change — going back to any point in your project's history.

This is part of a free Claude Code course for non-technical founders and beginners. No coding experience needed.

**In this video:**
- How sessions are saved automatically
- Resuming sessions with --continue and --resume
- Naming sessions with /rename for easy lookup
- What checkpoints are and how they work (automatic snapshots)
- Live demo: breaking something and using /rewind to fix it
- Restoring code only, conversation only, or both
- How sessions + checkpoints work together in a real workflow
