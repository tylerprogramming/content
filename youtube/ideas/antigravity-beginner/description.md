# YouTube Description

Google AntiGravity is a free AI coding tool that builds apps for you — and in this video I take you from zero to a fully working expense tracker dashboard in about 12 minutes. No coding experience needed. I cover setup, your first prompt, the task list system, live iteration, and the three things every beginner should know.

## In this video:
- What Google AntiGravity actually is (and why it's different from Cursor/Copilot)
- Download, install, and first project setup
- Building a full expense tracker dashboard with one prompt
- How the Task List and Plan Mode work (the key feature)
- Iterating on design and features with plain English
- The Rules system — how to make AntiGravity 10x better on every project
- Quick look at the Agent Manager (parallel agents)
