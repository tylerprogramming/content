# List / resource videos

## Why this format, specifically

Sabrina's two hardest outliers are both giveaways, not builds:

| Video | Views | Outlier |
|---|---|---|
| 10 Secret Codes for Claude AI & ChatGPT | — | **6.2x** |
| Every Prompt to Make Unlimited Free AI Videos | 39,000 | **2.8x** |

Her *builds* sit at 0.4-1.0x. The two that broke out both hand over a countable
set of things the viewer can take.

**The channel has zero of these.** Not "a few" — zero. It is the cheapest
unexplored format available, and the raw material already exists.

## What makes the format work

Four things, and the format fails without them:

1. **A number in the title.** The number is the promise. "Some skills" is not a
   video; "10 skills" is. It also sets the runtime and stops the sprawl.
2. **The files ship.** `(Every File Included)` / `(Free Templates)` is the whole
   move. Without it this is a listicle and it dies. With it, it is a download,
   and downloads get saved, shared and commented.
3. **Each item stands alone.** No dependency between item 3 and item 7 — that is
   what makes it re-watchable and what keeps retention flat instead of cliffed.
4. **Comment-gate or link the pack.** Direct feed into Skool. This format is the
   best top-of-funnel the channel can build, because the viewer self-selects as
   someone who wants to *do the thing*.

**The trap:** the 08-10 short *17 Claude Code skills run my content business* did
**0.2% CTR on 507 impressions**. Same material, framed as a diary. "Here is what
I have" is a flex. "Here is what you get" is a resource. Same footage, opposite
result — this is the single clearest example on the channel of packaging alone
deciding the outcome.

## The list

### 1. 10 Claude Code Skills You Can Steal (Every File Included)
The 17 skills already run the business. Pick the 10 that generalise — drop
anything YouTube-only, per the topic-reach rule. Files go in a public repo.
Highest confidence in this document: the material exists, is filmed-adjacent,
and the failed short is a controlled proof that only the framing was wrong.

### 2. 7 n8n Workflows That Run My Business (Free Templates)
The n8n re-entry, in the format most likely to land. `webhook n8n` is already
sending 63/month with nothing current. n8n templates are JSON — literally a file
to hand over — and the n8n audience is trained to import them. Best possible
first move back into that lane.

### 3. 12 MCP Servers That Actually Do Something
Rides the same term as the Sunday course and can be published two weeks after it,
catching the search demand that video builds. "Actually do something" is the
differentiator against the endless "top MCP servers" lists that are all API
wrappers nobody uses.

### 4. 8 Free AI Tools That Replaced My Paid Stack
BRAIN [2026-08-05]: naming the subscription being cancelled works like a dollar
figure. Doing eight at once is a stacked version of a proven title move. Note
the standing rule — **no money amounts in titles**, so the savings go in the
thumbnail and the first line, not the title.

### 5. 15 Prompts I Use Every Single Day (Copy These)
Closest analogue to Sabrina's 6.2x. Lowest production cost in the document —
no build, no screen recording chain, one sitting. Good filler between big builds.

## Sequencing

These are the cheap slot, not the main slot. The searched-term courses in
`2026-08-13-next-ideas.md` are the base load; these go between them, because
they cost a fraction of a course and feed the community directly.

Order: **#1 first** (material exists, proof the framing was the problem), then
**#2** as the n8n re-entry, then #5 as filler whenever a week gets tight.

## Rules carried over

- Number in the title, always.
- Files actually ship, or do not make the video.
- No "I" framing — see `2026-08-13-next-ideas.md`. `10 Skills You Can Steal`
  works, `17 Skills That Run My Business` does not, and that is measured.
- No money amounts in titles (`CLAUDE.md` standing rule).
