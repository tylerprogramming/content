# Filming Guide

Setup: Use a clean desk, two-camera setup if possible (one face cam 1/3 left, one over-the-shoulder screen capture). Capture full-screen recordings of Claude Code UI, VSCode snippets, and terminal output at 60fps for smooth text. Use a lav mic or shotgun on boom for clear voice; record room tone for easy edits.

B-roll & pacing: Interleave short 10–30s demo clips for each tip, with b-roll of typing, code popping in the editor, terminal runs, and the Claude.md file being edited. Keep overall pacing brisk: 30–60 seconds per numbered tip, longer demos where necessary (90–120s). Use on-screen callouts for commands and filenames. End with a 15–20s recap and a clear CTA to download the cheat-sheet. Keep transitions tight and cut any dead space — viewers expect a high-information, rapid-pace format.
