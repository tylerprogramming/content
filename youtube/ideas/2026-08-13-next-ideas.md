Against the four that work:

| Video | Impressions | CTR | Subs |

**Zero of the four start with "I."** All four are second-person instruction on a
term with search demand.

**Why "I" fails mechanically, not stylistically.** Nobody types "I automated my
video ads" into YouTube, so search cannot find it. And Suggested video is at
**5.9%**, meaning YouTube is not confident enough to push anything to people who
did not search. With search closed and browse closed, the video has no route to
a viewer. The content is fine. It has no door.

**The content is not the problem — the package is.** These are the same builds,
retitled as instruction:

| Was | Could be |
|---|---|
| I Automated My Entire Content Workflow with Claude | How To Automate Your Entire Content Workflow With Claude Code (Full Build) |
| I Run My Entire Content Business on 3 Claude Code Agents | 3 Claude Code Agents That Can Run a Whole Content Business |
| I Don't Edit Videos Anymore, Claude Code Does | How To Edit Videos With Claude Code (Full Setup) |

Nothing about filming changes. Only the promise does.

**When "I" is allowed:** Sabrina's best video is *I Built $1M Marketing Team with
1 AI Agent (7 Skills)* at **3.6x** her median. The "I" is attached to a number
and a stake, not to a workflow. *I automated my Pinterest* has no stake. If a
title starts with "I", it needs a number in it or it does not ship.

## The asset sitting unused

Search is **34.5%** of all traffic, the single biggest source, and it runs almost
entirely on videos you stopped making. Last 28 days:

```

ollama tutorial 52 · crew ai 42 · smolagents 35 · crewai full course 29
```

`crewai` + `crew ai` + `crewai full course` = **182 searches in 28 days**, landing
on a tutorial from a previous era that still pulled 5.5% CTR and 75 subs.

This is demand **proven on your own channel**, not guessed from a keyword tool.
It is the lowest-risk video you can make, and it fixes the Suggested problem as a
side effect: a new CrewAI video gets suggested off your old CrewAI videos, which
already have watch history. You are not starting cold.

**Note what is missing from that list: `claude code`.** You make constant Claude
Code content and it sends you no search traffic, because that term belongs to
channels far bigger than yours. You rank on *specific tool names with moderate
competition*. That is the lane. Play it deliberately.

## The rules these were generated against

1. **The head term must be something people already type.** Course framing is the
   wrapper, the searched term is the engine. Claude Cowork Full Course got 4,588
   impressions to Firecrawl's 30,981 on the identical shape — a demand gap, not a
   CTR gap, because impressions are served before anyone clicks.
2. **Second person, not first.** "How to" / "Full Course" / "For Beginners".
   If it starts with "I", it needs a number and a stake.
3. **Specific tool names, moderate competition.** Not `claude code`, not `ai
   agents` alone. Firecrawl, CrewAI, AgentKit, Ollama, n8n, MCP.
4. **Reclaim before you conquer.** A term already sending you traffic is worth
   more than a bigger term where you have no history, because it brings
   Suggested lift from your own catalog.

## What to do with the existing backlog

filmed. Retitle them against rule 2 and requeue. The AntiGravity block in Active
