# Analytics

Channel diagnostics and competitor research. Reports are dated `YYYY-MM-DD-slug`,
raw data lives in `data/`, and anything that produces a number lives in `assets/`
as a script so the number can be regenerated rather than trusted.

## Rule for this folder

**Every figure in a report must trace to a CSV in `data/`.** If a report states a
number that no script can reproduce, it has started to drift and should be
rebuilt from the data instead of edited. `assets/build-infographic.py` reads its
CSV for exactly this reason.

## Data

```
data/2026-08-13-tyler-last30-ctr.csv        our last 30 WITH CTR - hand-pulled from
                                            Studio, because the Analytics API does
                                            not expose impressions or CTR at all
data/2026-08-13-tyler-ai-last30.csv         our last 30 from the Data API (views,
                                            duration, thumbnails, video IDs). No CTR
data/2026-08-13-<channel>-last30.csv        one per competitor, Data API
data/2026-08-13-competitors-combined.csv    all 180 competitor videos in one file
data/2026-08-13-sabrina-recent.csv          superseded. Hand-pulled from Studio
                                            Advanced mode before the API script
                                            existed. Kept because
                                            2026-08-13-last30-and-sabrina.md cites
                                            it; use the -last30 file for new work
```

**Why two Tyler files:** CTR and impressions are Studio-only metrics. The
YouTube Analytics API v2 does not return them, so any CTR figure here was read
off Studio by hand and cannot be regenerated by a script. Views, durations and
thumbnails come from the Data API and can.

## Scripts

```
assets/competitor-pull.py     python3 competitor-pull.py @handle [@handle ...]
                              Last 30 uploads per channel, scored against that
                              channel's OWN median. Shorts scored separately from
                              long-form - mixing them makes every long-form look
                              dead on a channel that posts shorts.
assets/build-infographic.py   Renders the CTR infographic FROM the CSV
```

Run under the skills venv, which has the Google client libraries:

```bash
~/.claude/skills/.venv/bin/python3 assets/competitor-pull.py @indydevdan
```
