# Filming Guide - Video 2: ElevenCreative Flows Agent

**Format:** Horizontal (16:9) for YouTube. 12-16 min. Talking head + screen recording.

---

## Production do's (brief-mandated)
- **Film horizontal.** This is a dedicated long-form YouTube video, never vertical.
- **No microphone in the shot** if you can avoid it. Lav under the shirt or a boom out of frame.
- **Smart-casual clothing.** No pajamas, no loud logos. Solid color reads best on camera.
- **Good, front-facing light.** Natural window light or a ring/key light in front of you. Avoid backlit shots (no bright window behind you).
- **Clean or relevant background.** Tidy desk or a simple set. Nothing distracting moving behind you.
- **Audio check FIRST.** Record 20 seconds, play it back, confirm levels and no room echo or hum before you film the whole thing.
- **Speak the full product name early and clearly** - "Flows Agent in ElevenCreative" - it is the compliance line and it must land in the first 5 seconds.

---

## Pre-record checklist
- [ ] Logged into ElevenCreative with an account that has **Flows enabled** (it's in alpha - confirm your access is live before you sit down).
- [ ] **Flows Agent** panel is available in your Flow (open a new Flow and confirm the agent chat side panel appears).
- [ ] You have a **clear, specific ad/video brief in your head to type** - write the exact sentence down beforehand (e.g. "make me a 15-second product video for a ceramic coffee mug, warm and cozy tone, with a voiceover and background music"). A specific prompt = fewer re-runs = a cleaner, cheaper demo.
- [ ] **Verify the Assist mode options are live** in your build (approve-each / auto-run / auto-under-threshold) so you can show all three on screen. If the labels differ in your alpha build, note the real labels and narrate what you actually see.
- [ ] Enough **credits** in the account to run the full demo plus the batch/variations without hitting a wall mid-record.
- [ ] A **product image or asset ready** if you want the agent to build around a specific image (optional - the agent can generate one too).
- [ ] **PartnerStack link + code on hand** so you reference "link and code in the description" naturally (you don't read the URL aloud, just point to it).
- [ ] Screen recorder set to clean 1080p/1440p, cursor visible, browser zoom at a readable level, notifications silenced, only the ElevenCreative tab open.
- [ ] Do a 30-second dry run of the agent building nodes so you know the timing and can narrate over the real build.

---

## Exact on-screen demo steps (film in this order)
1. **Dashboard to Flows.** Open ElevenCreative, click into Flows, create a new Flow. Land on the empty canvas.
2. **Open the Flows Agent chat panel** on the side. Point to it: "this is where I just talk to it."
3. **Type the one-sentence brief.** Show the sentence clearly on screen as you type it.
4. **Let it ask clarifying questions.** Capture the agent asking about length / tone / voice / structure. Narrate that it asks before it spends.
5. **Answer the questions**, then let it build. Film the canvas as nodes appear and connect themselves (image node, video node, TTS node with Eleven v3, music node, composition node). This is the money shot - get it clean.
6. **Show the model options** on a node briefly to back the "50+ image and video models plus the full audio stack" line (name Veo 3, Sora 2, Kling, Seedance, Flux, Nano Banana on screen if visible).
7. **Play the first preview** in the composition node.
8. **Iterate by chat #1:** type "use a warmer voice for the voiceover." Show only the voice branch re-running.
9. **Iterate by chat #2:** type "use Veo for the video instead" (swap the model conversationally). Show that branch re-running.
10. **Play the updated preview.**
11. **Open Assist mode** and show all three settings on screen (approve-each / auto-run / auto-under-threshold). Hold on the menu long enough to read.
12. **Async moment:** type a bigger batch request (e.g. "build three variations with different opening shots"), then **physically close the browser tab** on camera.
13. **Reopen** ElevenCreative, open the Flow, and reveal the **finished** variations. Emphasize you walked away and came back to finished work.
14. If a node shows a **credit cost on hover before running**, capture it - it reinforces the honest cost story.

## Accuracy reminders while filming (say it right or lose payment)
- Platform is **ElevenCreative**; feature is **Flows** / **Flows Agent**. Never just "Flow."
- This is **Flows Agent**, not ElevenAgents. Do not say ElevenAgents at all.
- Say **"50+ image and video models"** - never "30+".
- Do not claim a **"Dubbing v2 node."**
- Say **"currently in alpha"** once.
- The **API is coming soon** - do not demo or promise it.
- Iterating is **not free** - chat is token-billed, generations use credits. Always pair cost talk with Assist mode.
- **No competitors, no money claims, no puffery.**
- **No em dashes** in any on-screen text.
