## Patterns & Insights

### Duration Sweet Spots
- **6-60 seconds**: Highest engagement (relatable takes, quick demos)
- **90-120 seconds**: Strong for tutorials and walkthroughs
- **3-5 minutes**: Works for in-depth but needs strong hook

### Hooks That Work
- "You need to know..." (authority/urgency)
- "Who even [does X] anymore?" (relatable disruption)
- "[Tool] is a cheat code for LIFE" (hyperbolic but authentic)
- "Everyone's talking about X... but here's the problem" (contrarian)
- "If you're non-technical..." (audience expansion)
- "I switched from ChatGPT to Claude" (comparison narrative)

### Content Gaps (Opportunities)
1. **Claude Code Skills deep-dives** - @olleai and @agentic.james are the only ones; you own this lane
2. **Claude Code for content creators** - @rileybrown.ai touched on this (video editing), massive untapped audience
3. **"I built X in Y minutes" speed builds** - format works on YouTube but underrepresented on TikTok
4. **Claude Code automation/agents** - only @nickvasiles really covered this
5. **Before/after workflow comparisons** - nobody showing "old way vs Claude Code way"
6. **Custom skills as superpowers** - literally nobody is making TikToks about building Claude Code skills

### Engagement Patterns
- Videos from small accounts (<10K followers) regularly outperform big accounts on engagement rate
- Authentic "this changed my life" angle beats polished tutorials
- Short relatable takes (under 15s) can go mega-viral even from tiny accounts
- Saves are HUGE on Claude Code content — people bookmark tutorials (high save:like ratio)
