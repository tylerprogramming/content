# 🎥 STORYBOARD / VISUAL BLUEPRINT: The Reverse Engineering Skill

## 🎯 OVERVIEW
*   **Goal:** A 10-12 minute educational piece establishing a new workflow standard for AI output quality.
*   **Tone:** Academic, rigorous, and highly technical.
*   **Visual Flow:** Always use comparison, contrast, and structured schematics.

## 🎬 SHOT LIST PER ACT

### **ACT I: INTRODUCTION (The Failure Mode)**
*   **Shot 1 (Hero):** Full screen on the "Winner Output Example" (from the code execution). It must look *perfect*.
*   **Shot 2 (The Doubt):** Zoom into a single line of text. Overlay motion graphics: a question mark and a red "NON-DETERMINISTIC" stamp.
*   **Shot 3 (The Thesis Statement):** Full screen text overlay: **PROMPT $\rightarrow$ (Fluke) $\rightarrow$ Output. INSTEAD. SYSTEM $\rightarrow$ (Guaranteed) $\rightarrow$ Skill.**

### **ACT II: THE 4-STEP WORKFLOW (The Process)**
*   **Visual Centerpiece:** A constantly evolving, animated diagram (The 4-Step Flow).
*   **Transition 1 (A $\rightarrow$ B):** Fade from the full text to granular boxes (Bullet points: Hook, Constraint, Metric). *Visual action: Highlighter passing over disparate rules.*
*   **Transition 2 (B $\rightarrow$ C):** The boxes coalesce under three header banners: **Structural Flow**, **Constraint Set**, **Mechanic**. Show the 'Triad' forming.
*   **Transition 3 (C $\rightarrow$ D):** This is the most complex shot. Show the rules turning into JSON/Code syntax. Use code blocks to illustrate the transformation: `rule: "must be skeptical"` $\rightarrow$ `# CONSTRAINTS: - Tone MUST be skeptical`.
*   **Transition 4 (D $\rightarrow$ E):** The final structured block *snaps* into the shell command/skill call.

### **ACT III: THE PAYOFF (Beyond Text)**
*   **Visual Contrast:** Side-by-side comparison. Left screen: Text. Right screen: Terminal/Code.
*   **Deep Dive:** Full screen focus on the `android-api-extractor` skill (The Advanced Example). Show the **Input File (APK)** leading to the **Structured JSON API Output**. This proves the concept applies to non-text data.
*   **Closing Shot:** Full screen text: **STOP PROMPTING. START ENGINEERING.** (Hold on this impactful statement).
