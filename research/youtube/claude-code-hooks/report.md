## Patterns (03-22)
- Comprehensive explainers that translate technical concepts into plain language perform very well
- Authority hooks (e.g., 'Meta Staff Engineer') boost credibility and watch time
- Actionable listicles ('5 skills') attract viewers looking for quick wins
- Personal workflow + real-world use cases are favored over abstract theory
- Titles emphasize accessibility ('for Normal People') or rarity/authority ('Staff Engineer')

## Gaps (03-22, about prompt templates, not Claude Code hooks; replaced)
- No concise, repeatable 'hook templates' for prompting Claude Code—short swipe files creators can reuse
- Lack of short-form demo clips (15–90s) showing immediate impact of a single hook or prompt
- Few comparisons or A/B examples showing which hooks elicit better outputs (and why)
- Missing beginner-to-advanced progression focusing specifically on crafting high-conversion hooks
