## 1. What it is, one paragraph

Jev is the first "System One model" from TypeSafe AI, a San Francisco lab founded 2024 by Diogo Almeida (co-author of the InstructGPT/RLHF paper at OpenAI). Announced 2026-09-14 (blog), public launch and $40M seed (DCVC) on 2026-09-15. It does not generate text. You send a `state` (text or JSON) plus a map of typed questions (Choice, Score, Noul) and get back typed answers with calibrated probabilities and confidence, in one parallel pass. Vendor-listed: $0.042 per million input tokens, output free, 70 to 500 ms per call, `jev-1.13.0`, text only, closed weights, hosted at `POST https://api.typesafe.ai/v1/systemone`.

## 5. Technical facts (from docs.typesafe.ai, fetched 2026-09-23)

| Item | Value | Source |
|------|-------|--------|
| Model id | jev-1.13.0 (aliases jev-latest, jev-preview) | https://docs.typesafe.ai/models |
| Price | $0.042 per Mtok input ($42 per Btok); output free | same |
| Rate limits | 250,000 tokens/s, 1,200 req/min, "adjusting dynamically" | same |
| Context | 64k total; 32k for state plus longest question | same |
| Input | Text only (string, JSON, array). No image/audio/video | same |
| Endpoint | POST https://api.typesafe.ai/v1/systemone | https://docs.typesafe.ai/api |
| Question types | Choice (up to 255 options, returns choice + probabilities + confidence), Score (ordered rubric, 2 to 10 levels), Noul (0 to 1 probability of yes, no confidence field) | https://docs.typesafe.ai/primitives |
| Training | RLCD, "Reinforcement Learning for Calibrated Decisions". Not fine-tunable; same weights every account | https://docs.typesafe.ai/introduction/machine-learning-primer |
| Data | Not trained on customer requests; ZDR for enterprise | https://docs.typesafe.ai/models |
| SDKs | pip install typesafe-sdk; npm @typesafe-ai/sdk | https://docs.typesafe.ai/sdk |
| Claude Code | `claude plugin marketplace add typesafe-ai/skills` then `claude plugin install typesafe@typesafe-ai`; invoke `/typesafe:typesafe-ai` | https://docs.typesafe.ai/agent-skill |
| Playground | https://console.typesafe.ai/playground | quickstart |

Docs sample (quickstart): state = Stripe support ticket; questions department (Choice: billing/technical/sales), frustration (Score: 3 levels), is_urgent (Noul). Response: choice technical p=0.85 conf 0.78, score 1.0, noul 1.0, usage 392 in / 65 out. Good on-screen demo because the 3 types show in one call.

Documented failure modes (jaggedness page, 9 listed): literal reading, math and counting, date comparison, indirection, large irrelevant state (context rot), adversarial content, contradictory criteria, structural invariants (P(refund)=0.72 and P(not refund)=0.47 sum to 1.19), generation. Rule from docs: "Code first, Jev second, LLM last" is the community phrasing; TypeSafe's is "keep the arithmetic in code."

Docs explicitly say Jev is not a coding-agent model: "There is no `model: 'jev-latest'` setting that turns your coding agent into a Jev-powered agent." https://docs.typesafe.ai/introduction/coding-agents

## 7. Academic and seminal works to cite

1. Ouyang, Wu, Jiang, Almeida et al., "Training language models to follow instructions with human feedback" (InstructGPT), arXiv 2203.02155, 2022-03-04. The RLHF origin; 1.3B InstructGPT preferred over 175B GPT-3.
2. Kahneman, Thinking, Fast and Slow (2011). Source of the System One name, credited in the docs and launch FAQ.
3. Sutton, "The Bitter Lesson" (2019), reframed by Almeida as "right task > data > compute > algorithms."
4. Jiang, Li, Li, "Jev-Mem: System-One-Controlled Agentic Memory," arXiv 2609.23986, 2026-09-21. First third-party academic use.
5. RLCD: no paper. Only the AI primer page and the launch post. Say "unpublished" on camera.
6. Jevons, The Coal Question (1865). The paradox the name references.

## 8. Weaknesses and open questions (our credibility beats)

- Closed weights, hosted only, no self-host, US-hosted. Early access; API was closed to new signups at least once (TechCrunch).
- Rate limits change "without notice" (docs warning).
- All headline multipliers are vendor-measured; TypeSafe's own "Nuance" boxes admit bias. Independent numbers so far: Vercel (5 to 18x), Bryo (Gemini more accurate).
- Text only. Every "browser agent" demo uses a DOM-to-text step.
- Not a calculator, not a date parser, literal reader, context rot in large state (docs).
- "Can't hallucinate" means schema-safe, not correct. Ronacher (Earendil): "it delegates the hallucination problem a little bit to the user."
- Training method has no paper. Architecture undisclosed.
