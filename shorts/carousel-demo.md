# Short #4 — How I Create Carousels with AI

**Format:** Screen recording
**Target length:** 45-60 seconds
**Post day:** Saturday April 5

---

### Hook (first 3 seconds)
"I create LinkedIn and Instagram carousels without touching a design tool."

### Script
Here's how. I tell Claude Code what topic I want a carousel about. It writes the slide content - title, steps, text for each slide.

Then it generates each slide as an image using Kie.ai. Dark background for LinkedIn, light background for Instagram. Different styles for each platform.

7 slides. Each one generated in about 30 seconds.

For LinkedIn, it combines them into a PDF. I upload it as a document post. Looks like a professional carousel.

For Instagram, it keeps them as individual images. I post them as a carousel through Blotato.

The whole set costs about a dollar fifty in AI generation. And I get content for two platforms from the same topic.

One conversation. Two carousels. No Canva. No Gamma. Just Claude Code and a good prompt.
