# Short Script - 5 Claude Code Features You're Not Using (45-60 sec)

5 Claude Code features almost nobody uses.

Plan Mode. Hit Shift+Tab. Claude shows you what it's going to build before it builds it. You review, then execute. Stop letting it build blind.

Compact. Your context window is full and Claude starts forgetting things. Type /compact. It keeps a summary of everything but frees up 90% of your memory.

Session History. You close the terminal and think it's gone. It's not. Type claude --resume. Pick any session and continue where you left off.

Rewind. Claude broke something. Type /rewind. It shows you snapshots from every checkpoint. Go back to before it went wrong.

Extended Thinking. Claude thinks step by step before responding. The output quality difference is real.
