5 claude code features that most people skip over

these aren't advanced - they're just not obvious when you first start using it.

1. plan mode (shift+tab) - see the full plan before claude builds anything. review it, adjust it, then let it execute. way better than just letting it go

2. /compact - when your context window fills up and claude starts forgetting stuff, this clears the conversation but keeps a summary. you go from 90% usage back to almost nothing

3. claude --resume - every session is saved. close the terminal, come back later, pick up exactly where you left off

4. /rewind - claude broke something? go back to any checkpoint and restore from there. saved me more times than I can count

5. extended thinking - claude reasons through complex problems step by step before giving you an answer. the output quality is noticeably better

which ones are you using? which ones are new to you?
