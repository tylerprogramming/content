# LinkedIn — Sunday March 29
**Topic:** Stop retyping instructions into every Claude session

---

If you're typing the same instructions into every Claude chat, you're doing it the hard way.

There's a file called CLAUDE.md that Claude reads automatically at the start of every session. Whatever you put in it, Claude follows — without you saying a word.

Go to your home directory. Create a file called CLAUDE.md. Type one rule in it.

That rule now applies to every Claude Code session you open. Forever.

👉 No more typing "be concise" every time

👉 No more pasting your project context at the start of every chat

👉 No more saying "don't use em dashes" for the hundredth time

The real power is that it compounds. Every time Claude does something you didn't want, add a rule. Every time you find yourself typing the same instruction twice, add a rule. After a few weeks, Claude works exactly the way you work - automatically.

I've been using this for months. My CLAUDE.md is a full page now. And I almost never correct Claude on style or behavior anymore - because it already knows.

One file. Permanent behavior. Most underused feature for Claude Code beginners.
