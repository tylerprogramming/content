**Topic:** 3 types of Claude memory — most people only use one

---

Claude has three types of memory. Most people are only using one — and then wondering why Claude keeps forgetting things.

Here's the breakdown:

👉 Context window: Everything in your current session. Temporary. When the session ends, it's gone. This is the one most people know.

👉 CLAUDE.md: A file Claude reads automatically at the start of every session. Permanent instructions — behavior rules, workflow context, preferences. Always on. You write it once, Claude follows it forever.

👉 Memory skill: Claude can write notes about you across sessions. Your goals, preferences, ongoing projects. Like a real assistant building a profile over time. Survives context resets.

Most beginners rely entirely on the context window and repeat themselves constantly. They paste the same system prompt every time. They retype the same instructions. They wonder why Claude seems to "forget" who they are.

The fix takes about 10 minutes. Create a CLAUDE.md file. Add 3-5 rules. Start using the memory skill. Now Claude knows you - every session, without you saying a word.

That shift alone changes how useful Claude Code is day to day.
