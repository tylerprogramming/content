something i wish someone told me earlier about Claude

the longer your session runs, the worse the output gets. it's not a bug. it's just how context windows work.

every message you send, every file Claude reads, every response it gives - it all fills up the context window. once it hits the limit, Claude starts dropping older context to make room. it forgets what you said earlier, instructions stop sticking, things feel off.

the fix is really simple. start a fresh session every hour or two, or whenever you switch tasks. for anything Claude needs to know every session, put it in CLAUDE.md - that file survives resets.

once you notice context rot happening it's impossible to unsee. but at least the fix is easy

how long do your sessions usually run before you notice the drop in quality?
