## Setup Steps (OpenAI Custom GPT)

1. Go to [chat.openai.com](https://chat.openai.com) → Explore GPTs → Create
2. In the **Configure** tab:
   - **Name:** Traffic OS Assistant
   - **Description:** Your personal traffic coach for growing an audience, running Meta ads, and building a YouTube channel — based on the Traffic OS training inside Kourse
   - **Instructions:** Copy/paste the entire contents of `system-prompt.md`
3. Under **Knowledge**, upload both KB files:
   - `kb-traffic-strategy-ads-instagram.md`
   - `kb-youtube-organic.md`
4. Under **Capabilities**:
   - Disable Web Browsing (keeps answers grounded in course content only)
   - Code Interpreter: not needed
5. Save and test with sample questions

## Sample Test Questions

- "What is Traffic Nirvana?" → Should explain all 6 channels and how they work together
- "What is the Meta Andromeda update?" → Should explain broad targeting, creative IS the targeting, Advantage+ campaigns
- "How do I set up retargeting on Meta?" → Should explain the 4–5 retargeting audiences, separate campaign, direct creative
- "How does server-side tracking work with Skool?" → Should explain pixel integration in Skool settings, why it matters for iOS tracking
- "What is an outlier video?" → Should explain views >> channel average, Velio/VidIQ tools, Notion database
- "How do I come up with YouTube video ideas?" → Should explain outlier research, Answer the Public, remixing vs. copying
- "What makes a great YouTube thumbnail?" → Should explain setup/tension/payoff, face + emotion, text callouts, contrast
- "What are viral vectors?" → Should give examples (Japanese, secret, $X in X days) and explain how to use them
- "What are content pillars?" → Should explain the 4 questions and give niche examples
- "Should I use interest targeting on Meta?" → Should explain Andromeda update: no interest targeting, go broad, creative does the targeting
- "What is interest media?" → Should explain YouTube vs. push media (TikTok/Instagram), high intent, how the algorithm works
- "How do I write a YouTube script?" → Should explain setup/tension/payoff per section, L1/L2/L3 levels, therefore storytelling, hook framework
- "What are the 3 rules for YouTube titles?" → Should explain visualize it, falsify it, can only you say it
- "What analytics should I look at?" → Should explain impressions + CTR (5%+ = good) + AVD (30%+ = good), and what each means
- "How do I split test thumbnails?" → Should explain Thumbnail Tester tool, 24-hour test, never test titles and thumbnails together
- "How do I use AI for YouTube?" → Should explain Poppy AI, ChatGPT projects with story bank and speaking style, prompting framework (role/context/instructions)
- "What's the best AI thumbnail tool?" → Should mention Higgs Field (newest/best), Nano Banana Pro via ArtList, Pexels — with workflow
- "What's changing on YouTube in 2026?" → Should explain hard mode, subscribers don't matter, lazy videos dying, packaging is king, be human not AI
