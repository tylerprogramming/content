# Winning Video Checklist (Claude/AI lane)

> Build every video package against this. Derived from the 2026-06-24 commonality analysis of top Claude/AI videos (60 days). Source: `research/2026-06-24-COMMONALITY-analysis.md`.

## 0. CADENCE (the #1 lever)
- [ ] Publishing 2x+/week? Top creators post daily-to-every-4-days. Volume + speed is the moat.
- [ ] Riding new releases within DAYS of launch? (Nate/Chase react to new models/features immediately.)

## 1. TITLE — use a proven formula
- [ ] Fits one: money/outcome ($X/mo) · numbered "I tried N, these are best" · "X% / X in Y min" · insider "ACTUALLY" · comparison "X vs Y vs Z" · contrarian "Stop/you're doing it wrong" · "better than 99%" · news "X is INSANE"
- [ ] Hook front-loaded (number/$/tool in first 2-3 words)
- [ ] One specific number + one curiosity gap
- [ ] ~50-60 chars, Title Case, optional parenthetical
- [ ] NOT: vague ("changed everything"), descriptive ("my workflow"), "master/full course/explained" (these drag on this channel)

## 2. THUMBNAIL — the 5-part formula (Tyler's biggest CTR fix)
- [ ] Big EXPRESSIVE face one side (~45% frame), real emotion (shock/smug/confident) — no flat faces
- [ ] 2-4 HUGE words other side, ONE word in accent color
- [ ] Claude orange asterisk/icon as brand cue (replace a letter / hold it / float it)
- [ ] A proof element (dashboard, $ number, real screen)
- [ ] Orange/coral palette, max contrast, legible at mobile size
- [ ] Steal-devices: "HOLY SH*T → TRY THIS", "JUST COPY ME", pointing at proof, holding the asterisk
- [ ] Run YouTube Test & Compare (2-3 variants)
- [ ] NOT: busy collage, tiny text, >1 face + 1 text block + 1 element

## 3. HOOK — first 5 seconds, no "hey what's up guys"
- [ ] Opens with the "MOST PEOPLE [do X wrong/basic]" reframe (the #1 device)
- [ ] Fast credibility flash woven in (a number/credential, one sentence)
- [ ] Specific numbered promise (N things / $ / minutes)
- [ ] Accessibility ("no technical experience needed")
- [ ] Open loop tease ("the last one changes everything")
- [ ] "Let's get into it" — straight in
- Template: "Most people [do X wrong]. [Quick cred]. Here are [N things] that [outcome], no [barrier] needed. [Tease the best]. Let's go."

## 4. FORMAT / FRAMING
- [ ] Showcase, not "teach a course" (showcase of a new/hot thing is Tyler's proven long-form lane)
- [ ] 10-25 min sweet spot for tutorials/showcases
- [ ] Winning formats: comparisons (X vs Y vs Z), "I tested N," numbered tips, news-reaction showcases, money/business
- [ ] Proof-first cold open (value/result on screen in first 15-30s — retention fix)

## 5. CTA
- [ ] ONE primary CTA: the funnel (free.tylerai.dev/youtube/)
- [ ] Comment-bait question at the end
- [ ] Skool secondary

- **Thumbnail:** black background · Tyler's face (consistent framing/expression) · huge 2-line white text · ONE orange accent word · the orange Claude asterisk as the signature mark · a concrete proof element (real channel stat — never fake $)
