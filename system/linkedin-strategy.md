# LinkedIn Strategy

## Two Post Formats

### Format 1: Duncan-Style Text Posts (Lead Gen)
- Result-first hook with specific numbers
- Proof stack (3+ concrete metrics)
- Framework or numbered list (skimmable)
- Personal story or credibility moment
- Comment-trigger CTA ("Comment 'X' and I'll send it over")
- No hashtags, no markdown, no bold
- Every post has a lead magnet attached
- Goal: comments = leads = DMs

Reference: Duncan Rogoff - grew LinkedIn from 1,500 to 10,000+ with this format. One post got 2,475 comments.

### Format 2: Charlie-Style Carousel PDFs (Reach)
- Built in Gamma, exported as PDF, uploaded to LinkedIn
- 6-7 slides per carousel
- Dark navy background on content slides
- Light accent color on CTA slide (contrast flip)
- Structure:
  - Slide 1: Title/hook (big bold, accent color keyword)
  - Slides 2-5: One step per slide
    - Colored "STEP X" badge (different color each step: blue, green, yellow, orange, purple)
    - Big heading with ONE keyword in accent color
    - 2-3 numbered substeps
    - Real screenshot below as proof
  - Slide 6: Payoff/result ("NOW USE IT" or "THE RESULT")
    - Show it working, example outputs, proof
  - Slide 7: CTA slide
    - Light background (contrast from dark slides)
    - "SAVE THIS GUIDE. REPOST FOR YOUR NETWORK."
    - Profile photo + handle + follow CTA
- Minimal text per slide, scannable in 3 seconds
- Code blocks in dark containers with monospace font
- Real screenshots, not mockups
- Page counter top right
- Goal: saves + reposts = reach

Reference: @charliehills - "How to Install Claude Code for Free" (7 pages)
