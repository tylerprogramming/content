## How To Use This Tracker

- **Adding new content:** drop it in the right `platform/<channel>/` folder with a date prefix. Then add a row here.
- **Tracking video pipeline state:** use `youtube/status.md` (separate file — that's the operational doc).
- **Finding something:** use `system/INDEX.md` for navigation help, or grep across `~/content/`.
- **Weekly review:** open this tracker every Monday morning to scan what was produced last week vs what's queued.
